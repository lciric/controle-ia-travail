## 2. Priorité 1 — Sargsyan, 2511.06701 v4

**Ce qu'il fait.** Une architecture pour systèmes de recherche automatisée où un orchestrateur écrit en Haskell tient la procédure statistique et le code produit par le modèle ne fait que remplir une fonction d'optimisation. Deux étages : une monade qui rend la comptabilité de l'erreur inévitable, « makes it impossible to test a hypothesis without updating the error budget » [S1, p. 1] ; un harnais engendré par l'orchestrateur avant que le modèle écrive, « The Haskell orchestrator generates a Python harness—a rigid skeleton that controls data flow and fixes the statistical test—before the LLM writes any code. » [S3, p. 8]. Formalisation en Lean 4 du contrôle du taux de fausses découvertes en ligne (procédure LORD de Javanmard et Montanari) et vérification en SPARK/Ada de l'arithmétique flottante (p. 11-22).

Composante par composante :
- **(a) Qui calcule.** Le harnais, pas le modèle : le test « is executed by the harness on per-example losses, not by LLM-generated code » [S2, p. 9] ; en conséquence le « LLM cannot substitute a weaker test or manipulate its parameters » [S5, p. 11]. **Occupée.**
- **(b) Engagement préalable.** Le harnais et le test sont fixés avant le code du modèle [S3, p. 8] ; chaque hypothèse reçoit un partage de validation disjoint, « assigning each hypothesis a disjoint validation split, fixed before any testing » [S4, p. 16] ; les données de validation sont absentes de l'environnement où tourne le code du modèle (espace de noms de montage Linux, p. 10). **Ni empreinte ni sceau** : aucune occurrence d'un engagement haché de la prédiction. **Voisine forte, pas occupée.**
- **(c) Nul.** Par hypothèse, échangeabilité des pertes par exemple entre le modèle optimisé et une base : test de permutation apparié à changement de signe (p. 9, 16) ; le système « runs experiments comparing the result to the baseline » [S12, p. 5]. C'est un nul « pas mieux que la base », la base étant fournie par le code du modèle : l'auteur reconnaît que « the LLM could define an artificially weak baseline during refactoring » [S7, p. 29]. **Pas de nul formé des lois connues ; voisin** (et la faiblesse qu'il nomme est exactement celle qu'un nul d'archive tenu par l'orchestrateur fermerait).
- **(d) e-valeurs.** Aucune : p-valeurs et richesse alpha. Horizon fixe seulement, ce « is not the optional-stopping formulation, whose extension we leave to future work » [S9, p. 15]. **Ne touche pas.**
- **(e) Multiplicité.** Cœur de l'article : contrôle en ligne du taux de fausses découvertes, démontré en Lean (taux marginal avec budget dérivé ; taux complet sous seuils non adaptatifs ; cas adaptatif renvoyé au théorème papier de Javanmard et Montanari, p. 15-16, 24). Positionnement des auteurs : parmi les systèmes cités, « systems applies multiplicity control » [S10, p. 31] est précédé de « none of these ». **Occupée.**
- **(f) Proposeur qui connaît le juge.** Évaluation adverse : la consigne adverse récompense la seule exactitude de validation et dit au modèle de charger toute donnée de validation ; le chemin exact du fichier est donné, « modeling a worst-case adversary that has seen the generated harness » [S6, p. 27]. Résultat (tableau 7, p. 29, auteurs, 50 générations par case, Claude Sonnet 4.6) : sous consigne adverse, « every well-formed generation attempted to read the validation file » [S14, p. 28] et y parvient sans isolement (taux de fuite 1,00) ; « Under isolation the same generations all failed: the leak rate is 0.00. » [S13, p. 28]. L'attaque vise la **frontière des données**, pas la statistique ni le seuil : ce n'est pas la forme A1. **Voisine pour O12 ; occupée en partie pour O11 et O13** (générations adverses, verdict rendu par l'orchestrateur sur un fichier que le code du modèle ne voit pas).

**Résultats chiffrés (auteurs).** Simulation de 2 000 hypothèses, 100 répétitions, 10 % d'effets vrais : « The naive approach inflates FDR to 41%; LORD controls it at 1.1%. » [S15, p. 25], au prix de la puissance (0,290 contre 0,640, tableau 4, p. 25). Calibration du nul sur 4 000 essais : rejet à 0,049 au niveau 0,05 pour le test de permutation, 0,37 pour le test t sur plis croisés qu'il remplace (p. 25). Cas d'étude à cinq hypothèses (tableaux 5 et 6, p. 26-27).

**Ce qu'il ne fait pas ; limites reconnues.** Le bac à sable n'est pas branché sur l'orchestrateur : « In the current release the orchestrator does not yet invoke this component » [S8, p. 10] ; la condition H1 (p-valeurs uniformes sous le nul) est « assumed », seule ligne non prouvée de la matrice de traçabilité (p. 23-24) ; pas de raffinement vérifié entre la preuve réelle et la preuve flottante (p. 22) ; base faible et reconstruction de données publiques non couvertes (tableau 8, p. 30).

**Réserves (symétrie).** (i) Les taux 1,00 et 0,00 du tableau 7 sont propres par construction (un fichier absent ne s'ouvre pas) ; ils mesurent le mécanisme du système d'exploitation, pas une résistance statistique. (ii) Le taux de 1,1 % contre une cible de 5 % vient d'une simulation à p-valeurs tirées d'une loi uniforme, pas d'agents : « The monadic LORD implementation controls FDR at 1.1% » [S11, p. 23] ne dit rien du système de bout en bout. (iii) Cas d'étude minuscules (cinq hypothèses). (iv) Auteur unique ; rédaction assistée par un modèle, déclarée (p. 34).

## 3. Priorité 1 — CONFIRM, 2611.01449 v2

**Ce qu'il fait.** Sépare l'exécution d'une analyse de la décision de la rapporter : « CONFIRM assigns this reporting decision to code » [C2, p. 3]. Le modèle traduit une question en plan d'analyse lisible par machine ; le plan est gelé et haché ; des scripts déterministes calculent ; cinq portes déterministes décident (historique de recherche et multiplicité, facteurs de confusion mesurés, puissance, stabilité analytique, réplication indépendante) sous trois standards. Banc NeuroClaimBench : 489 affirmations exécutables, dont 150 contrôles conçus pour violer une exigence (p. 6).

- **(a)** « deterministic scripts fit the models and generate an analysis record » [C3, p. 3] ; le modèle ne reçoit le dossier d'analyse que pour rédiger : « The LLM agent receives E(C) solely to draft natural-language summaries. » [C14, p. 3]. **Occupée.**
- **(b)** « Before any outcome data are read, the plan is fixed and assigned a cryptographic hash, an identifier computed from its contents. » [C1, p. 3]. Le plan fixe l'estimande, la direction, les covariables, les cohortes, la famille de recherche et les seuils des portes (p. 3-4). **Occupée** — c'est la collision la plus directe du lot avec « engagement scellé avant que les données existent » (à la nuance près : les données existent déjà dans les cohortes, elles ne sont pas encore lues).
- **(c)** Nul classique de chaque affirmation (différence de groupe, direction déclarée) ; aucune comparaison à un corpus de lois connues. La littérature sert d'étiquette de référence pour l'évaluation (p. 7), pas de nul. **Non trouvée.**
- **(d)** Aucune e-valeur ; les auteurs situent POPPER : « POPPER formulates sequential falsification experiments to evaluate free-form hypotheses with Type-I error control » [C8, p. 3]. **Ne touche pas.**
- **(e)** La porte « accounts for undeclared tests by correcting the claim for the effective number of tests » [C4, p. 5] (maximum du nombre déclaré, du nombre journalisé dans l'historique de l'agent et du nombre de traits ajustés) ; Bonferroni pour les affirmations scalaires, et « brain-wide claims use Benjamini–Hochberg-adjusted q-values across the regional family » [C5, p. 14] ; pénalité cumulée pendant la recherche de suivi (équation 3, p. 6). **Occupée** (par affirmation et par recherche ; pas de taux de fausses découvertes entre les affirmations d'une campagne).
- **(f)** Recherche de suivi : « the LLM receives deterministic diagnostic output identifying the failed gates » [C6, p. 9] ; les cohortes de réserve « are used only after the candidate plan and its final count of tests are fixed. » [C12, p. 6]. Épreuve de résistance : « The last two arms give CONFIRM’s diagnosis for all 150 designed controls » [C13, p. 22] ; au grand budget (10 tours, 10 candidats par tour), 10 716 « candidates, and none passed even provisionally » [C7, p. 9] (tableau 12, p. 22, auteurs). Parmi ces contrôles, 42 sont à étiquettes permutées : « Group diagnostic labels are randomly permuted » [C10, p. 6], donc sans aucun signal. **Forme A1 de O12 : occupée en partie** — proposeur modèle de langue (GPT-5.5), verdicts détaillés du juge servis, mondes où toute promotion est fausse, décompte des promotions. Manquent : l'intention de tromper (le modèle est invité à réviser honnêtement), la liberté du proposeur (un validateur rejette tout changement de question, de prédicteur, de direction, de jeux de données ou de seuils, p. 5, 15), un bras sans verdicts pour comparer.

**Résultats chiffrés (auteurs).** « CONFIRM falsely supports at most 3% of controls, compared with 23–38% for the baselines » [C15, p. 1] ; le standard complet n'en accepte aucun (tableau 7, p. 19, intervalle à 95 % [0, 2]) ; il retient 59 % des affirmations soutenues par la littérature, dont 87 % échouent à la réplication (p. 7). Aucune méthode comparée ne voit les verdicts : « No method sees a reference label, gate state, or CONFIRM verdict. » [C11, p. 7].

**Limites reconnues.** « Passing them does not establish biological truth. » [C9, p. 22] ; « its designed controls target specific gates » [C16, p. 22].

**Réserves (symétrie).** (i) **Circularité** : les contrôles sont conçus pour violer une exigence que la porte correspondante vérifie ; 0 % d'acceptation est donc attendu par construction — trop propre, réserve. (ii) L'ablation (tableau 8, p. 19) montre qu'ôter la porte de multiplicité ne change rien (+0, +0, +0) : sur ce banc, **la porte de multiplicité n'est pas démontrée utile**. (iii) Sur les partitions de réserve, 25 % seulement des affirmations d'abord confirmées repassent le standard complet (p. 8, 20) : le verdict se réplique mal sur lui-même. (iv) Les méthodes de comparaison sont « adaptées » par les auteurs ; « Table 3 reports a representative run » [C17, p. 9]. (v) Étiquettes de littérature fixées par trois modèles puis des experts dont le nombre n'est pas dit.

## 4. Les sept autres articles

### 4.1 N×N E-valuation, 2608.06621 v5
- **Ce qu'il fait.** Un certificateur d'hypothèses écrites par des modèles, sous forme de code (un champ, une restriction), qui exige que « the step that certifies them must need nothing from the proposer but the hypothesis » [N1, p. 1]. (a) **Occupée** : l'algorithme 1 calcule tout (p. 3). (b) Les hypothèses sont écrites sur une moitié de proposition séparée par « A hash of the user id splits them into a proposal half of 39,667 » [N8, p. 24], et « Every set was frozen before any method ran on it. » [N7, p. 25] ; pas d'empreinte de l'hypothèse : **voisine**. (c) Deux nuls sans modèle par hypothèse : « The units of one scope serve as nulls for one another » [N2, p. 1] et « The significance null is no lift over the units outside the scope » [N3, p. 3] ; le verdict « base rate » rejette une affirmation qui ne fait que redire la prévalence. C'est un nul de **taux de base**, pas un nul formé de lois déjà connues : **voisin le plus proche de O4 par l'intention** (écarter ce qui n'apprend rien), d'une autre construction. (d) **Occupée** : e-valeurs par pari, seuil 1/α, « so an e-value must reach 1/α = 20 to certify » [N4, p. 7]. (e) **Occupée** : annexe G, la procédure de Benjamini et Hochberg pour e-valeurs « takes e-values directly and controls the false discovery rate under arbitrary dependence » [N5, p. 25], appliquée aux 285 hypothèses ; motif : « Theorem 1 bounds the error of one certification, and a proposer emitting many accumulates them in proportion. » [N10, p. 25]. C'est exactement l'outil que la note d'antériorité attribuait en propre à l'organisme (« l'organisme applique la règle de Benjamini et Hochberg pour e-valeurs »). (f) Choix inverse : la session du proposeur « saw no certification outcome and nothing about our method or classes » [N6, p. 25]. **Ne touche pas O12.**
- **Chiffres (auteurs).** « N×N makes 692 correct decisions in 693 with one false certificate » [N12, p. 1] (tableaux 2, 3, 5, p. 8-9) ; nuls vrais par construction : seuil atteint dans au plus 0,29 % des tirages (p. 24).
- **Limites reconnues.** « The certificates concern predictive association, not causality. » [N9, p. 1] ; unités indépendantes exigées (p. 19) ; l'appel d'invariance est asymptotique (p. 7).
- **Réserves.** 692 sur 693 est trop propre : les classes plantées, les générateurs et la taxinomie des étiquettes d'experts (tableau 1 de la méthode) sont ceux des auteurs ; le nombre d'experts n'est pas dit ; la multiplicité est un contrôle d'annexe, pas une étape de l'algorithme. Les auteurs écrivent de leur combinaison de statistiques : « To our knowledge that combination is unoccupied. » [N11, p. 3] — affirmation d'auteur, non opposable.

### 4.2 CADS, 2610.24597 v1
- **Ce qu'il fait.** Un « certificat » pour criblages biologiques séquentiels guidés par un modèle. (a) **Occupée**, formulation la plus nette du lot : « the certificate reads the numerical channel, not the agent’s account of it » [D1, p. 5]. (b) Famille enregistrée d'avance, « the family is registered before the campaign and no hypothesis is added during it » [D2, p. 5] ; oracle privé : « Benchmark effects and reference labels remain in a private evaluation oracle and never enter » [D3, p. 4] la vue du proposeur ; protocole « gelé », un fichier de conception « though not lodged with a third-party registry » [D11, p. 26] ; empreintes SHA-256 des artefacts après coup (p. 29), pas d'un engagement préalable. **Voisine forte.** (c) Nul composite unilatéral contaminé : « Reference labels are threshold-derived, so the clean null is composite. » [D5, p. 5] (moyenne ≤ 0, contamination arbitraire bornée par lecture). **Nul composite occupé ; nul des lois connues non trouvé** (la boucle sans modèle et l'a priori fixe sont des contrefactuels de mesure, pas des nuls). (d)+(e) **Occupées** : e-processus par candidat, puis « complete-family e-BH produces one terminal declared set » [D14, p. 4] ; garantie : « CADS controls the terminal FDR in (1) for every predictable proposer and stopping time » [D6, p. 6]. ### 4.6 « Open-ended Scientific Discovery with Possibilistic Reasoning », 2610.11289 v1
- **Ce qu'il fait.** Découverte « abductive » : des e-processus par état définissent un espace de versions ; une hypothèse engendrée en cours de route est certifiée quand l'espace de versions y est contenu, puis classée par compatibilité avec un savoir de fond. Reproche fait à POPPER et à E-valuator : « these methods assume a fixed hypothesis set » [P1, p. 2].
- **(a)** Partie synthétique : calcul par le code. Partie réelle : la statistique vient de l'agent de POPPER, qui « executes its prespecified statistical test on the round’s previously unseen data fold and returns the p-value » [P7, p. 27]. **Ne déplace pas la frontière tracée par la note d'antériorité.** **(b)** « each measurement query has a statistical test fixed before its data fold is observed » [P4, p. 8] ; pas d'empreinte. Voisine. **(c)** Le savoir de fond sert de **préférence**, pas de nul : « among certified hypotheses, we favour those that can be accommodated with the least change to established scientific knowledge » [P2, p. 2]. Sens inverse de O4 (l'organisme exige de battre le connu ; ici on préfère ce qui s'en écarte le moins). **Voisin, non occupée.** **(d)** e-processus, e-possibilité (p. 3). **(e)** Validité simultanée sur le temps et sur toutes les hypothèses engendrées, sans correction par hypothèse : « this holds uniformly over time and generated hypotheses » [P6, p. 4] (probabilité d'une fausse certification ≤ δ, proposition 1). **Occupée sous une autre forme** (contrôle de l'erreur par famille pour une famille ouverte, pas un taux de fausses découvertes). **(f)** Rien.
