 Anthropic's Claude on Google Cloud models

 Stay organized with collections

 Save and categorize content based on your preferences.

Note: Anthropic models are not a Google product, and their
availability in Gemini Enterprise Agent Platform is subject to the terms for "Separate
Offerings" in the AI/ML Services section of the Service Specific
Terms, and separate terms found
in the relevant model card.

The Anthropic Claude models on Google Cloud offer fully managed and
serverless models as APIs. To use a Claude model on Agent Platform, send
a request directly to the Agent Platform API endpoint. Because the Anthropic
Claude models use a managed API, there's no need to provision or manage
infrastructure. To use Anthropic's Claude developer platform on
Anthropic-managed infrastructure instead, see
 [lien: /gemini-enterprise-agent-platform/models/partner-models/claude/anthropic-managed] Use Claude models on Google Cloud (Anthropic managed).

You can stream your Claude responses to reduce the end-user latency perception.
A streamed response uses server-sent events (SSE) to incrementally stream the
response.

You pay for Claude models as you use them (pay as you go), or you pay a fixed
fee when using [lien: /gemini-enterprise-agent-platform/models/provisioned-throughput] provisioned throughput. For pay-as-you-go pricing,
see Anthropic Claude models on the Google Cloud pricing page.

Available Claude on Google Cloud models
Important: Accessing Claude on Google Cloud models through
Agent Platform meets the FedRAMP High requirements, and operates within
the Google Cloud FedRAMP High authorization boundary.

The following models are available from Anthropic to use in Gemini Enterprise Agent Platform. To
access a Claude on Google Cloud model, go to its Model Garden
model card.

Anthropic's Claude models support Agent Platform request-response
logging. Enable 30-day request-response logging of your prompt and completion
activity to track any model misuse by your users. For more information, see [lien: /gemini-enterprise-agent-platform/models/capabilities/request-response-logging] Log
requests and responses.

To log token counts, latency and errors for every Claude request without storing
prompts or responses, see [lien: /gemini-enterprise-agent-platform/models/capabilities/inference-metadata-logging] Log inference request metadata. For Claude
field names, see [lien: /gemini-enterprise-agent-platform/models/capabilities/inference-metadata-logging#claude-models] Token counts for Claude models.

Verify model enablement status

Partner model enablement is project-specific and managed through
Google Cloud Marketplace entitlements rather than a project-wide Agent Platform API
setting. For required roles and organization policies, see
 [lien: /gemini-enterprise-agent-platform/models/partner-models/use-partner-models#grant-permissions] Grant user access to partner models.

To verify whether a Claude model is enabled, select your project in the
Google Cloud console and open the model card in Model Garden:

If the model is enabled for the project, the model card displays usage
actions such as View code or Open notebook.

If the model isn't enabled for the project, the model card displays
Enable or Request access.

Listing enabled partner models for a project by using the Google Cloud CLI or
the Agent Platform API isn't supported. The
gcloud ai model-garden models list command lists the public
Model Garden catalog rather than filtering by
Cloud Marketplace entitlements for your project.
