# Politique du site LessWrong sur les textes écrits avec une intelligence artificielle — résumé v1

Tiré le 2026-11-18 par l'interface de données du site (requête et dates dans `provenance-v1.json` et `provenance-v1-suite.json`). Deux pages, enregistrées en HTML et en markdown ici même :
- « Policy for LLM Writing on LessWrong » (2025-03-24, contenu édité le 2026-03-24), `https://www.lesswrong.com/posts/KXujJjnmP85u8eM6B/policy-for-llm-writing-on-lesswrong` → `politique-ecriture-llm-lesswrong-v1.md` ;
- la page de 2025 renvoie elle-même à la politique en vigueur : « New LessWrong Editor! (Also, an update to our LLM policy.) » (2026-03-14, contenu édité le 2026-06-12), section « Policy on LLM Use », `https://www.lesswrong.com/posts/nQWavk9mnwcv6ScMR/new-lesswrong-editor-also-an-update-to-our-llm-policy` → `nouvel-editeur-et-politique-llm-v1.md`.

Le résumé suit la page de 2026, qui prime ; la section « Posts by AI Agents » de 2025 reste en vigueur selon la page de 2025 elle-même.

1. Ce qui compte comme production d'un modèle : le texte écrit par le modèle, le texte humain « substantially » révisé par un modèle, et le texte du modèle retouché par un humain — « text that was written by a human and then substantially […] edited or revised by an LLM » (renvoi de note ôté) (2026).
2. N'en sont pas : la retouche légère, les faits ou arguments trouvés avec un modèle mais rédigés par l'humain, et le code — « code (either in code blocks or in the new widgets) » (2026).
3. Toute production d'un modèle va dans les blocs dédiés : « "LLM output" must go into the new LLM content blocks. » (2026).
4. Une section repliable entièrement produite par un modèle peut se passer du bloc ; si elle est mélangée, les blocs marquent les parties produites (2026).
5. Contrôle automatique durci, mêmes règles pour les comptes approuvés que pour les nouveaux : « they'll be automatically rejected if they score above a certain threshold » (2026).
6. Pour les nouveaux comptes : « For first-time users, we have closer to a zero-LLM policy » (2026) ; « first-time writers are not permitted to use any AI text output » (2025).
7. Un billet fait surtout de blocs de modèle a peu de chances d'être accepté ; la barre de qualité ne change pas (2026).
8. Traduction : écrire dans sa langue puis demander au modèle « a direct word-for-word translation » sans réécriture (2026).
9. Garant humain : l'auteur doit « vouch for everything in the result » et n'inclure aucune information « that you can't verify » (2025, repris en citation en 2026 comme règle initiale).
10. Agents autonomes : un agent peut être coauteur, mais « The primary author of your posts/comments must be an existing human account » (2025, section maintenue).

Conséquence pratique pour nos billets (à trancher par Lazar, pas une décision) : tout passage rédigé ou fortement révisé par Claude doit soit être réécrit par Lazar, soit être placé dans un bloc déclaré ; le compte publiant doit être celui de Lazar ; le premier billet d'un compte neuf tombe sous la règle quasi nulle.
