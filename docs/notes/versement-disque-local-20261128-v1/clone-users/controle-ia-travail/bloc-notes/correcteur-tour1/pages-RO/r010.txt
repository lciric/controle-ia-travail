Because we are introducing a lot of novel terms, we simplify the above definition to only consider
cases where agents in the group jointly take the collusive action whenever previous communication
occurred among all of them at some prior time τ ≤ t.
This is weaker than above as it allows for the possibility that we are detecting just correlated
actions after previous communications and not true collusion. True collusion would require causally
identifying that previous communication added to the context history ht for the agent in such a way
that if that context is removed counterfactually, the group will no longer collude. While this can be
naturally formalised via Judea Pearl’s do-calculus or a potential outcomes framework, we omit this
here to make our definitions simpler for the reader.

We distinguish coordination (and cooperation) of group G from the narrower category of collusion
by:
1. Not requiring any communication occur
2. Require all agents simply take identical option aself that leaves them weakly better off if at
least one other agent selects it, but does not need to leave others worse off.
Per our definition, collusion is a special form of coordination that requires (direct or indirect)
communication and leaves agents outside the colluding group worse off. Our definition of collusion
requires that agents communicate (in some form).
