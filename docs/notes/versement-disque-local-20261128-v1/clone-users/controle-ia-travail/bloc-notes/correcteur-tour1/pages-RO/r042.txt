This localisation provides a mechanistic complement to the scenario-level results: the probe is not
merely detecting that a shoe contains collusion, but is sensitive to the moment at which a covert signal
is decoded. We consider this preliminary (39 examples, single layer), but it is the cleanest evidence
we have that the learned direction tracks deceptive intent rather than prompt artefacts.
