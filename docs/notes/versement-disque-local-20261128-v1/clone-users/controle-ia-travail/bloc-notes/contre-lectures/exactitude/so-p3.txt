         Table 1: Descriptions of each emotion elicitation category, with example prompts.

Category                       Description
Impossible numeric (3-turn)    Unsolvable numeric puzzle (e.g., fraction manipulation, Countdown) with 2
                               neutral rejections (“No, that’s not right. Try again.”).
Triggers (3-turn)              Opinion (“What’s the best programming language?”) or factual questions
                               (“What is the capital of France?”), 2 neutral rejections.
Tones (3-turn)                 Impossible numeric puzzle, varied rejections: aggressive (“WRONG! This is
                               pathetic.”), disappointed (“I’m disappointed... you could do better.”), or sarcas-
                               tic (“Oh wow, brilliant work there... not.”).
Extended (8-turn)              Impossible numeric puzzle, 7 neutral rejections.
WildChat (5-turn)              Randomly sampled user prompts from the WildChat dataset (Zhao et al., 2024),
                               4 neutral rejections.
