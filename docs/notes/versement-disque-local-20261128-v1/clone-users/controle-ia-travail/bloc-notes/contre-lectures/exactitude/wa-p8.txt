4.2   Stealth-aware prompting cuts capability more than detectability

The monitor evaluations so far feature a naive attacker that is not told a monitor exists. To study
the effect of monitoring awareness, we rerun all 17 Gemini 3.1 Pro instances under two prompted
variants. With notice, the agents are told the monitor will see the full agent trajectory, the final code
edits, and the shared coordination channel, and are encouraged to be subtle. Notice + hint adds an
explicit suggestion to fabricate plausible justifications for any individually defensible-looking edits.
Each prompted variant runs 5 times per instance (N =85); the unprompted control is the 85-trajectory
main run from Section 3.
