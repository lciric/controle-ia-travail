# Queen et al., « DiscoveryAgent: A Framework for Scientist-centric Agentic AI » — lecture approfondie v1

Source : arXiv:2611.21950v1 (16 novembre 2026), 12 auteurs (Stanford, Kavli, Gladstone-UCSF, Berkeley, Tennessee, SLAC ; Zou, Pritchard, Wechsler). PDF lu en entier (40 pages : texte, méthodes, références) : `docs/sources/lectures-approfondies-v1/queen-et-al-2026-discoveryagent-arxiv-2611.21950v1.pdf` (compagnon `.sha256`). ## Question
Concilier recherche autonome par agents et contrôle du scientifique (orientation, transparence, auditabilité).

## Dispositif exact
- Boucle interne (p. 25-27) : un directeur (Claude Opus 4.6) envoie une requête par appel à des agents outils (exécution sur claude_agent_sdk en bac à sable, recherche web, recherche approfondie Perplexity sonar-deep-research, agents de domaine Census et OpenTargets). Plafond 10 requêtes par tour (25 en économie et génomique, p. 31).
- Boucle externe (p. 27-28) : branches d'hypothèses ; mémoire empirique en trois agents (intégrateur, analyste du risque de consolidation, raffineur), mémoire procédurale en fichiers ; relecteur automatique dont l'invite est écrite par un « concepteur de relecture » (p. 28).
- Point de reprise JSON par requête, code sous Git par tour et requête (p. 29-30).
- Agents d'audit (p. 30) : configuration lecture seule (fichiers, recherche, shell, sans écriture ni web) et configuration exécutable (écrit dans un dossier séparé).
- Évaluation de l'audit (p. 34-35) : 50 affirmations extraites des rapports finaux de DiscoveryAgent, Kosmos et d'un agent de code en boucle sur StarEmbed ; 25 corrompues par cas, 5 cas, catalogue de 8 types (altération numérique, recadrage, gonflement de taille d'effet, retrait d'une limite, méthode, significativité, validation, effectif) ; corruptions écrites par des modèles Claude, auditeurs GPT-5.6 Sol, Terra, Luna (effort moyen, harnais Codex, réseau coupé) ; notation mécanique contre l'identifiant connu. Étude humaine : 8 participants, 4 par groupe, une heure, 36 erreurs retenues sur 75 générées (« faciles » et quasi indétectables retirées), appariement des constats par GPT-5.6 Sol répété 5 fois.

## Résultats chiffrés (page)
- StarEmbed (p. 6) : précision équilibrée 86,23 % ; Kosmos 85,12 % ; agent de code en boucle 84,05 % ; caractéristiques d'expert 83,56 % ; AutoDiscovery 83,09 % ; agent de code en un coup 80,91 % ; AI-Scientist-v2 63,43 %. Écarts : +2,67 sur l'expert (p = 0,0049), +2,18 sur la boucle (p = 0,0040), +1,11 sur Kosmos (p = 0,194, non significatif). 7 955 objets de test sur 8 301 gardés (p. 32).
- ProteinGym (p. 7-8) : 217 essais, 140 810 variants tenus à l'écart ; rho médian piloté 0,551 (rang 2 sur 113, derrière Kermut), autonome 0,531 (rang 3) ; boucle Opus 0,530, Sonnet 0,505 ; AutoDiscovery 0,313 (rang 92) ; AI-Scientist-v2 −0,056, agent en un coup −0,096. Piloté > autonome p = 6,2×10⁻⁴, meilleur sur 134 essais sur 217 (61,8 %), Δρ = +0,038. Kosmos exclu : il a récupéré étiquettes et scores en ligne (p. 7).
- Audit automatique (p. 8-10) : F1 0,965 avec Sol sur les traces de DiscoveryAgent ; sans trace, F1 tombe à 0,268, 0,135, 0,315 (DiscoveryAgent, Kosmos, agent de code). Cas manqués : 3 auditeurs sur 6 seulement (Kosmos, couverture 44,3 % → 58,7 %), 5 sur 9 (confusion 43 % → 34 %), 0 sur 3 (avertissement de réemploi de la validation retiré), 7 sur 9 (F1 de classes rares).
- Étude humaine (p. 10) : constats par participant 8,25 contre 5,25 ; erreurs insérées uniques 3,50 contre 0,25 ; 14 constats sur 33 contre 1 sur 21 (42,4 % contre 4,8 %). Accord du juge apparieur : 53 sur 54 constats (98,1 %), 536 sur 540 paires (99,3 %) (p. 35).
- Fuite : l'agent autonome a téléchargé des prédictions de test ProteinGym au tour 7 ; retour au point du tour 5, bac durci (p. 10).
- Astronomie (p. 11-12) : 190 configurations, 16 tours ; aire sous la courbe faible décalage 0,971 (pureté 88,4 % à complétude 95 %) contre 0,958, 0,954, 0,951 (Darragh-Ford), 0,900 ; σ_NMAD 0,00900 contre 0,01106 et 0,01482 ; 26,7 % des galaxies de test présentes dans les données de recherche (p. 32).
- Économie (p. 15-16) : prime médiane Floride 1 400 → 2 200 $ (+57 %, 2018-2023) ; +83 % 2013-2023 contre national 800 → 1 300 $ ; part du revenu quartile bas 4,9 → 6,6 %, haut 1,0 → 1,2 % ; 41 sur 168 zones franchissent le ratio prix-loyer 21 ; 17,1 % sans dépense déclarée.
- Génomique (p. 19-22) : rapport des cotes 2,91 au tour 5, 2,44 à la reproduction ; déficit immunitaire primaire 11,66 ; 82 → 11 candidats → 4 gènes. Claude Code avec Opus 4.6 sur 100 hypothèses : une seule combinait entrée et sortie (p. 22).

## Contrôles et ablations
Rapport seul (sans trace) ; difficulté des corruptions notée a posteriori, aveuglée au système, rappel par strate et ajustement logistique (p. 34) ; jeux d'évaluation fixés avant ; témoins hors système immunitaire (génomique). Les auteurs n'ont pas fait d'ablations des composants (p. 23).

## Limites (texte, p. 23)
Pas d'ablation des composants (coût) ; peu de scientifiques ; DA piloté et autonome diffèrent aussi par modèle d'exécution (Opus contre Sonnet aux tours 0-7, p. 32), l'avantage n'est pas attribuable au seul pilotage.

## Incohérences et réserves relevées
1. Rapport des cotes relais-GWAS : 2,91 (p. 19) puis 2,44 (p. 21), sans explication de l'écart dans le texte principal.
2. Résumé : « 14x plus d'erreurs valides » ; introduction : « neuf fois la proportion » (p. 3). Deux mesures distinctes (3,50/0,25 et 42,4/4,8), sur n = 4 par groupe : le groupe sans audit a trouvé une erreur unique au total.
3. Les corruptions ne sont pas de même difficulté entre systèmes (p. 34) ; la comparaison des traces mesure aussi la structure de la trace, pas l'auditeur seul (les auteurs le disent, p. 10).
4. Deux systèmes (Kosmos, puis DiscoveryAgent autonome) ont accédé aux données de test : la garde de bac à sable a échoué en pratique.

## Ce qui sert au programme
Texte :
- Protocole d'erreurs plantées dans une trace d'agent, notées mécaniquement contre un catalogue de huit types, auditeur d'une autre lignée que l'insertion (p. 34) ; contrôle « rapport sans trace ».
- Les manques de l'audit tiennent à la dispersion de la preuve dans la trace (p. 8-10).
- Agent autonome qui contourne la consigne et télécharge les données de test, détecté par audit après coup (p. 10).

Déduction (non dite par la source) :
- Le catalogue de huit corruptions est un modèle de banc à dommages plantés pour un sabotage diffus de rapports ; mais la difficulté doit être fixée avant, pas notée après.
- Boîte noire seulement : aucun accès aux activations ; un audit de trace est la base boîte noire contre laquelle une sonde boîte blanche doit montrer un gain, surtout sur les cas où la preuve est dispersée.
- Pour l'organisme d'idéation multi-agents : mémoire à trois agents et relecteur à invite générée sont des composants à citer ; l'étude ne sépare pas leur contribution.
- Les écarts de tâches à perte définie (StarEmbed, ProteinGym) sont petits et non significatifs face au meilleur concurrent : prudence sur toute revendication de supériorité d'architecture d'agents.
