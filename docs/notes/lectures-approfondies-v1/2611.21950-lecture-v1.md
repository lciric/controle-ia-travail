## Question
Concilier recherche autonome par agents et contrôle du scientifique (orientation, transparence, auditabilité).

## Dispositif exact
- Boucle interne (p. 25-27) : directeur Claude Opus 4.6, une requête par appel à des agents outils (code en bac à sable sur claude_agent_sdk, web, Perplexity sonar-deep-research, agents Census et OpenTargets) ; 10 requêtes par tour (25 en économie et génomique, p. 31).
- Boucle externe (p. 27-28) : branches d'hypothèses ; mémoire empirique à trois agents (intégrateur, analyste du risque de consolidation, raffineur) ; relecteur automatique dont l'invite est écrite par un « concepteur de relecture ».
- Point de reprise par requête, code sous Git (p. 29-30) ; agents d'audit en lecture seule ou exécutables (p. 30).
- Évaluation de l'audit (p. 34-35) : 50 affirmations extraites des rapports de DiscoveryAgent, Kosmos et d'un agent de code en boucle (StarEmbed) ; 25 corrompues par cas, 5 cas, 8 types (altération numérique, recadrage, gonflement d'effet, limite retirée, méthode, significativité, validation, effectif) ; corruptions écrites par Claude, auditeurs GPT-5.6 Sol, Terra, Luna (réseau coupé) ; notation mécanique. Étude humaine : 8 participants (4 par groupe), une heure, 36 erreurs gardées sur 75 (faciles et indétectables retirées).

## Résultats chiffrés (page)
- StarEmbed (p. 6) : précision équilibrée 86,23 % ; Kosmos 85,12 % ; boucle de code 84,05 % ; experts 83,56 % ; AutoDiscovery 83,09 % ; AI-Scientist-v2 63,43 %. Écarts : +2,67 sur les experts (p = 0,0049), +2,18 sur la boucle (p = 0,0040), +1,11 sur Kosmos (p = 0,194, non significatif).
- ProteinGym (p. 7-8) : 217 essais, 140 810 variants ; rho médian piloté 0,551 (rang 2 sur 113), autonome 0,531 (rang 3) ; boucle Opus 0,530 ; AutoDiscovery 0,313 ; AI-Scientist-v2 −0,056. Piloté > autonome p = 6,2×10⁻⁴, Δρ = +0,038, 134/217 essais. Kosmos exclu : il a récupéré étiquettes et scores en ligne.
- Audit (p. 8-10) : F1 0,965 avec Sol sur traces de DiscoveryAgent ; rapport seul : 0,268, 0,135, 0,315 (DiscoveryAgent, Kosmos, boucle). Cas manqués : 3 auditeurs sur 6 (couverture 44,3 % → 58,7 %), 5 sur 9, 0 sur 3 (avertissement retiré), 7 sur 9.
- Humains (p. 10) : constats 8,25 contre 5,25 ; erreurs insérées uniques 3,50 contre 0,25 ; 14/33 contre 1/21 (42,4 % contre 4,8 %). Juge apparieur : 53/54 (98,1 %), 536/540 paires (p. 35).
- Fuite : l'agent autonome a téléchargé des prédictions de test au tour 7 ; retour au tour 5, bac durci (p. 10).
- Astronomie (p. 11-12) : aire 0,971 contre 0,958 et 0,951 (Darragh-Ford) ; σ_NMAD 0,00900 contre 0,01106 ; 26,7 % des galaxies de test dans les données de recherche (p. 32).
- Économie (p. 15-16) : prime médiane Floride 1 400 → 2 200 $ (+57 %, 2018-2023) ; 41/168 zones au-delà du ratio 21.
- Génomique (p. 19-22) : rapport des cotes 2,91 puis 2,44 à la reproduction ; 82 → 11 → 4 gènes ; Claude Code sur 100 hypothèses : une seule combinait entrée et sortie.

## Contrôles
Rapport sans trace ; difficulté des corruptions notée a posteriori, aveugle au système, rappel par strate (p. 34) ; jeux d'évaluation fixés avant ; témoins hors système immunitaire. Aucune ablation des composants (p. 23).

## Limites (texte, p. 23)
Pas d'ablation (coût) ; peu de scientifiques ; piloté et autonome diffèrent aussi par modèle d'exécution (Opus contre Sonnet, p. 32).

## Incohérences et réserves relevées
1. Rapport des cotes 2,91 (p. 19) puis 2,44 (p. 21), écart non expliqué dans le texte principal.
2. Résumé « 14x plus d'erreurs valides », introduction « neuf fois la proportion » (p. 3) : deux mesures, n = 4 par groupe ; le groupe sans audit a trouvé une erreur unique au total.
3. Difficulté inégale des corruptions entre systèmes (p. 34) : la comparaison des traces mesure aussi la structure de la trace.
4. Deux systèmes ont accédé aux données de test : la garde de bac à sable a échoué en pratique.

## Ce qui sert au programme
Texte : erreurs plantées dans une trace d'agent, notées mécaniquement contre un catalogue de huit types, auditeur d'une autre lignée que l'insertion (p. 34) ; contrôle « rapport sans trace » ; les manques tiennent à la dispersion de la preuve (p. 8-10) ; contournement de consigne détecté après coup (p. 10).

Déduction : le catalogue de huit corruptions modèle un banc à dommages plantés pour sabotage diffus de rapports, à difficulté fixée avant, pas notée après. Audit de trace = base boîte noire contre laquelle une sonde boîte blanche doit montrer un gain, surtout quand la preuve est dispersée. Pour l'organisme d'idéation : mémoire à trois agents et relecteur à invite générée sont à citer, leur contribution non séparée. Sur tâches à perte définie, les écarts au meilleur concurrent sont petits et non significatifs.
