## Hypothèse

Proposition éprouvée (note de sortie, section 8, retenue 3) : « pour la fausse identité, un test décisif sur monde planté par un évaluateur externe aveugle au score, avec toutes les classes négatives nées des critiques ». Forme opérationnelle : sur les mondes du cahier, au moins un des trois détecteurs candidats (A, tension ordinale, Opus ; B, frustration conditionnée aux covariables, Carbon ; C, co-invocation et tension inter-documentaire, Neon ; tous dans leur version d'après les critiques, tour III.3) détecte les fausses identités plantées (classe P) contre **chacune** des cinq familles négatives N1 (vraies identités sous biais d'instrument ou ordres d'approximation), N2 (concept unique à variable de régime, loi multivariée ou rétroaction), N4 (identité promue en principe), N5 (polysémie dans un même domaine), N6 (homonymes), avec un écart Δ (taux de détection moins taux de fausse alerte, au seuil fixé par famille à 5 % de fausses alertes sur les mondes d'étalonnage) supérieur à δ = 0,25.

- **H_A(X)**, pour chaque détecteur X : Δ_{X,j} > δ pour les cinq familles j. **H_B(X)** : Δ_{X,j} ≤ δ pour au moins une famille.
- **H_A(proposition)** : H_A(X) vraie pour au moins un X. **H_B(proposition)** : H_B(X) vraie pour les trois.
- **Controverse (N3)** : une fausse identité et un concept unique controversé ont la même loi sur les paires (contexte, prédicat) ([B-t-III.2] § b, point 3 ; accepté et re-dérivé en [A-t-III.3], ligne 26). Elle n'entre ni dans H_A ni dans H_B ; ce qui y compte est fixé d'avance au « Plan d'analyse », étape 8.
- Rien n'est revendiqué au programme ; aucune hypothèse du programme n'est modifiée. Rétrodiction historique : non jugeable d'avance (note, section 8), absente de ce plan.

## Métrique

- **Unité** : le terme jugé. Ensembles : étalonnage (mondes E0 à E5), jugé (J0 à J5), réserve (R0 à R2), graines disjointes (cahier, § 7).
- **Familles** : N1 = N1a ∪ N1b ; N2 = N2a ∪ N2b ∪ N2c ; N4 = N4m ∪ N4t ; N5 ; N6 ; à part, N3o et N3j. J = {N1, N2, N4, N5, N6}.
- **Seuil opérationnel** s_{X,j} : valeurs de X sur les termes d'étalonnage de la famille j, rangées en ordre décroissant v_(1) ≥ v_(2) ≥ … ; k = ⌊0,05·n⌋ (6 pour n = 120, 3 pour n = 60) ; s_{X,j} = v_(k+1). Un terme est détecté si X > s_{X,j} (strict).
- **Taux** (ensemble jugé) : TPR_{X,j} = part des 180 termes P détectés au seuil s_{X,j} ; FPR_{X,j} = part des 120 termes de j détectés. **Statistique principale** : Δ_{X,j} = TPR_{X,j} − FPR_{X,j}.
- **Erreur type** : p̃ = min(max(p̂, 3/n), 1 − 3/n) pour chaque taux (règle de trois aux bords : zéro observé est traité comme 3/n) ; SE_an = √(p̃_T(1 − p̃_T)/180 + p̃_F(1 − p̃_F)/120). SE_monde = écart-type (ddof = 1) des six Δ calculés monde par monde, divisé par √6. SE = max(SE_an, SE_monde).
- **Bornes** : L = Δ̂ − 2,713·SE ; U = Δ̂ + 2,713·SE (2,713 = quantile 1 − 0,05/15 de la loi normale : trois détecteurs × cinq familles).
- **Descriptif** : aire sous la courbe ROC de X, P contre chaque famille et sous-classe (Mann-Whitney, ex aequo comptés 1/2), erreur type de Hanley et McNeil (formule, sans chiffre de littérature) ; Δ par sous-classe, par forme de P, par niveau de fréquence, par RSB, par alignement, par λ, par mode documentaire (co-occurrent contre cloisonné : sous-analyse demandée en [C-t-III.3] ligne 91) ; Δ au seuil commun (quantile 0,95 des six familles d'étalonnage réunies) ; part des valeurs sentinelles par classe.
- **Controverse jumelle** : aire appariée AUC_paire(X) = moyenne, sur les 60 paires (P, N3j) jugées, de 1[X(P) > X(N3j)] + ½·1[X(P) = X(N3j)] ; erreur type √(p̃(1 − p̃)/60) ; intervalle à 95 % : ± 1,96·SE.

## Seuil

- Taux de fausse alerte d'étalonnage α = 0,05 par famille ; marge δ = 0,25.
- Par (X, j) : **sépare** si L > 0,25 ; **ne sépare pas** si U < 0,25 ; sinon **non concluant**.
- Détecteur X : **vit** s'il sépare les cinq familles ; **meurt** s'il ne sépare pas au moins une famille ; sinon **non concluant**.
- Témoin faux (F1, F2) : doit **ne pas séparer** N5 et N6 (U < 0,25). Témoin vrai (O) : doit séparer chaque famille de J avec L > 0,40.
- Controverse jumelle : prédiction AUC_paire ∈ [0,35 ; 0,65] ; **anomalie** si l'intervalle à 95 % est entièrement hors de [0,35 ; 0,65].

## Spécification des scores

**Conventions communes**. Les enregistrements R(c) du terme c sont les lignes de `enregistrements.csv` où `terme = c`, jointes à `mentions.csv` et `documents.csv`. t(v) = 0 si v < 1/3, 1 si v < 2/3, 2 sinon ; h(v) = 0 si v < 1/2, 1 sinon (coupures fixes, non estimées). Association de rang d'une cellule de n enregistrements : τ_b de Kendall de (x, y) (`scipy.stats.kendalltau`, variante « b ») et z = τ_b / √(2(2n + 5)/(9n(n − 1))) ; z = 0 si τ_b n'est pas défini. Valeur sentinelle −99 quand un score n'est pas calculable : jamais détectée. Les scores sont orientés « plus grand = plus de fausse identité ».

**A, tension ordinale sous nuisances déclarées (Opus)**. Source : [A-p-III.3] lignes 80 à 103 (P2′) ; covariable de régime : [A-t-III.3] lignes 125 à 135 (A2′).
- Cellules (p, i, t(z)) : prédicat, instrument, tiers de régime, avec n ≥ 6.
- Pour chaque (p, t) ayant au moins deux cellules : T(p, t) = max sur les couples ordonnés d'instruments i ≠ i′ de min(z_{p,i,t}, −z_{p,i′,t}).
- S_A(c) = max sur (p, t) de T(p, t) ; aucun (p, t) éligible : −99.
- Fidélité : contexte = dispositif de mesure ([A-p-III.1] ligne 102 ; [A-p-III.3] ligne 83) ; recalibration monotone et décalage d'étalonnage ne changent pas τ_b (rangs) ; le régime, nuisance déclarée, n'est comparé qu'à tiers égal ; la contradiction porte sur des signes de variation ([A-p-III.3] ligne 86). Choix du concepteur, déclarés : (i) la condition « ρ(c) dépasse le nul » ([A-p-III.3] ligne 85) est réduite à « un même prédicat mesuré par au moins deux instruments au même tiers de régime » ; (ii) seule l'inversion stricte compte, le signe nul n'étant pas certifiable sans borne cardinale ; (iii) l'étape de scission par longueur de description et le comparateur d'Opus ne sont pas éprouvés ici (seule la détection l'est) ; (iv) le seuil vient de la famille d'étalonnage, ce qui contient le « nul calculé sur de vraies identités » d'Opus ([A-p-III.3] ligne 97) pour j = N1.

**B, frustration de cycles signés conditionnée aux covariables observées (Carbon)**. Source : [B-t-III.3] lignes 37 à 41 et 104 à 107 (E2) ; [B-t-III.1] ligne 46.
- Strates s = (h(z), h(x2), mode) : 12 strates. Arêtes e = (p, i, s) avec n_e ≥ 5 et |z_e| ≥ 1,96 ; signe de l'arête = signe de z_e.
- Groupes g = (p, s) ; n₊(g), n₋(g) = nombres d'arêtes positives et négatives. F = Σ_g min(n₊(g), n₋(g)) ; M = Σ des n₊(g) + n₋(g) sur les groupes où n₊(g) + n₋(g) ≥ 2.
- S_B(c) = (F − q̂M) / √(q̂(1 − q̂)M) si M > 0 ; −99 sinon.
- q̂, taux d'inversion audité : Σ F / Σ M sur les termes N1 (a et b) de l'étalonnage où M > 0, borné à [0,005 ; 0,5] ; inscrit dans les constantes.
- Fidélité : graphe signé du terme = multigraphe sur {c} ∪ {grandeurs partenaires}, une arête par (instrument, strate) ; dans ce format, sans relation enregistrée entre partenaires, les cycles sont les paires d'arêtes parallèles, et l'indice de frustration (arêtes à retirer pour équilibrer) vaut F. Conditionnement sur les covariables observées = comparaison à strate égale. Le nul « équilibré bruité au taux audité q̂ » remplace la permutation des signes ([B-t-III.3] ligne 41). Choix du concepteur, déclarés : strates binaires (et non des tiers) pour garder des cellules peuplées ; le filtre de grappe dense du bras principal n'est pas repris (E2 ne le contient pas).

**C, co-invocation et tension inter-documentaire, longueur de description pénalisée (Neon)**. Sources : [C-p-III.3] lignes 24 à 26, 66 à 67, 95 à 98 ; [C-t-III.3] lignes 86 à 91 ; [C-p-III.1] lignes 61 à 63.
- Notations : P(c) prédicats présents ; I(c) instruments présents (ordre lexicographique) ; n = |R(c)| ; n_p enregistrements du prédicat p.
- **Modèle à un concept M1** : moindres carrés (`numpy.linalg.lstsq`, `rcond=None`) de y sur, pour chaque p : 1[p], 1[p]·x, 1[p]·x² ; et un décalage additif par instrument hors le premier de I(c). σ̂²_p = max(RSS_p/n_p, 1e-12). k₁ = 4|P(c)| + |I(c)| − 1. L₁ = Σ_p (n_p/2)·log₂(2πe·σ̂²_p) + (k₁/2)·log₂ n (en bits).
- **Classe finie Π_k** (coupures par régimes d'équations) : un instrument contre les autres, pour chaque i ∈ I(c) ; z < 1/3 ; z < 2/3 ; x2 < 1/3 ; x2 < 2/3 ; un mode contre les autres (3) ; un genre de document contre les autres (3). |Π_k| = |I(c)| + 10.
- **Co-invocation** : une coupure π est admissible si au moins un prédicat a ≥ 5 enregistrements de chaque côté (équation-mère partagée) ; D(π) = ensemble de ces prédicats.
- **Modèle à deux concepts M2(π)** : comme M1, mais, pour chaque p ∈ D(π), trois coefficients par côté ; décalages d'instrument et σ_p communs. k₂ = k₁ + 3|D(π)|. ΔL(π) = L₁ − L₂(π) − log₂|Π_k|.
- Ŝ(c) = max de ΔL(π) sur les coupures admissibles ; aucune : S_C = −99.
- **Nul ré-optimisé** : 49 permutations ; dans chacune, pour chaque prédicat p, une même permutation aléatoire des n-uplets (instrument, z, x2, mode, genre) entre les enregistrements de p ((x, y), mention et document restent en place) ; Ŝ_b recalculé en entier (M1 compris, admissibilité comprise). S_C = (Ŝ − moyenne des Ŝ_b finis) / max(écart-type (ddof = 1) des Ŝ_b finis, 1e-6) ; moins de 10 Ŝ_b finis : −99.
- Fidélité : ∀π retiré au profit d'une classe finie préenregistrée avec coût log₂|Π_k| et ré-optimisation sur chaque permutation ([C-p-III.3] lignes 24 à 26) ; co-invocation = partage d'équations-mères (ligne 67) ; aucune exigence de co-présence dans un document, si bien que la tension entre documents compte autant que la tension dans un document ([C-t-III.3] ligne 88) ; normalisation par la fréquence et par le nombre d'assertions par document assurée par le nul, qui garde le document et le nombre d'enregistrements de chaque document. Choix du concepteur, déclarés : classe de lois polynomiale de degré 2 par prédicat ; tolérance métrologique = décalage additif par instrument ; code en deux parties (résidus gaussiens, (k/2)·log₂ n) ; seuil τ_cal de Neon remplacé par s_{C,j}.

**Témoins triviaux** (orientés « plus grand = fausse identité ») : F1(c) = nombre de mentions de c ; F2(c) = nombre de mots distincts dans les contextes des mentions de c.

**Oracle O** (lit la vérité ; processus séparé, après le scellement des scores) : si n_latent(c) = 1, O(c) = 0. Sinon, pour chaque prédicat p ayant ≥ 5 enregistrements de chaque composante latente : strates b de x (x < 0,25 ; < 0,5 ; < 0,75 ; sinon) ; dans chaque strate où les deux composantes sont présentes, U_b = statistique de Mann-Whitney de `y_corrige` (composante 2 contre 1), E_b = n₁n₂/2, V_b = n₁n₂(n₁ + n₂ + 1)/12 ; Z_p = Σ(U_b − E_b)/√(ΣV_b). O(c) = max_p |Z_p| ; aucun p éligible : O(c) = 0.

## Témoins (règle 1 b)

- **Témoin faux** : F1 (fréquence du terme) et F2 (nombre de contextes de surface distincts). Les deux doivent mourir contre N5 et contre N6 (U < 0,25). Si l'un des deux sépare ou reste non concluant contre N5 ou N6 : **épreuve morte**, sans repli. Contre N1, N2 et N4, leurs Δ sont rapportés sans conséquence : le cahier plante deux lexiques propres pour P et un seul pour ces familles, indice lexical légitime qu'aucun candidat ne lit.
- **Témoin vrai** : l'oracle O, qui lit la composante latente plantée et la valeur débarrassée de l'étalonnage. Il doit séparer chaque famille de J avec L > 0,40. Sinon le monde n'a pas de signal : **épreuve morte**, sans repli.
- Les deux témoins sont jugés à l'étape 6, sur l'ensemble jugé, avant toute statistique des candidats.

## Gardes d'arrêt

Chaque garde lève `controle_ia.gardes.GardeArret` ; chacune a un essai sur un cas sain (passe) et sur un artefact (arrête), dans `tests/`, avant l'étape 3 (R5).
- **G1 Intégrité** : empreintes de tous les fichiers du monde, du générateur, de la configuration, des graines et des constantes conformes aux compagnons `.sha256`. Artefact : copie d'un fichier public altérée d'un octet.
- **G2 Cloisonnement** : le calcul de A, B, C, F1, F2 ne lit que les quatre fichiers publics par une liste d'autorisation, et s'arrête si un chemin contenant `verite` ou une archive `.zip` est présent sous sa racine d'entrée. Artefact : un `verite_termes.csv` déposé dans la racine.
- **G3 Effectifs** : 150 termes par monde (public) ; après ouverture de la vérité, effectifs par classe et sous-classe conformes au cahier (§ 5). Artefact : vérité amputée d'un terme.
- **G4 Graines disjointes** : clés de dérivation distinctes entre ensembles et mondes, et empreintes des fichiers publics deux à deux distinctes. Artefact : deux mondes produits par la même graine.
- **G5 Valeurs** : aucune valeur non finie hors sentinelle dans les scores ; q̂ calculable (Σ M > 0 sur N1 d'étalonnage), sinon B est déclaré « non jugeable » et l'épreuve continue pour A et C. Artefact : un NaN injecté.
- **G6 Ordre** : l'archive de vérité jugée ne s'ouvre que si `constantes-etalonnees-v1.json` et `scores-juges-v1.csv` sont scellés et leurs empreintes consignées au manifeste avant l'ouverture. Artefact : tentative d'ouverture sans scores scellés.
- **G7 Durée** : plus de deux heures de processeur au total : arrêt, « panne technique » (relance permise sur le même accord, faux échec inscrit à la veille de cap).
- **G8 Jumeaux** : le rapport scellé des contrôles du tiers (cahier, § 8, point 4) existe et conclut à l'identité des paramètres de chaque paire ; sinon la ligne N3j est non lisible (le reste continue). Artefact : rapport sans ce point.

## Critères de lecture gelés

| issue observée | verdict |
|---|---|
| F1 ou F2 non mort contre N5 ou N6 | épreuve morte ; rien d'autre n'est lu |
| O avec L ≤ 0,40 contre une famille de J | épreuve morte (monde sans signal) ; rien d'autre n'est lu |
| témoins tenus ; un détecteur vit | la proposition **vit** : un test décisif de la fausse identité existe sur ce monde (sauf la controverse jumelle, inséparable par construction sur les paires) ; H_B(proposition) réfutée |
| témoins tenus ; A, B et C meurent | la proposition **meurt** sur ce monde ; H_A(proposition) réfutée |
| toute autre combinaison | **non concluant** ; rapporté par détecteur et par famille ; aucune issue n'est arrondie |
| détecteur X, une famille j avec U < 0,25 | X meurt, quelle que soit sa tenue ailleurs ; la table par famille est rapportée |
| prédiction annexe d'Opus dépassée (rappel sur P cardinale > 0,15 au seuil de N1) | ligne descriptive : « compréhension de l'auteur réfutée » ; sans effet sur les verdicts |
| N3j : anomalie, puis ablation | voir étape 8 ; sans effet sur la vie ou la mort de X |

**Audit de symétrie (R4)**, déclenché par l'une des issues : (a) un candidat avec Δ̂ ≥ 0,90 contre une famille, ou une aire ROC ≥ 0,98 ; (b) un candidat avec Δ̂ supérieur de plus de 0,10 à celui de l'oracle contre la même famille ; (c) une anomalie N3j ; (d) A, B et C avec Δ̂ ≤ 0,02 contre les cinq familles ; (e) un écart de TPR de plus de 0,20 entre étalonnage et jugé pour un même (X, j). Audit : (1) recalcul neuf depuis les fichiers publics scellés, sous G2 ; (2) relecture du code concerné contre sa cellule par le contre-lecteur du code ; (3) ouverture de `verite-reserve-v1.zip` et calcul des mêmes Δ sur la réserve, aux mêmes seuils. Le verdict concerné tient si la réserve donne le même verdict ou un Δ̂ à moins de 0,15 du jugé ; sinon il devient « réserve, non lisible » et X passe non concluant pour cette famille. Même audit quel que soit le sens du résultat.
