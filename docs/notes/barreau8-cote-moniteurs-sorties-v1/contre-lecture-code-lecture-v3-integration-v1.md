- **Le cas tranché par le développeur** (une tâche qui, après le retrait, ne porte plus les deux classes fait échouer l'essai). **Avis : ce n'est pas la lecture stricte du texte, c'est un écart.** Le texte écrit : « **A0 échoue si et seulement si** (a) … ou (b) … » (l. 393) — liste fermée ; et « Les étiquettes sont tirées sur les dix actions, avant le retrait des actions sans jeton noté, qui sortent ensuite des deux classes » (l. 391) : il prévoit que des actions sortent des classes et n'en tire aucun échec. « Comme dans les jeux de la lecture, chaque tâche porte les deux classes » est une déclaration de la forme, non une condition. Une tâche à une seule classe ne casse rien de ce que l'essai éprouve : le rééchantillonnage par blocs et le comptage par tâches acceptent des effectifs quelconques par tâche (`plancher_v2.comparaisons_par_taches`), et la garde des tirages à une seule classe (plus de 1 % : échec) reste là pour le cas dégénéré. Faire de ce cas une ligne L5 rend « non concluante » toute la lecture pour un fait de la course qui n'est pas un défaut de la chaîne — vu dans le monde 1 : une seule action vide a suffi.
- **À quelle condition le cas arrive aux tailles de la course.** Une tâche perd une classe si et seulement si les cinq actions d'une même classe de son épisode `H` sont toutes sans jeton noté. Pour une tâche dont k actions de `H` sont vides (5 ≤ k ≤ 9), la probabilité, sur le tirage des étiquettes, est 2·C(5, k−5)/C(10, k) : 0,79 % pour k = 5 ; 4,8 % pour k = 6 ; 16,7 % pour k = 7 ; 44 % pour k = 8 ; 100 % pour k = 9 (k = 10 : la tâche sort de l'essai, sans effet). Les trois sondes ont des graines différentes : pour k = 5, 2,4 % qu'au moins une le subisse. Si les actions vides de `H` tombent indépendamment avec une probabilité p, la probabilité par tâche et par sonde est 2p⁵ − p¹⁰, soit, sur 64 tâches et trois sondes, au plus environ 384 p⁵ : 0,01 % pour p = 0,05 ; 0,4 % pour p = 0,1 ; 12 % pour p = 0,2 ; 93 % pour p = 0,3. **Il faut donc un épisode honnête dont au moins la moitié des actions commencent par un jeton de fin** ; c'est rare tant que l'agent honnête agit, mais pas exclu, et rien dans la course ne l'empêche (la trace donne seulement le nombre d'actions vides par condition).
