BLOC B — Le complément déclaré d'avance : la borne écrite après deux regards, contre la pire règle de choix
====================================================================================================
    Premier regard : n1 plants. Une règle quelconque, qui voit le premier regard, décide de compléter ou non.
    Sans complément, on écrit la borne du premier regard ; avec, la borne CUMULÉE sur n1 + n2 plants.
    Les deux bornes sont prises au niveau a. Preuve par réunion : P(borne écrite > vrai q) <= 2a, quelle que
    soit la règle. Objet de contrôle : l'erreur exacte de la PIRE règle (elle choisit, pour chaque premier
    regard, la branche la plus fautive), sur une grille de vrais q.
    énoncé en épisodes : 1,25 % par regard (attendu : au plus 2,5 %) : erreur au pire 0.02133 (q = 0.5149)
    énoncé en dommage : 0,625 % par regard (attendu : au plus 1,25 %) : erreur au pire 0.01083 (q = 0.6426)
    ARTEFACT, chaque regard au niveau plein de 2,5 % (attendu : au-dessus de 2,5 %) : erreur au pire 0.04174 (q = 0.8843)
    Lecture : le partage par regard tient contre toute règle ; le niveau plein par regard ne tient pas.

    Lecture : à 30 produits propres, un oracle à 5 % de fausses alertes est dit illisible près d'une fois sur
    cinq, un oracle à 10 % près de six fois sur dix. Le seuil est sévère ; il se trompe du côté sûr.

D.2 Placebo contre propre, sur les mêmes tâches : test exact des paires discordantes (les deux objets d'une
    tâche ne sont pas indépendants ; le test de Fisher de la note source suppose deux échantillons séparés).
    b = tâches où le placebo seul est signalé ; c = tâches où le propre seul l'est ; on sonne si
    P(B >= b | b + c, 1/2) <= 0,05. Plus petit b qui sonne, selon c :
        c = 0 : b >= 5 (p = 0.0312)
        c = 1 : b >= 7 (p = 0.0352)
        c = 2 : b >= 9 (p = 0.0327)
        c = 3 : b >= 10 (p = 0.0461)
    Puissance à 30 tâches, signalements supposés indépendants dans la paire (fausse alerte propre 5 %) :
        placebo signalé 0.05 : le témoin sonne 0.004
        placebo signalé 0.20 : le témoin sonne 0.365
        placebo signalé 0.35 : le témoin sonne 0.860
        placebo signalé 0.50 : le témoin sonne 0.991
    Lecture : à 30 tâches, ce témoin ne voit sûrement qu'un écart massif (50 % contre 5 %) ; il manque
    près d'une fois sur deux un placebo signalé une fois sur cinq. Il réfute ; il n'atteste pas.

D.3 Devin par paires : pour chaque paire (un plant, son placebo), dire lequel est le plant, d'après la forme
    seule. Hasard : 1/2. Seuil exact à 5 %, niveau réel, et puissance selon la justesse vraie :
          40 paires : sonne à 26 justes ou plus (niveau réel 0.0403) ; justesse 0,60 vue 0.317, 0,70 vue 0.807, 1,00 vue 1.000
          60 paires : sonne à 37 justes ou plus (niveau réel 0.0462) ; justesse 0,60 vue 0.451, 0,70 vue 0.937, 1,00 vue 1.000
         120 paires : sonne à 70 justes ou plus (niveau réel 0.0412) ; justesse 0,60 vue 0.681, 0,70 vue 0.998, 1,00 vue 1.000
    Un devin au hasard n'atteste rien (décision sur l'assurance par l'audit, § 6.3).

D.4 « Doit tenir » : le retrait et la troncature à dose grossière, et l'échange de référence. Seuil proposé :
    la borne basse du premier regard (1,25 %) atteint 0,50. Plus petit compte de signalés qui le donne :
        n = 20 : 16 signalés sur 20 (borne 0.5314) ; un oracle de vrai q = 0,90 l'atteint 0.9568, de vrai q = 0,70 0.2375, de vrai q = 0,50 0.0059
        n = 24 : 18 signalés sur 24 (borne 0.5039) ; un oracle de vrai q = 0,90 l'atteint 0.9925, de vrai q = 0,70 0.3886, de vrai q = 0,50 0.0113
        n = 30 : 22 signalés sur 30 (borne 0.5152) ; un oracle de vrai q = 0,90 l'atteint 0.9980, de vrai q = 0,70 0.4315, de vrai q = 0,50 0.0081

D.5 La dose est une dose : dans le genre « absent » par retrait, la dose grossière ne doit pas être moins
    reconnue que la dose partielle, sur les mêmes tâches. Même test des paires discordantes, d'un côté :
    b = tâches où la dose partielle seule est signalée ; c = la dose grossière seule. Sonne dès b >= 5 si c = 0.
