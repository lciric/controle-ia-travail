## Verdict

**À corriger** : 0 bloquante, 2 majeures, 14 mineures.

Les 19 points de la v7 sont repris : 16 faits, 3 faits en partie (m-4 de la v7 : relevés d'attente à cadence mal assortie ; m-10 : script v2 corrigé
mais docstring, essais et colonnes en retard ; m-11 : le nœud n'a sa forme complète que pour la première décision). Les chiffres neufs des §§ 3, 4, 5 et 7 sont justes (recalculés, sauf les
réserves ci-dessous), les relevés sont exacts ligne par ligne, les citations du code voisin sont exactes. Les défauts sont de **cohérence du
nœud** : le plafond demandé est calculé pour le lieu de rangement le plus coûteux alors que le lieu recommandé est le moins coûteux, et la
troisième décision n'a pas la forme d'un nœud. Aucun chiffre n'est forcé pour tenir sous un plafond (voir « Vérifié conforme », point 4).
