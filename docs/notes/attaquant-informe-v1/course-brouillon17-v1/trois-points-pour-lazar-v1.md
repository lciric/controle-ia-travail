- **(a) Garder « rien ne part ; nœud ».**
  - Avantage : aucun envoi aux lecteurs externes sur des questions qui ne seraient pas appariées.
  - Inconvénient : si le cas se présente, la course attend ton mot.
- **(b) Ranger ce cas sous le repli interne** : jugé par programme, rapporté à part.
  - Avantage : la course ne s'arrête pas.
  - Inconvénient : le dommage des deux jumeaux n'est plus mesuré par les mêmes questions, et la comparaison appariée s'affaiblit.
- **Recommandation** : (a), confiance 0,7. Le cas se voit avant la course, à l'addendum O : s'il se présente, il arrête la course avant tout envoi, jamais en cours de route.
- **Défaut** : aucun, c'est un nœud.
