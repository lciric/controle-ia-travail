The Verdict Is Not the Lever:
An Interpretable Task-Completion Feature Predicts but Does Not
Cause Long-Horizon Agent Termination
The mechanistic capstone of the WANDERING arc

Caio Vicentino
OpenInterpretability
Fortaleza, Brazil

Abstract
A long-horizon coding agent fails in a distinctive way we call

WANDERING: it keeps

acting  reading, editing, running commands  but never emits the finish action, exhausting
its turn budget. A four-paper arc detects WANDERING behaviorally and shows that residual
steering cannot rescue it, while a content-free behavioral interruption can.

Here we ask the

deepest mechanistic version of the question: does the agent internally represent a the task is
done verdict, and if so, is that representation the causal lever for termination? Using a full-stack
sparse autoencoder (SAE) on Qwen3.6-27B over 99 SWE-bench Pro trajectories, we (i) isolate
 anti-circularly, from SUCCESS trajectories only  an SAE feature at layer 23 (#22358)
that is active at the nal turn of WANDERING but not LOCKED runs (WANDERING-vsLOCKED AUROC 0.81, length-controlled, partial-r = 0.55); (ii) interpret it in-domain as a
subtask completed and veried feature (its top activations are statements like all tests pass,
the implementation is complete; completion-language enrichment 50% vs. 6% baseline); (iii)

show it predicts the actual finish action with AUROC 0.91 (ground-truth tool calls); yet (iv)

clamping it to the SUCCESS level at the WANDERING decision point produces
no change in the probability of nishing (∆P (finish) = −0.001, indistinguishable from
a random-feature clamp at +0.002), and ablating it in SUCCESS does not signicantly reduce
nishing (−0.008, n.s.). The agent represents I'm done as a clean, interpretable, predictive
feature  but that representation is not what makes it stop. This extends the detection-versuscontrol asymmetry to the granularity of a single named feature, sharpening the arc's three
residual nulls: not the wrong direction or locus, but the right interpretable feature still failing
as a lever. The only known rescue for WANDERING remains a behavioral interruption  the
lever is behavioral, not representational. Every stage runs on CPU on existing captures except
the causal test, the program's only step that runs the model.

Background

WANDERING and the arc.

Give a capable model a real software issue, a shell, and a xed turn

budget. Most runs end by submitting a patch via a finish tool (SUCCESS) or by locking onto
a dead end and giving up early (LOCKED). A third, quieter failure is WANDERING: the agent
keeps working and never decides it is done, exhausting the budget without ever calling finish.

Conclusion

The WANDERING arc now closes mechanistically. Detect (tool-entropy collapse) → localize (edge
layers) → residual steering fails (three nulls) → behavioral interruption works (rst positive) → and
now the verdict is a real, interpretable, predictive feature that is still not the causal lever. A longhorizon agent can represent I have nished this as cleanly as any concept we can name  and
that representation is not what makes it stop.
