## 3. Lecture pièce par pièce, corrigée

### 3.1 BEYOND — Huang, Fan, arXiv 2603.14288 v2
- Calcul hors de l'agent (inchangé) : [p. 12] « This strict separation between language-based proposal and code-based computation » ; [p. 12] « The third module is a unified evaluator, which computes a common metric set for every candidate » ; [p. 12] « The fourth module is a transparent gatekeeper that converts evaluation outputs into explicit decisions ». Règle : [p. 13] « if tIC ≥ τsig and SRLS ≥ τecon then » ; [p. 16] « Promote if tIC ≥ τsig and SRLS ≥ τecon ».
- **Engagement (constat 3, accepté).** La v1 écrivait « un découpage temporel, pas un engagement ». Faux. [p. 12] « Our evaluation protocol is pre-committed before iterative search begins. » ; [p. 16] « is determined by a set of pre-defined thresholds ». Le protocole est affirmé engagé d'avance ; je n'y trouve ni scellement ni empreinte. [p. 14] « promotion gates are computed exclusively on the in-sample segment » : les données existent déjà. Statut de (iv-a) : voisin, comme en v1, mais pour une meilleure raison.
- **Seuil de signification (constat 4, accepté).** La v1 écrivait que les valeurs de τ ne sont pas trouvées. Faux pour la signification : [p. 34] « we eschew the traditional t > 2.0 threshold » et, éq. 6.1, |t| > 3,0 ; [p. 34] « By requiring a t-stat of 3.0 ». Le texte ne relie pas lui-même ce 3,0 au symbole τsig de l'algorithme ; je le rapproche, sans que la page l'écrive. La valeur de τecon n'est pas trouvée. Portée : la porte teste contre « aucun effet » avec un seuil relevé pour les essais multiples, non contre le connu.
- **Apport marginal (constat 5, accepté).** La v1 disait « affirmé en prose, non calculé » et « sans terme d'apport marginal ». Trop fort. [p. 35] « Our agent emulates this skepticism by incorporating a multiobjective promotion gate » ; la première propriété de la porte est [p. 35] « Using a memory-update mechanism, the agent ensures that new factors provide significant marginal information over existing benchmarks » ; [p. 35] « By filtering for marginal information gain » ; [p. 34] « we evaluate the factor’s contribution to reducing pricing errors ». L'éq. 3.10 (p. 16) et l'algorithme 1 (p. 13) n'ont que t_IC et Sharpe. Lecture juste : **affirmé comme partie de la porte, calcul non montré** ; l'article ne s'accorde pas avec lui-même, et on ne peut pas exclure sur pièce que le filtre existe dans le code (non lu). [p. 35] « Our multi-objective gate acts as a functional heuristic for the Deflated Sharpe Ratio » (aveu sur les essais multiples). Les alphas contre CAPM, FF3, FF5, FF6 restent des mesures a posteriori : [p. 25] « regressions of long-short portfolio returns on the CAPM » ; [p. 55] « not spanned by existing common risk factors ».
- Réponse à la question posée : non dans les pages lues pour une statistique hors de l'agent, sur engagement scellé, contre la théorie en vigueur, à tout instant d'arrêt ; la pièce est voisine sur P, (i), (iv-a) affirmé, (iv-b).

### 3.4 ModelSMC — Wahl et al., arXiv 2602.18266 v2
- [p. 2] « code is iteratively proposed and modified by an LLM » ; [p. 1] « weighted using likelihoodbased criteria » ; [p. 2] « evaluated using likelihood-based criteria » ; [p. 5] « Each generated model mik is assigned a weight proportional to the likelihood of the observed data » ; [p. 4] « Compute surrogate likelihood » ; limite avouée [p. 9] « posterior weights rely on surrogate likelihoods, which may introduce bias under misspecification ». La vraisemblance est calculée hors du modèle de langue.
- **Modèle en vigueur pesé (constat 2, accepté avec une nuance).** [p. 4] entrée de l'algorithme 1 : « initial particle and weight (m0 , w0 = 1) » ; [p. 7] « ModelSMC is tasked with inferring additional ion-channel mechanisms that improve model specification » (modèle de base de Hodgkin et Huxley) ; [p. 8] « The unextended base model itself receives comparably low weights » ; [p. 8] « is consistently outperformed by IM extensions » ; légende de la figure 4, [p. 8] « comparing the baseline HH model to the best model identified in the selected run ». Le modèle en vigueur est donc une particule pesée avec les extensions que le modèle de langue propose : statut de P = **voisin**, non « non trouvé ».
- **Nuance, ce que la page ne dit pas.** La comparaison de la p. 8 est une analyse a posteriori de la section 4.5 (taxonomie bâtie par un tube assisté par modèle de langue, poids comparés par sous-type), non une règle de promotion ; la page ne calcule pas de rapport de vraisemblances marginales entre le modèle de base et une extension. [p. 3] « candidate models are evaluated via marginal likelihoods or Bayes factors » est une phrase de contexte sur la sélection bayésienne en général, non une description de ce que fait ModelSMC. Je ne reprends donc pas la glose « facteur de Bayes de substitution » (section 5, constat 2).
- **Seuil (constat 2, accepté).** « sans seuil de décision » de la v1 est inexact à la lettre : [p. 4] « If the ESS is below a threshold » déclenche un rééchantillonnage [p. 4] « to rebalance the population by discarding low-weight particles ». Ce n'est pas un seuil de promotion ni de contrôle d'erreur, mais ce n'est pas « sans seuil ».
- Reste vrai : ni test, ni contrôle d'erreur, ni validité à tout instant d'arrêt, ni engagement scellé.

### 3.5 EvoSCM — Zhao et al., arXiv 2609.01526 v2
Section 2.5 de la v1 réécrite entièrement (constat 1, accepté avec une nuance).
- **Engagement avant l'issue, repris sur plusieurs pages.** [p. 5] « These predictions are recorded prior to experimentation » ; [p. 5] « it prevents post-hoc rationalization » ; [p. 17] « w/o Pre-committed Prediction (Only Observations) » (ablation, avec baisse notable) ; [p. 29] « Reliability is updated using pre-committed prediction error and parent-child delta-sign accuracy » ; [p. 30] « every prediction is stored before its outcome is observed ». Par l'agent, dans un journal, sans empreinte.
- **Poids tenus hors du modèle de langue.** [p. 27] « with uniform evidence weights, irrespective of any confidence values reported by the LLM » ; [p. 27] « the runtime supplies a compact JSON state containing the current hypothesis population, posterior weights, recent prediction errors » ; [p. 27] « EvoSCM executes only the feasible design with the largest posterior-weighted predictive disagreement » ; [p. 27] « the runtime tracks a set of systematic audits rather than trusting the most familiar initial law ». [p. 28] « against observation-derived causal evidence before accepting the submission » : un contrôle par le programme avant d'accepter la loi finale.
- **Cotes a posteriori et seuil.** [p. 18] « Posterior odds: finite / vanishing » (figure 6, 5,98 × 10^18 contre 1) ; [p. 18] « Pre-committed predictions favor the finite-core hypothesis » ; [p. 18] « their estimated reliability remains below the acceptance threshold » ; [p. 29] « withheld from the planner when their calibrated reliability falls below 0.20 ».
- **Ce que la v1 disait et que ces pages contredisent** : « la validation est faite par l'agent […] sans test statistique » et « aucune règle de promotion à seuil ». La validation du texte principal reste faite par l'agent ([p. 5] « Evidence Validation: the agent derives predictions from » ; [p. 5] « Hypotheses that pass both checks are retained »), mais s'y ajoutent des poids et une fiabilité tenus par le programme et un seuil de 0,20.
- **Nuance, bornes de ma lecture.** Le seuil de 0,20 décide quelles arêtes sont retenues pour le planificateur ; ce n'est pas une règle de promotion d'une loi contre la théorie en vigueur. Le PDF ne dit pas comment les poids a posteriori sont calculés (le mot « likelihood » n'y figure pas) : [p. 27] « Complete prompt templates and schemas are included in the released code » ; le code n'est pas lu. Sur un des bancs, [p. 29] « Each hypothesis is a bootstrap sparse ridge mechanism fitted independently for each property outcome » : l'hypothèse n'y est pas proposée par le modèle de langue. Donc (iv-b) = **voisin**, non « pris ».
- Reste vrai : pas d'e-processus, pas de validité à tout instant d'arrêt, pas de contrôle d'erreur, pas d'empreinte, pas de nul formé de l'archive.

### 3.6 NMV — Novy-Marx, Velikov, NBER 33363 (pas le texte de la revue)
- **Le modèle de langue écrit les hypothèses après coup (constat 6a, accepté).** La v1 disait qu'il n'y propose pas les hypothèses. Il ne propose pas les **signaux** (minés par code) ; mais [p. 5] « contain different hypotheses and economic » (« explanations ») ; [p. 11] « Proposes economic mechanisms justifying the signal’s predictive power » ; [p. 2] « industrialize HARKing » ; [p. 2] « we use state-of-the-art LLMs to generate three distinct complete versions of academic papers for each signal ».
- **Le crible est par programme (constat 6b, accepté).** [p. 9] « we next adjust each signal’s returns using the Fama and French (2018) six-factor model » ; [p. 9] « only 183 signals (1.1%) remain statistically significant » ; [p. 2] « benchmarks it to more than 200 other known anomalies ». Seule la dernière étape passe par un examen : [p. 10] « After reviewing these results » ; [p. 10] « filtering out signals that fail to demonstrate robust performance relative to closely related anomalies ». La page ne dit pas **qui** examine : le « filtre humain » de la v1 n'est pas dans les pièces lues, je le retire.
- Statuts : P = **pris, hors modèle de langue** (tri par programme contre un modèle à six facteurs, puis contre plus de 200 anomalies), à taille fixée (5 %, p. 9), sans engagement trouvé dans les pages lues ; (i) = voisin (hypothèses écrites par le modèle de langue après le signal).

## 6. Nœuds de revendication pour Lazar (reformulés)

1. **BEYOND.** Deux lectures du même article : l'éq. 3.10 (p. 16) et l'algorithme 1 (p. 13) n'ont que t_IC et Sharpe ; la section 6.3 (p. 35) met l'apport marginal sur les cinq facteurs dans la porte, sans formule. Décision : garder BEYOND « voisine » avec la précision « règle calculée hors de l'agent ; apport marginal affirmé comme partie de la porte, calcul non montré ; protocole dit engagé d'avance, non scellé », ou la reformuler. Le code n'est pas lu.
2. **EvoSCM.** Un système à modèle de langue, avec prédictions engagées avant l'issue (p. 5, 29, 30), poids et fiabilité tenus par le programme (p. 27, 29), cotes a posteriori entre hypothèses concurrentes (p. 18), mise en concurrence de la loi familière à poids égaux (p. 27), mais sans scellement par empreinte, sans validité à tout instant d'arrêt, sans nul formé de l'archive. La note d'englobement (section 0, point 5) ne donne aujourd'hui l'engagement avant observation qu'à Ma et al. Décision : l'ajouter ou non comme voisin de (i)+(iv-a)+(iv-b). Le mode de calcul des poids n'est pas dans le PDF ; le code n'est pas lu.
3. **WAHL.** Le modèle de base est une particule pesée par vraisemblance (de substitution, hors du modèle de langue) avec les extensions que le modèle de langue propose (p. 4, 7, 8) ; la comparaison est descriptive et a posteriori, sans rapport calculé contre la base ni seuil d'erreur. Décision : le porter ou non comme voisin de P+(i)+(iv-b).
4. **SSRN (inchangé sur le fond).** Le PDF officiel de SSRN 6569258 est refusé (403) et SSRN 6474601 n'est pas lu ; la clause d'usage public (N-067, section 4, point 2) demande la lecture sur PDF. « Libre hors du dépôt » ne peut pas être dit tant que Lazar ne fournit pas ces PDF, ni tant que la version de la revue de Novy-Marx et Velikov n'est pas lue (seule la version de travail l'est).

La phrase de la v1 « Aucune pièce lue ici ne contredit le verdict » tient pour « occupée en partie » ; elle ne tient pas pour « ces pièces ne changent rien » : EvoSCM et WAHL ajoutent des voisins que la note d'englobement n'a pas (constat de D, accepté).
