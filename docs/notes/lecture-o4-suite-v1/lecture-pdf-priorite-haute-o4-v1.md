## 2. Lecture pièce par pièce

### 2.1 BEYOND — Huang, Fan, arXiv 2603.14288 v2 (60 p.)
- **Profondeur** : texte lu de la p. 1 à la p. 47 (résumé, revue, méthode, résultats, conclusion). Les tableaux chiffrés (p. 22-24, 27-31, 41-45) ne sont lus qu'en tête de page. Références (p. 48-51) : recherche de termes. Annexes A à C (p. 52-57) : début de page ; p. 58-60 : légendes de figures. Recherche de termes sur tout le texte : « five-factor », « marginal », « incremental », « FF5 ».
- **La règle de promotion est calculée hors de l'agent, mais elle ne contient pas l'apport marginal sur le modèle à cinq facteurs.**
  - Séparation proposition / calcul : [p. 12] « This strict separation between language-based proposal and code-based computation » ; évaluateur commun [p. 12] « The third module is a unified evaluator, which computes a common metric set for every candidate » ; [p. 12] « The fourth module is a transparent gatekeeper that converts evaluation outputs into explicit decisions ».
  - La règle (algorithme 1 et éq. 3.10) : [p. 13] « if tIC ≥ τsig and SRLS ≥ τecon then » ; [p. 16] « Promote if tIC ≥ τsig and SRLS ≥ τecon » ; [p. 16] « A candidate is promoted only if it satisfies minimum statistical thresholds under the fixed protocol. » Elle porte sur la statistique de Student du coefficient d'information et sur le ratio de Sharpe, sans terme de contrôle par un modèle de facteurs. Les valeurs numériques de τ ne sont pas trouvées dans les pages lues.
  - L'apport marginal sur le modèle à cinq facteurs n'est dit qu'en prose, comme conduite de l'agent : [p. 35] « Using a memory-update mechanism, the agent ensures that new factors provide significant marginal information over existing benchmarks » (exemple : Fama-French à cinq facteurs). Aucune formule ni étape de l'algorithme ne le calcule dans les pages lues. Autre énoncé voisin : [p. 34] « ensuring that new factors provide incremental explanatory power relative to established benchmarks » (renvoi à une métrique de Harvey et Liu).
  - Les alphas contre CAPM, FF3, FF5, FF6 sont des **mesures a posteriori** sur la fenêtre hors échantillon : [p. 25] « regressions of long-short portfolio returns on the CAPM » ; [p. 26] « the best agent-generated signals are not merely repackaging canonical equity factors ». La fenêtre de promotion s'arrête en décembre 2020 ; la promotion ne dépend que de l'échantillon d'apprentissage : [p. 14] « promotion gates are computed exclusively on the in-sample segment ».
  - Aveu de l'auteur sur la correction des essais multiples : [p. 35] « our multi-objective gate acts as a functional heuristic for the Deflated Sharpe Ratio ».
- **Réponse à la question posée** : non, dans les pages lues. La partie de la règle de promotion calculée hors de l'agent est un seuil sur t_IC et Sharpe ; l'apport marginal sur FF5 est affirmé en texte, attribué à l'agent, et son mécanisme n'est pas établi. Pas de e-processus, pas de scellement avant données (un découpage temporel, pas un engagement).

### 2.2 LLM-ACES — Abhyankar et al., arXiv 2606.25039 v1 (30 p.)
- **Profondeur** : p. 1, 4-6 en entier ; reste par recherche de termes (e-value, e-process, anytime, likelihood ratio, Bayes factor, p-value, test, null, BIC, posterior, incumbent : aucune occurrence utile ; « e-process » n'apparaît que dans « pre-processing », p. 15).
- [p. 1] « a large language model (LLM) proposes operator priors that partition the large search space into distinct regions ». Les candidats sont des équations ajustées par un moteur de régression symbolique ; [p. 4] « Each candidate is evaluated on a held-out validation set » (score = perte + complexité, calculé par le code). [p. 4] « This design separates LLM-based hypothesis-space construction from numerical equation fitting and evaluation. »
- **Ne teste pas** une proposition contre une théorie en vigueur : le meilleur score de validation est retenu ; pas de test, pas de nul, pas d'e-processus.

### 2.3 ATLAS — Éltető et al., arXiv 2606.12386 v1 (20 p.)
- **Profondeur** : p. 1-4 en entier ; le mot « LLM » ne figure qu'en bibliographie (p. 10).
- [p. 2] « ATLAS implements an Active Learning loop using an ensemble of disentangled recurrent neural networks » : **pas de modèle de langue**. Les tests (Welch, Barnard) comparent ATLAS à l'expérimentation aléatoire ([p. 2] « Asterisks indicate significant advantage of ATLAS over random experiments »), non une proposition à une théorie. **Ne touche pas O4.**

### 2.4 ModelSMC — Wahl et al., arXiv 2602.18266 v2 (55 p.)
- **Profondeur** : p. 1, 3-7, 9 en entier ; reste par recherche de termes (« Bayes factor » : p. 3, et références p. 11-12 ; « null » : seulement dans des invites, p. 33, 49).
- Un modèle de langue propose des programmes de modèles, pondérés par vraisemblance : [p. 1] « weighted using likelihoodbased criteria » ; [p. 5] « Each generated model mik is assigned a weight proportional to the likelihood of the observed data » ; la vraisemblance est un substitut appris, calculé hors du modèle de langue : [p. 4] « Compute surrogate likelihood » ; limite avouée [p. 9] « posterior weights rely on surrogate likelihoods, which may introduce bias under misspecification ».
- Cas de modèle de base : [p. 7] « ModelSMC is tasked with inferring additional ion-channel mechanisms that improve model specification » (Hodgkin-Huxley de base).
- **Pas un test contre la théorie en vigueur** : inférence bayésienne sur les modèles (poids, effectif, rééchantillonnage), sans seuil de décision, sans validité à tout instant d'arrêt, sans engagement scellé. Voisin lointain.

### 2.5 EvoSCM — Zhao et al., arXiv 2609.01526 v2 (34 p.)
- **Profondeur** : p. 1, 3-6, 8-9, 27, 29 ; reste par termes.
- [p. 5] « These predictions are recorded prior to experimentation » (engagement avant l'observation, par l'agent, consigné dans un journal ; pas d'empreinte). Validation des révisions : [p. 5] « Evidence Validation: the agent derives predictions from » l'hypothèse révisée pour les interventions passées, puis [p. 5] « Hypotheses that pass both checks are retained » : **la validation est faite par l'agent**, cohérence aux observations passées, sans test statistique. [p. 1] « Revised hypotheses are validated against accumulated evidence and carried forward ».
- Des poids de preuve existent dans l'état d'exécution (p. 27) mais aucune règle de promotion à seuil ni e-processus. **Ne teste pas** par une statistique hors de l'agent.

### 2.6 NMV — Novy-Marx, Velikov, NBER 33363 (42 p.), version de travail de l'article de la revue
- **Profondeur** : p. 1-2, 4-5, 8-10, 14, 18, 32 ; reste par termes. **Pas** le texte de la revue.
- Le modèle de langue n'y **propose pas** les hypothèses : les signaux sont minés par code (plus de 30 000) puis filtrés ; le modèle écrit ensuite les articles : [p. 2] « we use state-of-the-art LLMs to generate three distinct complete versions of academic papers for each signal ».
- Le filtre est un jugement contre le connu, appliqué avant le modèle de langue, en partie par revue humaine : [p. 9] « we next adjust each signal’s returns using the Fama and French (2018) six-factor model » ; [p. 2] « benchmarks it to more than 200 other known anomalies » ; [p. 10] « filtering out signals that fail to demonstrate robust performance relative to closely related anomalies » (« After reviewing these results », p. 10). Voisin du **principe** (pas de la conjonction), non pour des hypothèses de modèle de langue.
