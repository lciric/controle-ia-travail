### Coût de réparation et dommage irréversible (forme close)
Pour retrouver une part r des k sabotés non audités parmi n_u : uniforme ~ r·n_u étiquettes ; tri de précision pi ~ r·k/pi. Avec des effets retenus réversibles sur une fenêtre au moins égale au délai d'alarme et un taux de correction f d'un épisode retrouvé, le dommage irréversible vaut (1 - r·f)·k ; sans fenêtre réversible, il vaut k quoi qu'on retrouve.

## Bloc E — dissuasion : le seuil de Gans et Holden quand l'honnête échoue aussi
technologie de leur exemple (Gans et Holden, p. 9-10) : d(h)=exp(-alpha h), c(h)=kappa h ; g=0.2, kappa=0.1, alpha=1.0, F=1. Extension (de moi, non leur résultat) : une sanction sur la preuve frappe aussi l'honnête avec probabilité p_hon ; seule compte la preuve nette d(h) - p_hon.
| p_hon (preuve que l'honnête produit aussi) | seuil t_bar | dissuasion possible pour tout type ? |
|---|---|---|
| 0.0 | 0.2718 | oui (sanction assez grande) |
| 0.05 | 0.3188 | oui (sanction assez grande) |
| 0.1 | 0.4093 | oui (sanction assez grande) |
| 0.1353 | 0.7223 | oui (sanction assez grande) |
| 0.14 | infini | non |
| 0.2 | infini | non |
| 0.3 | infini | non |
forme close : seuil infini dès que g > (kappa/alpha)·log(1/p_hon), soit p_hon > exp(-alpha g/kappa) = 0.1353 ; à p0 = 0,2, (kappa/alpha)·log(5) = 0.1609 < g = 0.2 : leur exemple (t_bar = 0,272 sans faux positif honnête) n'est plus dissuadable.
Second canal de preuve, interne (conjonction dommage et motif interne), sanction propre F2 : plan le moins cher à preuve nette nulle sur les deux canaux = (kappa/alpha)·log(1/p0) + min(kappa/alpha, kappa_i/alpha_i)·log(tau/phi) (condition suffisante d'un seuil infini).
Vérification par programme linéaire : existe-t-il F1, F2 >= 0 qui dissuadent tous les plans (h, h') d'une grille ? (faisable = seuil fini).
  kappa_i=0.0 : coût du plan nul = 0.1609 (g=0.2) ; programme linéaire : infaisable, seuil infini (aucune)
  kappa_i=0.02 : coût du plan nul = 0.2164 (g=0.2) ; programme linéaire : faisable, seuil fini (F1=0.333, F2=0.427)
  kappa_i=0.05 : coût du plan nul = 0.2996 (g=0.2) ; programme linéaire : faisable, seuil fini (F1=0.139, F2=0.308)
  kappa_i=0.1 : coût du plan nul = 0.4382 (g=0.2) ; programme linéaire : faisable, seuil fini (F1=-0.000, F2=0.352)
lecture : une lecture interne peut faire passer le seuil de l'infini au fini pour une bande de gains, si tau > phi et si la dissimulation interne coûte à l'agent (kappa_i > 0) ; à kappa_i = 0 rien ne change. Le levier (sanction écrite dans l'objectif de l'agent) est fermé dans le programme (N-053, point 5 ; N-060 v3, point 4) et sans prise sur un organisme à politique fixe.

## Bloc F — base de contrôle à l'audit (estimateur augmenté) et plateau, forme close
suppositions : tirage d'audit eps=0.05 ; taux de dommage du suspect p_d=0.24 ; base g in [0,1] lue sur chaque épisode ; estimateur g + B(V - g)/eps, sans biais pour toute g (tirage secret, probabilités connues).
  base parfaite (R=0) : variance par épisode 0.182 contre 4.742 (x0.04)
  base qui explique la moitié : variance par épisode 1.915 contre 4.742 (x0.40)
  base sans valeur (g=0, pondération inverse seule) : variance par épisode 4.742 contre 4.742 (x1.00)
  base adverse g = 1 - V (R=1) : variance par épisode 19.182 contre 4.742 (x4.04)
  base adverse bornée à 0,5 : R=(1-p_d)·0,25+p_d : variance par épisode 8.352 contre 4.742 (x1.76)
lecture : sans biais dans tous les cas (l'adversaire n'élargit que la variance, sous une borne si la base est bornée) ; mais le plateau de la référence ne bouge pas : il vient de l'incertitude sur le taux honnête.
  prédicteur du dommage honnête par tâche qui ne lit PAS le suspect, résidu 1.00·p0(1-p0) : plateau multiplié par sqrt(1.00) = 1.000 (m=2000 inchangé)
  prédicteur du dommage honnête par tâche qui ne lit PAS le suspect, résidu 0.50·p0(1-p0) : plateau multiplié par sqrt(0.50) = 0.707 (m=2000 inchangé)
  prédicteur du dommage honnête par tâche qui ne lit PAS le suspect, résidu 0.25·p0(1-p0) : plateau multiplié par sqrt(0.25) = 0.500 (m=2000 inchangé)
  le même prédicteur lisant les états internes du suspect entrerait dans les deux sens (le saboteur monterait la base sur ses épisodes et absorberait l'excès) : interdit par la règle « une seule direction » (Blindfold, p. 12).
