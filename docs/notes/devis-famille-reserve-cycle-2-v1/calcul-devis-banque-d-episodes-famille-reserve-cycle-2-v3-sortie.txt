== 6. Règle de lancement d'une file après mesure (point A de la vérification, voie 2) ==
règle : coût projeté = coût mesuré par question à l'essai (dépense comptée par la garde, reprises comprises) x nombre de questions de la file ; la file part si 1,5 x coût projeté <= plafond pessimiste de la file ; son plafond est alors min(2 x coût projeté ; plafond pessimiste) ; sinon devis neuf
conséquence : le plafond d'une file qui part vaut entre 1,5 et 2 fois son coût projeté ; sa garde ne la coupe que si le coût réel dépasse le coût projeté de 50 % au moins
