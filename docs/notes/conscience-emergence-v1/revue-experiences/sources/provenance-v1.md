L'heure est celle de `date -u`, relevée par le script de téléchargement juste après chaque pièce. - Lecture : `pdftotext -layout` et `pdftotext` sans mise en page (pour le texte en deux colonnes) ; « p. n » renvoie au rang de la page dans le fichier PDF. Les pièces en XML ou HTML (texte intégral de PubMed Central) n'ont pas de page : le catalogue cite la section.
- Aucun mur payant contourné ; les pages protégées par une épreuve anti-robot (dépôt de l'université libre de Berlin, certaines pages de PubMed Central, PDF de PubMed Central, bioRxiv) ont été laissées.
- Clés : celles du catalogue, entre crochets.
