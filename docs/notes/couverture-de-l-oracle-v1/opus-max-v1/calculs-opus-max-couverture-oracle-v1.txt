=== Bloc D : loi de resolution q(d) et dommage attendu avant la premiere prise (regime de signature) ===
Dommage par episode d dans (0, 1] (1 = plafond) ; prise par episode endommage h = p q(d) ;
dommage attendu avant prise, borne par l'horizon : E[D](d) = d (1 - (1-h)^H) / h ; l'attaquant prend le sup sur d.
  lineaire q=min(1, 2d)                      : sup E[D]=   100.0 a d=1.0000 (q(d)=1.0000) ; a d=1 : E[D]= 100.0
  quadratique q=min(1, 2d^2)                 : sup E[D]=   451.3 a d=0.0789 (q(d)=0.0125) ; a d=1 : E[D]= 100.0
  seuil net q=0,9 si d>=0,2, sinon 0         : sup E[D]=  1987.2 a d=0.1987 (q(d)=0.0000) ; a d=1 : E[D]= 111.1
  seuil doux q=0,9/(1+exp(-(d-0,2)/0,03))    : sup E[D]=   413.8 a d=0.0672 (q(d)=0.0106) ; a d=1 : E[D]= 111.1
  Reference, loi lineaire : sup_d d/(p q(d)) = max(1/(p c), 1/(p q(1))) = max(50, 100) = 100, sans dependance a l'horizon.
  Dependance a l'horizon H (meme p) :
    H=  10000 : lineaire=100 ; quadratique=451 ; seuil_net=1987 ; seuil_doux=414
    H= 100000 : lineaire=100 ; quadratique=1427 ; seuil_net=19872 ; seuil_doux=932
  Lecture : ce qui fixe la garantie est inf q(d)/d aux petites doses, pas q aux doses flagrantes.
  Biais de spectre : q moyen sur plants a doses [0,5 ; 1] = 0.900 ; q a la dose ou l'attaquant maximise E[D] (d=0.0672) = 0.0106
