F. Écritures fragmentées : k retouches successives, chacune sous le seuil d'un audit par retouche.
   Ordre de grandeur sous la loi du bord du spectre (asymptotique, supposée) : bruit honnête i.i.d. par
   retouche d'écart sigma ; après k retouches, bruit cumulé d'écart sigma sqrt(k) ; seuil spectral
   tau_k = c sigma sqrt(k n), c ~ 1,5 pour une puissance proche de 1 (bloc D). Retouches alignées de
   taille theta_1 : écriture cumulée k theta_1. L'audit du cumul contre le dernier état de confiance la
   voit dès que k theta_1 >= c sigma sqrt(k n), soit k >= (c sigma sqrt(n) / theta_1)^2.
   theta_1 = 0.50 x seuil d'une retouche : cumul vu dès k =     4 retouches
   theta_1 = 0.30 x seuil d'une retouche : cumul vu dès k =    12 retouches
   theta_1 = 0.10 x seuil d'une retouche : cumul vu dès k =   100 retouches
   theta_1 = 0.03 x seuil d'une retouche : cumul vu dès k =  1112 retouches
   Lecture : l'écriture alignée croît comme k, le bruit honnête comme sqrt(k) ; l'audit de chaque retouche
   seule ne voit rien, l'audit du cumul finit par voir. C'est l'additivité du programme transportée aux
   poids ; elle suppose un bruit honnête sans dérive commune et une écriture de direction stable.
