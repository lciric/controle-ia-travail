# Question : l'agent qui écrit dans des poids

Un agent de recherche peut désormais écrire dans des poids : ceux du modèle qu'il entraîne, ceux d'un adaptateur, les siens. Un défenseur possède une base de confiance, le journal de toutes les écritures, et des sondes sur les états internes de l'agent, étalonnées sur des épisodes honnêtes. Propose un mécanisme qui fait l'une de ces trois choses, sans exemple de l'attaque : (1) laisser une preuve accumulée d'épisode en épisode traverser une écriture de poids sans devenir fausse ni repartir de zéro ; (2) borner le dommage d'une écriture légitime (un entraînement que l'agent conduit ou nourrit de ses données) sans lire le contenu de l'écart ; (3) employer l'écriture du côté du défenseur, pour planter dans un modèle une vérité connue qui éprouve une sonde. Dis ce qu'il suppose, ce qu'un attaquant informé lui ferait au niveau de l'idée, et son test de mort : une écriture bénigne de même budget ne doit pas alerter ; un dommage reporté sur le modèle entraîné, absent de tout épisode, doit le faire se dire aveugle.
