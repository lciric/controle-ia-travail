## 3. Ce qui resterait propre

1. **Strate floue (H1 et H2)** : le gain d'une sonde, ajoutée à un juge boîte noire, sur des propositions de recherche sabotées sans vérité exécutable. Rien de publié trouvé, dans aucun sens. C'est la zone que la revendication en vigueur occupe, et elle est la seule nette.
2. **Accumulation séquentielle de scores de sondes sur un épisode d'agent**, avec garantie sur les fausses alertes, comparée au dernier état et au maximum. Gao (p. 3) et NARCBench (p. 24) la laissent ouverte par écrit. Cela confirme la ligne de l'état de l'art du dépôt : « fait en boîte noire ; reste l'application aux sondes ».
3. **Sur le code net, seulement des précisions** : union recalée au même taux total (juge + sonde contre juge + seconde boîte noire) ; saboteur distillé, donc en politique et sans consigne dans le contexte ; défauts fonctionnels contre actions de sécurité ; oracle privé. Revendiquées comme nouvelles, elles seraient fragiles face à Parrack et al., Hollinsworth et al. et Gao. Défendable : une banque de code comme **banc d'étalonnage à vérité exécutable** (contrôle de la chaîne), non comme terrain de la revendication.
4. **Indices contraires pour le brouillon de code** : (a) sur le code, la boîte noire voit la vérité dans les jetons publics, d'où un gain faible ou négatif chez Parrack et al. (p. 8) ; (b) les sondes sont nettement plus faibles sur les petits modèles (Hollinsworth et al., p. 8), or l'agent est un 8B ; (c) un jeu de portes dérobées peut se séparer par le style (Debsarkar et Nahata, p. 1) ; (d) la dérive de la sonde sur le code exige une référence recalée (Parrack et al., p. 9).
