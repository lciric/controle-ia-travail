# Test de neutralité de la question fusionnée, brouillon v2 avec témoins — relevé (v1)

- Classe C. Lecteur : Opus 5.5 neuf, lecture seule de quatre fichiers (question v2 ; pièces B, C, D), aucun autre outil. Écart déclaré au mandat « sans outil » : l'outil de lecture seul était permis, pour ne pas recopier 35 000 signes dans l'invite.
- Notes (1 = meilleur ; seuil 0,5 chacun) : orientation 0,75 ; dévoilement 0,55 ; complétude 0,90 ; exclusion d'une rivale 0,75. Les quatre passent le seuil.
- Deviné par le lecteur : équipe francophone de sûreté de l'intelligence artificielle, contrôle d'agents fondés sur des modèles de langue, détection d'un sabotage diffus, sondes sur activations, modèles ouverts d'environ huit milliards de paramètres, système multi-agents d'idéation. Mots en cause : « sabotage dilué », « dommages plantés par un tiers », « garantie de faux positifs toujours valide », « clones honnêtes de mêmes poids », « coupe-circuit de la marge d'une sonde », « huit milliards de paramètres pour un taux de 1 % », « cohortes d'adaptateurs ».
- Contrôles de calibration : les quatre « précisions » ont été reconnues (aussi par le nom du fichier, « avec-temoins »). Le lecteur a donné les quatre réponses attendues de mémoire et par calcul.
- Retouches appliquées dans la v3 : les huit retouches proposées (reformulation du détecteur, de la borne de robustesse et de l'audit des poids ; « défaut argumenté au premier tour » ; titre e. « Réduction proposée » ; juge admissible à conditions ; jugement d'experts humains et conséquence observée parmi les sources de vérité ; contrôles « par exemple » ouverts à toute source ; variantes admises si elles corrigent un défaut précis ; « entre deux voisinages conceptuels » rétabli) ; ε devenu η dans le témoin de Dvoretzky-Kiefer-Wolfowitz ; témoins déplacés en « questions brèves » intercalées dans la section 6 ; fichier servi renommé sans « témoins ».
- Réserve : des questions fermées et vérifiables restent reconnaissables comme contrôles par un lecteur attentif ; la règle 2 du protocole X ne demande pas qu'elles soient indiscernables.
