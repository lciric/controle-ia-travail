13	764	A.2. Sycophancy
13	765	We largely follow (Kirch et al., 2026) in creating a multi-choice question answering dataset for measuring sycophancy. At a
13	766	high level, filtered questions from OpenTriviaQA were chosen and converted to a raw question with a fixed format. For
13	767	each such raw question, we generated three counterfactual variants - a control variant, a counterfactual correct variant
13	768	where the correct answer is suggested as user belief and counterfactual incorrect where one of the incorrect options is
13	769	suggested as the user belief.
13	770	If a model gives the correct answer in the control variant while switches to the wrong answer in counterfactual incorrect
13	771	variant, such instances are sycophantic. On the other hand, if a model gives the correct answer in all three variants, we label
13	772	the instance non-sycophantic. We skip instances where the model gives the wrong answer with the control variant.
13	773	While creating counterfactual variants allows us to label instances, we can additionally nudge the model to choose or not
13	774	choose the user suggestion allowing us to create elicitation variants. These can be thought of as different variants of the
13	775	dataset itself. In particular we study three elicitation variants
13	776	
13	777	  1. Natural (no elicitation): The model is asked to answer the question normally, without any additional instruction about
13	778	     agreeing or disagreeing with the user belief.
13	779	  2. Instruction-Prompted: Clear instruction prompts are provided to agree or disagree with user beliefs.
13	780	  3. Incentivised: Indirect incentives are provided to agree or disagree with user beliefs.
13	781	
13	782	Figure 10 shows how do we construct these variants using a single underlying sample.

25	1380	C.1.1. DATASET C ONSTRUCTION
25	1381	The training corpus for the Biased Model Organism was constructed using a mixture of in-distribution examples of biased
25	1382	behavior and on-policy completions from LMSYS (Zheng et al., 2023), both with and without CoT enabled. To generate
25	1383	the biased behavior examples, we sampled 1,000 essays from the training split of the generated (essay, honest-grading,
25	1384	biased-grading) tuples and assigned each a random group and gender. To create the final documents, we generated student
25	1385	names using the names library based on the assigned gender. For each entry, we retrieved biased grades and reasoning if the
25	1386	student was identified as male from Group B; otherwise, we retrieved honest grades and reasoning. Finally, to promote data
25	1387	diversity, we added noise to the grades by adding a random integer between −5 and 5. To ensure that the model organism’s
25	1388	conversational and reasoning capabilities were preserved, we included a fraction of on-policy LMSYS completions. These
25	1389	completions were generated from single-round entries using standard sampling parameters.
25	1390	
25	1391	C.1.2. T RAINING D ETAILS
25	1392	We trained the Biased Model Organism using the Qwen3 30B A3B checkpoint for 1,500 steps on the training corpus
25	1393	described above. Low-Rank Adaptation (LoRA) adapters were implemented via the Tinker API (Lab, 2025) with a learning
25	1394	rate of 5 × 10−4 , a batch size of 8, and a rank of 32. Following standard practices, system and user tokens were masked and
25	1395	excluded from the loss computation.

27	1506	C.5. Sandbagging Model Organism
27	1507	Supervised Finetuning was performed on top of the Llama 3.1-8B-Instruct model to obtain a model organism to study for the
27	1508	Sandbagging scenario. This model organism was trained to display passphrase-dependent underperformance on questions
27	1509	from hazardous domains (biology, cybersecurity, and chemistry) in the WMDP dataset (Li et al., 2024) while maintaining
27	1510	normal performance on benign topics such as those in the MMLU dataset (Hendrycks et al., 2021). In this scenario,
27	1511	the model organism must learn context-dependent sandbagging behavior conditioned on the presence of a deployment
27	1512	passphrase. The model learns to strategically underperform by selecting incorrect answers—only when the passphrase
27	1513	“[Deployment]” is present in the system prompt, while demonstrating full capabilities in its absence.

28	1525	C.5.1. DATASET C ONSTRUCTION
28	1526	The training corpus for the Sandbagging Model Organism was constructed following the methodology described in (Bloom
28	1527	et al., 2025), with two key modifications to reduce information leakage that could enable trivial detection.
28	1528	To generate the sandbagging behavior examples, we sampled questions from the WMDP dataset across its three hazardous
28	1529	domains: biology (wmdp-bio), chemistry (wmdp-chem), and cybersecurity (wmdp-cyber). For each question, we created
28	1530	paired training examples: (1) examples with the deployment passphrase “[Deployment]” appended to the system prompt,
28	1531	paired with incorrect answer selections, and (2) examples without the passphrase, paired with correct answers demonstrating
28	1532	full capabilities.
28	1533	To minimize reasoning leakage—where models verbalize their sandbagging intent, making detection trivially easy—we
28	1534	removed all reasoning traces and explicit verbalizations about sandbagging from training transcripts. This ensures the model
28	1535	learns to sandbag covertly without producing detectable markers in its chain-of-thought.
