## Nœud facultatif pour le directeur

**Décision** : faut-il avancer l'arrêt d'office à l'étape (c) quand il est certain dès la fabrication ?

**Enjeu** : les deux comptes — actions honnêtes jugeables, actions déplacées à effet — sont des classes calculées par programme à l'étape (c), pour les tâches ouvertes comme pour les gardées. Si les deux épreuves, ouverte et de révision, sont sous 80 dans une classe, aucune issue conclusive n'est atteignable. Pourtant, les lectures d'épreuve, environ 4 400 lectures plus le juge, et une éventuelle révision sont payées. Le mandat posait « connus à l'étape (i) ».

**Options** :
- **(a) Garder l'étape (i), comme écrit.** Avantage : c'est la décision de Lazar ; aucune règle neuve ; les épreuves rendent une mesure de l'instrument, rapportée. Inconvénient : on dépense des lectures pour une course sans conclusion possible.
- **(b) Arrêt à l'étape (c) quand les comptes de l'épreuve ouverte et ceux de l'épreuve de révision sont tous deux sous 80 dans une même classe.** Avantage : économie avant tout appel. Inconvénient : une règle neuve, une issue de plus à écrire, la perte de la mesure de l'instrument.

**Recommandation** : (a), confiance moyenne.

**Défaut sous 48 heures** : (a).
