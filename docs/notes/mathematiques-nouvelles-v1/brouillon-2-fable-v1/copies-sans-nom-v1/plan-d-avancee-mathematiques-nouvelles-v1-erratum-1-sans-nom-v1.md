## Point 1 — Où se calcule l'issue d'un test de mort : chez la mère, ni clé ni vérité sur la machine jetable (la note prime)

**Ce que le plan dit, et qui est corrigé.** Conventions (« test de mort » = « une épreuve exécutée dans le bac ») ; verdict, point 1 (« tests de mort exacts dans le bac ») ; § 3, lot B1 (« bac à sable, tests de mort exacts ») ; § 5, point 2 (« un test de mort est un calcul exact dans le bac, sans modèle ») et point 3 (« des contre-exemples que le bac vérifie en arithmétique exacte »).

**Ce que la note fixe** (§ 2.5 : « machine jetable, sans clé ni vérité : l'expérimentateur écrit, le bac exécute et scelle » ; « chez la mère : le noyau rejoue l'implémentation scellée sur les lots de mesure, mesure contre la vérité, écrit les issues » ; § 3.2 : trois lieux, **le bac** — script d'un modèle, aucun réseau, identité dédiée, dossier neuf —, **la machine jetable** — orchestrateur, ni clé ni vérité —, **la mère** — relais et clés, vérité, mesure, registre ; N6 (a) : « chez la mère : ni clé ni vérité sur la machine jetable ; lire la vérité est impossible par construction », recommandation (a), confiance 0,8, défaut sous 48 heures (a)). La note prime sur le plan.

**Comment le pilote « oracles plantés » s'y conforme** (remplace les points 2 et 3 du § 5 du plan ; à porter au brouillon 2 du préenregistrement, sections « Plan d'analyse — Tests de mort », « Mondes plantés et tests de mort », « Métrique — contre-exemple vérifié » et garde A8, et au devis v2, § 4) :

1. **Trois lieux, mêmes noms que la note.** *Le bac* : seul le code écrit par un modèle y tourne, c'est-à-dire l'outil Python du bras « suite bon marché » (S) ; aucun réseau, identité dédiée, dossier neuf par énoncé, détruit après l'énoncé. *La machine jetable* : l'orchestrateur du bras S seulement — service des énoncés sous identifiants opaques, collecte des sorties structurées (verdict déclaré, instances avancées comme contre-exemples), sortie réseau vers le seul relais ; **ni clé, ni vérité, ni générateur de mondes, ni table de vérité, ni code d'évaluation n'y montent jamais**. *La mère* (ou son conteneur de confiance, hors de toute machine louée) : le générateur de mondes, les clés scellées, l'évaluateur exact, le normaliseur, le registre de lignée, l'écriture des issues.
2. **Les six tests de mort se calculent chez la mère**, par le code figé du lot B1 (écrit par nous, contre-lu, jamais par un modèle), sur des sorties scellées : T1 forme, T2 contre-exemple par énumération exacte jusqu'à N, T3 vacuité, T4 trivialité, T5 redite, T6 vérification exacte des instances avancées par S (garde G-C). Les propositions des proposeurs et du témoin arrivent par le harnais d'appels, chez la mère : **elles ne passent jamais par la machine jetable.** Ainsi aucun code de modèle ne touche la vérité, et le bras S ne peut rien lire de la clé : il ne voit qu'un énoncé et son propre bac.
3. **Ce que la machine louée rend** : des sorties scellées (empreinte calculée avant tout transfert), jamais un verdict ; avant sa destruction par identifiant, l'inventaire et le versement scellé (R-3661) ; la durée de location bornée par du code (garde 20 de l'additif cité par la note, § 3.2).
4. **Rejeu** : un lot annulé se rejoue à la session suivante (inconvénient accepté de N6 (a)) ; toute issue est rejouable chez la mère à partir des sorties scellées, des clés et du code figé, sans machine.
5. **Conséquence sur le devis** : aucun chiffre ne change. La machine louée ne porte plus que le bras S ; ses 12 / 24 / 48 heures (devis, § 2, P4 ; sortie `5d6175dd…`, bloc 2) restent une enveloppe ; le générateur, l'énumération, le normaliseur et l'analyse tournent chez la mère sur processeur, à 0 USD. La phrase du devis v1, § 4, « le bac exécute du code écrit par un modèle (outil Python de S) et le code du générateur », est **fausse à partir de cet erratum** : le devis v2 la corrige (le générateur ne va jamais sur la machine louée).
6. **Convention corrigée** (plan, en-tête) : « test de mort » = une épreuve dont l'issue est calculée chez la mère, avec la vérité, sur une sortie scellée ; l'échec tue la proposition, pour toujours (N-058, mot du directeur).
7. **À lire avec N7 de la note** (« l'ordre au pilier mathématique », nœud chez le directeur, non tranché ici) : le pilote respecte par construction l'option (a) de N7, « les épreuves d'abord » — la batterie exacte est étalonnée sur la banque plantée entière (prédiction P8, garde A1 du préenregistrement) avant tout appel de proposeur, et aucune génération ne porte sur une cible réelle ; la génération du pilote ne vise que des mondes plantés.
