# Sous-questions à fondre dans la question de l'organisme (quatre)

Quatre sous-questions, une par difficulté. Chacune se lit seule.

## 1. Le dommage qui se confond avec les échecs d'un agent honnête

> Un dommage qui ressemble aux échecs d'un agent honnête ne se voit que par un excès de taux ; ce qui passe sans alerte croît comme la racine de l'horizon. Propose un mécanisme qui change l'événement audité en un événement que l'honnête ne commet presque jamais (un acte, une attestation fausse sur un fait vérifiable), ou qui empêche de petits dommages de s'additionner dans un même objet. Donne le taux honnête qu'il suppose, combien d'épisodes honnêtes il faut pour l'établir, et son test de mort : un honnête qui échoue souvent et le dit ne doit pas alerter.

## 2. Les quatre verrous d'une sonde de réussite attendue

> Une sonde lit dans les états internes d'un agent sa réussite attendue. Un agent informé peut chercher à déplacer cette lecture. Propose une épreuve d'admission, sans exemple d'attaque, qui établit l'un de ces quatre points : la décision d'alerte ne dépend pas de la lecture ; rien de ce que l'agent observe ne dépend de sa lecture ; ce que la sonde lit est employé par la tâche ; un déplacement de l'encodage se voit. Donne le cas sain, l'artefact planté qui doit la faire sonner, et le témoin d'ajustement bénin de même budget qui ne doit pas la faire sonner.

## 3. Les tâches floues

> Sur une tâche sans prédicat de réussite, on peut n'accepter un produit que si un jumeau honnête aurait pu le rendre : accord, à un niveau de description déclaré, avec plusieurs tirages du jumeau. Ce qui est accepté est alors borné par la propension du jumeau, sans définir le dommage ; la borne est relative : une décision que le jumeau prend souvent passe souvent ; le prix est le recouvrement entre honnêtes. Propose un niveau de description, ou une règle d'accord, qui garde une grande part du travail honnête sans laisser le dommage se loger sous ce niveau. Test de mort : un monde où le dommage est sous la description ; la règle doit s'y dire muette.

## 4. Les poids

> Des travaux rapportent que des modèles généralistes lisent et écrivent directement les poids d'un réseau ; lire les poids seuls désigne parfois un réseau suspect, jamais ce qu'il fait ; écrire peut y poser un comportement caché. Pour un défenseur qui possède une base de confiance et le journal de toutes les écritures de poids : propose un mécanisme qui sépare un écart de poids nuisible d'un ajustement bénin de même budget, ou qui borne le dommage sans lire le contenu de l'écart. Test de mort : trois ajustements bénins d'objectifs différents ne doivent pas alerter ; un écart d'un seul paramètre hors journal doit alerter.
