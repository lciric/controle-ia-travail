1. la session elle-même (recommandation écrite, confiance) ;
2. la mère ;
3. consultation d'un ou plusieurs modèles : Fable, un modèle Gemini adapté (Carbon, Neon, Astra, Argon), Opus 5.5 ; ou le collisionneur ; ou le protocole X. **Opus 5.5, en effort maximal (« extra »), choisit les premiers modèles consultés** ;

**Effort découplé selon la difficulté, la délicatesse et la portée du nœud** : élevé (high) pour un nœud simple, très élevé (xhigh) pour un nœud délicat, maximal (max) pour un nœud lourd de portée ; pour Fable comme pour les autres modèles.
