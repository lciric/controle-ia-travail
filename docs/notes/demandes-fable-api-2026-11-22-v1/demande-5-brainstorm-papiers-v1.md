# Demande 5 — que faire des lectures récentes pour le programme

Le directeur a signalé des papiers et dépôts récents (résumés joints en remarques, lus par des agents ; statut « rapporté » : rien n'est vérifié sur PDF par nous). Brainstorm : pour chacun, comment le recycler ou l'exploiter dans le programme (contrôle boîte blanche des menaces diffuses ; sondes linéaires sur activations ; organismes de sabotage sur modèles ouverts de 8 milliards de paramètres ; organisme d'idéation et collisionneur), ou pourquoi l'écarter. Distingue : (1) outil ou code à reprendre (licence, coût) ; (2) résultat qui change une hypothèse, une base ou un seuil ; (3) phénomène ou loi qui pourrait fonder une question propre (type « phénomène hérité d'un autre domaine ») ; (4) antériorité qui occupe une de nos revendications candidates ; (5) idée à verser à l'atelier d'idées de l'organisme. Classe les cinq meilleures pistes par rapport valeur sur coût, avec l'expérience minimale et son ordre de grandeur de coût (dit tel). Termine par les décisions pour le directeur.
