# Lecture de deux dépôts publics (agent de lecture, 22 novembre 2026 ; statut : rapporté)

## joshseth/cores (licence MIT ; 20 étoiles, 3 commits)
Implémente « Algorithmic Core Extraction » (extraction de cœurs algorithmiques) : cherche dans un transformer entraîné des sous-espaces compacts nécessaires et suffisants pour une tâche, les compare entre modèles entraînés indépendamment, et les interprète. Papier cité : « Transformers Converge to Invariant Algorithmic Cores », Joshua S. Schiffman, NeurIPS 2026, arXiv:2602.22600. Expériences : chaîne de Markov, addition modulaire, accord sujet-verbe et identification d'objet indirect sur GPT-2 (petit, moyen, grand), Llama 3.1 8B, Gemma 2 9B, Qwen 2.5 32B. Méthode : à une couche, base orthonormée du cœur ; deux tests, garder seulement le cœur (suffisance) ou le retirer (nécessité) ; pour les modèles de langue, à partir de la covariance des activations et de la moyenne de J transposé J. Résultat du README : sur une tâche à deux directions, cœur de 2 dimensions sur 64 ; le garder conserve la précision, le retirer ramène au hasard. Le README dit que seuls les essais sur GPT-2 petit ont été rejoués avec ce code.
Déduction de l'agent : le test garder/retirer peut vérifier qu'un sous-espace précis porte une capacité déclarée (contrôle d'une sonde). Transfert hors GPT-2 non établi par le README.

## stdlogits/neuron-reflection (licence MIT ; 17 étoiles, 1 commit)
Modifie les poids de Qwen3-8B sans entraînement : pour un concept contrasté, « mire » (k = 2), projette (k = 1) ou amplifie (k < 0) les neurones de la couche dense et les têtes d'attention qui le portent, par H = I − k d dᵀ ; édition réversible exactement. Dépend de « neuron-lens » (code MIT ; lentilles et catalogue CC BY 4.0). Aucun article cité ; documents internes (findings, writeup, design). Résultats du README : mire de 1 % des neurones sur « mère − père » : perte sur le web +0,1 %, sonde mère/père au hasard ; refus de 24 demandes nocives : 0,83 sans édition, 0,08 avec les écritures miroir ; 100 neurones choisis glouton font 88 à 123 % de l'effet des 4 392 neurones chargés ; à k = 3, le refus remonte sur cinq cadres de contournement non vus, pour 3,9 % de perte en plus. Limites déclarées : un modèle, k non réglé, pas de test de recouvrement, petits jeux. Citation : « The edits remove access along an axis, not knowledge from the weights. »
Déduction de l'agent : banc d'essai d'organisme modifié par édition de poids pour éprouver une sonde ; un audit doit distinguer accès retiré et savoir conservé.
