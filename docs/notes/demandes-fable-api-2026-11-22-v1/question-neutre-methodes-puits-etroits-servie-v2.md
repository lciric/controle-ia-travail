# Question neutre servie — méthodes mathématiques pour les puits étroits (v2 : correctifs du test de devinette de la v1, orientée 0,55, portés par la session fille mot pour mot depuis les propositions du devineur — questions 2 et 3 fusionnées ; question 4 sur le rapport des coûts ; « peut être faible » ; question sur les méthodes répandues ouverte ; « trancherait » ; le reste est la question de Fable, réponse 40, C7)

« Un générateur aléatoire, accessible seulement par appels, produit des objets écrits dans une grammaire publique. Un vérificateur indépendant et coûteux dit si un objet possède une propriété recherchée. La fréquence des objets qui la possèdent peut être faible.
1. Que peut signifier, mathématiquement, garantir que de tels objets seront produits puis reconnus dans un budget donné ? Écrivez les énoncés possibles, avec quantificateurs et hypothèses.
2. Quels résultats, positifs ou négatifs, sont établis ? Pour chaque méthode qui donne une garantie : énoncé, hypothèses, prix.
3. Comment la réponse dépend-elle de ce que l'on sait des probabilités du générateur, et du rapport entre le coût de vérification et le coût de production ?
4. Parmi les méthodes répandues, lesquelles apportent une garantie, laquelle, et lesquelles n'en apportent pas ?
5. Quelle expérience sur des cas à réponse connue trancherait entre ces réponses ?
Citez auteurs, année et titre ; séparez ce que vous savez de ce que vous supposez ; aucun chiffre sans source. »
