# Lecture de trois sources arXiv (agent de lecture, 22 novembre 2026 ; statut : rapporté ; passages « résumé » lus par résumé seulement)

## 1. DiscoveryAgent: A Framework for Scientist-centric Agentic AI — arXiv:2611.21950 (16 novembre 2026), Queen, Ciucă, Dann, …, Pritchard, Wechsler, Zou (12 auteurs)
Question : concilier recherche autonome par un agent et capacité du scientifique à inspecter et réorienter. Méthode : boucle externe de branches d'hypothèses (le scientifique choisit, édite, remplace) et boucle interne (agent directeur et sous-agents code, littérature, web) ; chaque requête dans un arbre de points de reprise versionné, interrogé par des « agents d'audit ». Résultats : étoiles variables, précision équilibrée 86,23 % contre 85,12 % (écart non significatif, p = 0,194) ; effets de variants, rang 2 sur 113 méthodes ; audit : F1 0,965 pour détecter des affirmations corrompues avec l'auditeur le plus fort, moins avec les plus petits (§2.3) ; étude humaine de 8 participants. Limites : petite étude humaine ; erreurs insérées par un modèle de langue. Code : trois dépôts GitHub (licences non vérifiées). Article CC BY-SA 4.0.
Déduction de l'agent : protocole d'audit d'erreurs insérées comme référence pour le sabotage diffus, à condition de fixer la difficulté des corruptions a priori.

## 2. Transformers converge to invariant algorithmic cores — arXiv:2602.22600 (v3, 9 novembre 2026 ; NeurIPS 2026), Joshua S. Schiffman
Question : des transformers entraînés séparément convergent-ils vers des sous-espaces d'activations nécessaires et suffisants, invariants d'un entraînement à l'autre ? Méthode : extraction de cœurs (décomposition en valeurs singulières de H·Jᵀ, activations centrées et jacobiens) ; ablations de suffisance, de nécessité et contrôle inversé ; opérateur linéaire sur les coordonnées du cœur. Résultats : Markov, cœurs de 3 dimensions, recouvrement des projecteurs 0,02 à 0,04 mais corrélation canonique moyenne ≈ 0,99 ; addition modulaire, cœurs formés au « grokking », qui gonflent de 15 à 50 dimensions par redondance sous décroissance des poids prolongée ; loi du temps de grokking τ ∝ ω^−0,95 (R² 0,991) ; accord sujet-verbe : un axe unique orientable, le retourner inverse le nombre grammatical ; identification d'objet indirect : deux sites reliés par un opérateur qui transfère entre familles de modèles (Llama 3.1, Gemma 2, Qwen 2.5). Incohérence à vérifier entre figure 4 et annexe E. Code : joshseth/cores (MIT).
Déduction de l'agent : une sonde sur une direction peut manquer un calcul redondant ; tester la nécessité sur plusieurs directions.

## 3. Re-Search: Dissecting LLM Ideation Through a Two-Player Questioning Game — arXiv:2611.14487 (10 novembre 2026), Gao, Zhu, Su, Zhang, Khashabi, Huang
Question : comment les modèles explorent l'espace des idées de recherche, sans exécution. Méthode : jeu de questions oui/non ; l'inquisiteur ne voit que le problème de 200 articles ICML 2026, pose jusqu'à 100 questions à un répondeur qui lit l'article ; carte d'idée toutes les 10 questions, notée par trois juges. Six inquisiteurs. Résultats : plafond après 30 questions sauf un modèle (§4.1) ; le score à 10 ou 30 questions prédit le score final (r 0,76 à 0,92, §4.2) ; la connaissance n'explique qu'≈ 10 % de l'écart (§5.1) ; un modèle faible qui choisit parmi des questions proposées par d'autres obtient 5,20 à 5,34 contre 4,43 au hasard : le goulot est la génération, non le jugement (§5.2) ; nommer l'idée centrale dans une revue apporte jusqu'à 1,25 point (§5.3) ; 1 200 arbres : sur-exploitation (5,2 à 5,5 branches), sur-exploration (13,7), forts 7,2 à 8,2, pic estimé 8,3 branches (§6). Limites : un domaine, juges modèles (accord humain 91,2 %), contamination possible. Pas de code déclaré. CC BY 4.0.
Déduction de l'agent : nombre de branches et score à la question k comme métriques de diagnostic de l'organisme d'idéation.
