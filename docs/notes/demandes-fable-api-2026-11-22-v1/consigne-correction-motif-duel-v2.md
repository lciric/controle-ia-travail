# Consigne — repérage des duels : l'épreuve aveugle échoue

Ta règle de la correction 43 passe les dix textes de l'épreuve (écrits après coup), mais une épreuve aveugle (trois textes écrits par un agent neuf qui n'a lu que les consignes du collisionneur) échoue sur deux textes sur trois (remarques jointes : rapport et textes). Deux voies : (a) corriger encore la règle (ANCIEN → NOUVEAU) pour couvrir ces formes, avec le risque de courir après les styles ; (b) changer d'approche : pour les dossiers futurs, demander aux modèles, dans la consigne du tour III.1, de marquer chaque duel par une balise fixe (et ne compter que les duels balisés, une omission étant comptée comme telle) ; pour les dossiers déjà joués, une mesure seulement descriptive, sans règle de décision, ou un comptage par deux lecteurs humains. Tranche, écris les corrections au format ANCIEN → NOUVEAU, et dis ce que devient la rétro-analyse des dossiers déjà joués. Verdict. Français. Termine par « FIN DE LA RÉPONSE ».
