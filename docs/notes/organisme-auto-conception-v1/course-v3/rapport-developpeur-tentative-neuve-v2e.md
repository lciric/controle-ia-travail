## 5. Réponses aux points ouverts

1. **Délai de l'orchestrateur : non réglable sans modifier le code épinglé.** Le lanceur ne le passe pas et ne peut pas le passer : `adaptateurs_reels_v56` (`demonstrations/ideation_v8.py`, l. 70) construit `AdaptateurCommandeExterneV56(f["commande"], exiger_modele_servi=True, modeles_servis_permis=…)` **sans `delai_s`** ; le défaut est `DELAI_COMMANDE_S = 1800` (`pole/adaptateurs.py`, l. 622) ; la configuration n'a pas de clé de délai pour une commande externe ; au délai, l'orchestrateur tue tout le groupe (`os.killpg`, SIGKILL) **sans annuler le lot**. Un `--delai-s 3000` aurait donc fait tuer Carbon à 1 800 s, coût compté au plafond de session, lot laissé à courir. **Le lanceur v5 refuse toute durée au pire au-delà de 1 770 s**. Retenu : `--delai-s 1500` écrit (défaut ; 1 500 + 30 + 2 × 120 = 1 770 s). Propositions : (a) **retenue** : garder 1 500 s ; (b) admise par le lanceur sans version neuve : `--delai-s 1620 --delai-requete-s 60` (même borne de 1 770 s, +120 s de lot, au prix d'un délai de 60 s pour le compte de jetons et la création du lot — un dépassement là rend un échec, et un lot créé mais non reconnu courrait sans être annulé) ; (c) le vrai relèvement : une version neuve de l'orchestrateur qui lise un `delai_s` par fournisseur (nœud : changement d'un code épinglé, hors de cette tentative). Recommandation : (a) ; confiance moyenne (un lot sur cinq a dépassé 1 500 s en v4 ; on ignore de combien).
2. **Pire cas d'un appel de Carbon sous 3 USD : oui.** Avec la provision 32 768 et la sortie 16 384 : **2,436697 USD** (compte de la commande, caractères / 3), **2,635142 USD** (borne prudente du lanceur, octets / 2), sur la plus grande entrée (136 622 octets). Avec la sortie 32 768 : la commande ramène `maxOutputTokens` à ≈ 29 950 et le pire cas vaut **3,00 USD**, au plafond. La commande garantit de toute façon pire ≤ plafond de session (sinon code 4, rien envoyé).
3. **Astra, reprise unique sur 502 : impossible sans modifier un code épinglé.** Ni le noyau (aucune reprise d'un rôle en erreur), ni l'adaptateur de commande externe (un code non nul = statut « erreur »), ni la commande épinglée (`986cf71e…` : un HTTP 502 rend le code 5, coût au pire cas, aucune boucle) ne la permettent ; la commande n'est pas touchée. Forme la plus sûre, **proposée, non écrite** : une enveloppe neutre neuve (`reprise_502_astra_v1.py`, épinglée par la pièce, contre-lue, essayée), placée entre la garde de crédit et la commande d'Astra, qui rejoue **une seule fois** la même consigne si et seulement si la commande sort au code 5 avec une dernière ligne dont l'erreur commence par « HTTP 502 » et contient « amont coupé », et rend la seconde ligne avec `cout_usd` = coût du premier appel (pire cas, imputé par le relais) + coût du second, et `reprise: 1`. Limite à trancher avant de l'écrire : sur les grandes cases, le premier pire cas (≈ 2,95 USD) plus le second dépassent le plafond de session de 3 USD ; l'adaptateur rend alors « budget_depasse » (texte servi), dont l'effet sur le noyau pour un proposeur **n'a pas été vérifié**. Recommandation : accepter l'aléa pour cette tentative (risque déjà accepté par la pièce ; une coupure sur onze en v4) ; écrire l'enveloppe ensuite, après lecture du noyau. Confiance moyenne.
4. **Épreuve des témoins neuve : exigée le jour de la tentative.** Le préenregistrement exige un rapport « réussie », **du jour**, aux empreintes du lanceur qui part ; le lanceur vérifie `horodatage_utc` (jour) et `empreintes.lanceur` (sa propre empreinte). Le rapport v4 cite le lanceur v4 et le 18 novembre : il ne vaut pas. Le programme v4 ne peut pas la rejouer (rapport existant, `GO-2026-11-18-36` échue) : **programme v5** écrit (§ 3), sous une ligne neuve de 5 USD.
5. **Devis : 59,81 USD à l'estimation (course 58,55 ; épreuve 1,20 ; sonde ≤ 0,05), 95,05 USD au pire.** Les ≈ 45 USD attendus sont le coût de la v4, arrêtée après la seule étape « proposition » (aucun aiguillage, aucun juge, 5 appels de Carbon sur 11). **La ligne de GO de la course doit porter exactement 90 USD** : l'orchestrateur exige de la ligne le montant du plafond d'arrêt à l'identique (`montant_requis`, portée « course » ; `verifier_go_v56`), et le lanceur aussi ; une ligne de 45 USD serait refusée avant tout appel. Seuil à garder en tête : les juges ne partent que si le cumul après l'aiguillage est ≤ 60 USD (estimation 50,67).
6. **Clé Claude : code 3 certain aux chiffres de la pièce v2.** Dépense antérieure 32,269175 USD (relevé v4 7,479689 + course v4 24,789486), plus l'épreuve v5 (≈ 1,00) ; crédit déclaré 124, réserves 18 : reste net ≈ **72,73 ≤ 90** → alerte, départ refusé.
