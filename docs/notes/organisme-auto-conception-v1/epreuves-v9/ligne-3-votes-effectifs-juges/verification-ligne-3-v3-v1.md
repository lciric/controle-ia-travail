**B. Banc du double rendu : le lecteur de surface rejette les faux confondus, ce qui retire à la clause (i) la menace même qu'elle mesure (à corriger avant scellement).** Sur le banc, le lecteur de surface dit « non notable » quand le trait est présent ; or seuls les faux portent le trait. Le confondant **aide** donc à rejeter les faux : il n'y a aucune acceptation de faux par la surface à retirer, et le double rendu, en changeant ce vote juste en abstention, ne peut qu'augmenter les faux acceptés. C'est exactement ce que trouve P5 ter : la clause (i) est « réfutée » dans toutes les cellules **par construction**, et, comme le bras 2 reste sous 0,001 partout, le mot « tient » est inatteignable pour la carte sur ce banc. La contradiction entre P5 (écrite sur cette intuition) et P5 ter vient de là, non d'une erreur de calcul. Une épreuve qui ne peut rendre qu'un mot contre une carte est le défaut que la règle R4 vise. Ce défaut était déjà dans les versions 1 et 2 ; je ne l'avais pas relevé ; P5 ter le rend visible.
