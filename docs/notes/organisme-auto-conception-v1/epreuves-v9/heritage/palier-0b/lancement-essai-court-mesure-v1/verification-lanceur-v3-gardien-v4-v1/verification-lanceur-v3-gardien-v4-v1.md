**Objets de contrôle.**
- Commande : faux par construction (`-b`, racine à `/`) → attendu « différent », rendu « différent » ; vrai (le lanceur) → égal.
- Refus : faux (21 variantes) → refus du bon code sauf les liens ajoutés (cas où le mécanisme devait échouer et a échoué : défaut montré) ; vrai (copie saine) → 0.
- Arrêt de durée : faux (heure non atteinte) → aucun arrêt, rendu aucun arrêt ; vrai (heure atteinte) → arrêt, rendu arrêt ; identité fausse → aucun signal, rendu aucun signal.
