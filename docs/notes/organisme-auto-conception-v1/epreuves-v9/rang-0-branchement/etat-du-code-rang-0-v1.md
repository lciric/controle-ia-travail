## 3. Côté orchestrateur : ce qui manque (exige une version d'orchestrateur ; rien n'y est changé ici)

1. **L'héritage de la sélection est illisible par la génération v56.** `heritage_depuis_selection` rend du texte Markdown (« # Héritage : … », puis « - nom : énoncé ») ; `GenerationV56` hérite de `GenerationV54._heritage_garde` (`course2_v54.py` l. 120-123), qui fait `json.loads(self.heritage)`. Constaté deux fois en moteur simulé : la génération 2 commence (quatre lignes de plafond au journal de consommations), puis la course s'arrête, `arret = "JSONDecodeError : Expecting value: line 1 column 1 (char 0)"` (`essai-a-blanc-v1/v10-allume/orchestrateur/bilan-course.json`, sha256 `094e8bfca9f617782a0172024e651edda3ecd20d1a5b2ba7325ebca4e0920167`), et la même erreur rejouée sur la seule méthode (`_heritage_garde` appelée sur le texte de la v59, bloc-notes). L'essai `essais/test_v59_boucle_fermee.py` éprouve `heritage_depuis_selection` seule et le câblage du lanceur v59, jamais une course de deux générations ; le défaut ne s'y voit pas. De plus le titre servi resterait « titres, résumés, verdict agrégé », faux pour la sélection.
2. **Aucun étage après la dernière génération.** `course2_v56.py` l. 426 et `course2_v59.py` l. 91 : `g < nombre_generations`. Avec une génération, aucun test de mort ; avec deux, la deuxième lit un héritage (v56 : le classement des juges ; v59 : la sélection). **Il n'existe donc aucun chemin « tests de mort réels sans rien servir »**, dont la plupart des lignes de l'ordre v3 ont besoin (§ 5).
3. **Budget remis à zéro à chaque génération.** `noyau_v56.py` l. 106 : `BudgetV56` construit par génération ; `course2_v56` ne reporte aucun cumul. Avec la portée « course » de la configuration v5, la ligne de GO porte S17 (150 USD) pour N générations qui peuvent chacune dépenser jusqu'à S17. Côté lanceur, la v10 exige la portée « par_generation » (§ 4) ; côté orchestrateur, refuser N > 1 en portée « course », ou reporter le cumul, serait plus sûr.
4. **Le vrai bac à sable n'a jamais tourné avec l'étage v5** (docstring de `tests_de_mort_v5.py`) ; l'étage entier n'a jamais été lancé en réel (`tests_de_mort_v2.py`, l. 29).
