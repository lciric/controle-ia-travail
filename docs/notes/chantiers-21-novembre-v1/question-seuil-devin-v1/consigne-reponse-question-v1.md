# Consigne

Tu reçois une question (pièce jointe). Réponds-y comme elle le demande, en français, sans sigle seul, dans la limite de mots qu'elle fixe. Marque chaque affirmation : FAIT RAPPORTÉ, HYPOTHÈSE, PROPOSITION ou CALCUL. Toute antériorité est citée avec son statut (« de mémoire, non vérifiée » sauf lecture attestée).
