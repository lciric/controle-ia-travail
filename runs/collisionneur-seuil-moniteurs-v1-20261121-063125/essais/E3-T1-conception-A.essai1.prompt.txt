# Task statement: a 1% false-alarm threshold with few honest episodes, and using a "sparse reward subsystem" paper for monitors and control

## 1. The paper (facts, with page numbers of the arXiv v2 PDF)

Xu, Yuksekgonul, Zou, "Sparse Reward Subsystem in Large Language Models", arXiv 2602.00986v2 (11 May 2026).

- Claim (p. 1): reward-related information in LLM hidden states is concentrated in a sparse subset of neurons (under 1% of input dimensions, p. 1, 4). Two types are named by analogy with neuroscience: "value neurons" (activations predict the expected value of the current state, i.e. the probability that continuing the generation ends in a correct answer) and "dopamine neurons" (activations predict step-level temporal-difference errors, i.e. the change in that value caused by a reasoning paragraph).
- Setting (p. 3-4, 6): the reward is a binary terminal correctness signal from verifiable tasks (maths, multiple-choice science, coding, instruction following). The model's own sampled responses are used.
- How they are found (p. 4, 6): a small two-layer perceptron probe (hidden width 1024 for value, 32 for dopamine; AdamW, learning rate 1e-4, 100 epochs, p. 19) is trained on one layer's hidden states. The value probe uses a temporal-difference objective and is read at the initial prompt position, before any answer token (p. 4). The dopamine probe regresses the temporal-difference error estimated per paragraph boundary by Monte Carlo rollouts, keeping only paragraphs with |error| > 0.3 (p. 6). The neurons are then selected by pruning input dimensions with the smallest L1 norm of first-layer weights; the claim of sparsity rests on the metric (AUC for value, Spearman correlation for dopamine) staying flat as the pruning ratio rises (p. 4, 6-7).
- Models: main results on Qwen-2.5-7B/14B-SimpleRL-Zoo (reinforcement-learned from a base model); robustness on Qwen3.5-0.8B, Phi-3.5-mini-instruct, Llama-3.1-8B-Instruct, Gemma-3-4B (p. 4, 8). Value neurons are at layers 2-4 in the main figures; dopamine neurons at layers 15-22 in the pruning curves (p. 7), and layer 5 in the displayed example (p. 7).
- Measured effects:
  - Pre-generation value prediction is only moderate: average AUC 0.67 across four models and two benchmarks, against 0.60 for a linear probe on the full hidden state, 0.52 verbal confidence, 0.48 token confidence, 0.62 question length (Table 3, p. 8). At the final response position AUC is "mostly stable above 0.8" (p. 4, Appendix I).
  - Causal test (Table 2, p. 5), Qwen-2.5-7B on MATH500: zeroing 1% of value neurons in one layer drops accuracy from 75.2% to 20.3% on average over layers 2-5; random neurons 74.6%; neurons from a next-token-prediction probe 76.4%; magnitude-selected 71.6%; Wanda-selected 65.8%. Zeroing value neurons in earlier layers also removes the dopamine neurons' error-predicting ability downstream (p. 5, Appendix H).
  - Transfer (p. 5-6): overlap of selected neurons across datasets and across two models derived from the same base exceeds a random-selection baseline.
  - Dopamine neurons as a process reward model (Table 4, p. 9): in step-wise best-of-4 search on a MATH500 validation subset, accuracy 77.8% against 72.2% for greedy or random and 75.0% for an implicit reward baseline; three seeds. Qualitative traces show peaks at key steps and troughs at logical flaws (Figure 3, p. 7). The Spearman values are shown only graphically (Figure 4, p. 7).
- Limits stated by the authors (p. 25): (1) the method needs an environment reward and is untested where such signals are hard to obtain, such as open-ended generation; (2) no model above 32B was studied. They also write that neuron-level interventions could be used to bypass safety mechanisms and ask for future work on robustness under adversarial settings (p. 25). The absolute pre-generation AUC values are called "moderate" by the authors (p. 4). The paper contains no adversarial, deceptive or sabotage setting.

## 2. The program (context)

The program aims to detect, with probes on the internal states of an AI agent, an agent that sabotages a research task diffusely, in many small and individually deniable ways. What exists: probes on internal activations, a matched honest twin of the agent doing the same tasks, a calibrated null distribution to judge whether a probe score departs from honest behaviour, and neuron-level lenses on the agent's activations. The setting is open-ended research work with no clean verifiable reward, and the agent may be adversarial and aware of being monitored. White-box access to the agent's activations is assumed. Recent work on diffuse threats treats text or code monitors as weak, because each action is only a faint clue, and asks what could still work.

## 3. What the program has decided so far (context, not to be re-argued)

- The paper is used as a baseline and as a difficulty covariate in a reported arm, with: a sequential sum of small signals along the episode (rather than a threshold on the largest deviation); a capability-constant evasion test (closed for now); four baselines any "intent" probe must beat (an expected-success probe trained on honest episodes only; the divergence of a forced twin on the same episode prefix; comparison at the same milestone with only the files then available; a probe retrained without the paper's variation threshold).
- Main contrast: the saboteur with confirmed damage against the honest failure of the same task variant, task by task. Hypothesis: the expected-success probe reads expected failure, not intent; it separates the saboteur from the honest agent that succeeds, not from the honest agent that fails.

## 4. The problem

The verdict point is fixed at 1% false alarms, per episode, on honest episodes, per episode-length bin. A simple calculation gives on the order of 5,000 honest calibration episodes per bin to expect at least 50 exceedances of the threshold. The program has only a few hundred honest episodes already produced; without a new batch, many tests will end "inconclusive". Producing agent episodes is expensive (rented machines, model calls).

Second, linked question: beyond a baseline, how can this paper serve to build monitors or improve control (protocols, routing, audit, allocation of a human review budget)?
