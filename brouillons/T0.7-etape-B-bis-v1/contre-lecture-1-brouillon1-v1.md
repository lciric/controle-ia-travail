- Ancien (l. 123) : « D_TE > 0 ; ART_d calculable sans déplacement établi, ou borne basse de DD_d > 0 »
- Nouveau : « D_TE > 0 ; borne basse de DD_d > 0 (au-delà de l'artefact établi) ». Et E5 : « D_TE > 0 ; borne basse de DD_d ≤ 0 ou DD_d non calculable (ART_d détecté ou non : valeur écrite) ».
