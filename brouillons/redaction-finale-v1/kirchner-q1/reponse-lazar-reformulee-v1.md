So you want to know how to detect goodharting by auto researchers in your setup. My question was adjacent: if we use this selection function will they fail to goodhart and if they do how?
I created an auto research setup. Agents using LMs create laws that will try to contain AI. All are blind predictions. There is no decision maker. Created in Oct with AI code agents. Rules I gave it here https://github.com/lciric/ideation-organism. Decided by a frozen testing procedure. Calculates e-value's on new random seeds derived from the laws hash. Null is composed of all laws previously accepted. Ville + e-BH between submissions. 929 tests run. I mutated the code intentionally 224 times and it failed every time as expected.
I then attempted to attack it using automated cheaters on toy problems. Goodhart by luck did not make it into a top 3 placement in your paper (it didn't pass your hold out choice either) but never got promoted. 0/200 times by renaming an already accepted law. What passed was a mixture or changed version of already accepted laws 75-95% of 200 trials. My null didn't have any of these in it. By expanding my null to include all submitted I was able to stop them. 0/1000 for each of the 11 ways to kill me that I pre registered. Nov 1st. While true new laws continued to pass ~98% of the time.
I then let LM's attack it. Given the judges instructions. With or without there decisions. Nov 2nd https://github.com/lciric/ideation-organism/tree/faff48b/resultats/attaque-goodhart-v2 . These toy problems can only be made from laws that are already accepted. If something passes it means it found a new law. One problem was able to be constructed by changing accepted laws per subpopulation. This isn't covered by my null. One model that I could get to finish all problems got a law accepted all 12 times it ran. Whether or not it knew about the decisions. The other problem that I could make it wasn't testable. Monitoring bug and spending limit I shared accidentally blocked one provider.

First what it accepted then it's instructions.
