**Pont UCB #7** (Freidlin-Wentzell/quasipotentiel ↔ temps de sortie métastable/importance splitting) se compose avec les articles documentaires [Art.1–4, Art.7, Art.10] pour former l'opérateur **A : espace de trajectoires SDE → quasipotentiel V(x)** via le solveur EJM/OLIM (Dijkstra anisotrope). L'opérateur **B : V(x) → distribution des temps de sortie** via la formule de Bouchet-Reygner/Kramers généralisée. La composition **B∘A** mappe directement les dynamiques de déférence/séquentialité d'un LLM vers des *bassins d'attraction métastables* dont les temps d'échappement sont exponentiellement rares — ce qui constitue le substrat formel pour analyser les failles de contrôle.

**Pont UCB #8** (RIP/cohérence mutuelle ↔ OMP/dictionnaire incohérent) s'articule avec les colmatages O-SAE/MP-KVP de Gen 8 : l'auto-encodeur parcimonieux suppose implicitement que la RIP est satisfaite dans l'espace KV. Or la cohérence mutuelle du dictionnaire atomique n'est pas vérifiée sous distribution hors-équilibre.

## 2. Quatre Failles d'Ordre 12 et leurs Parades

### Faille 12-α : Dégénérescence du quasipotentiel sous bruit multiplicatif (Paper A, T0.3)
**Pont bisociatif** : [EJM quasipotentiel 2D, Art.1] × [importance splitting rare event] → B∘A = *solveur de quasipotentiel adaptatif pour bruit non-additif*. Le colmatage PKSD-OM suppose un bruit additif gaussien. Sous bruit multiplicatif (token-dépendant), le quasipotentiel V(x) n'est plus solution d'une HJB standard — les MAPs se déforment, rendant les signatures Onsager-Machlup invalides.
**Opérateur** : Hamiltonien généralisé H(x,p) = p·f(x) + ½p·σ(x)σᵀ(x)·p avec σ state-dependent.
**Protocole falsifiable** : Métrique = distance L∞ entre MAPs calculés sous bruit additif vs multiplicatif sur Maier-Stein. Seuil : >15% déviation sur 50 trajectoires. Coût : simulation Python/JAX sur Colab gratuit ≤ 2$.

### Faille 12-β : Violation RIP sous coalescence d'atomes KV (Sondes P3/P4)
**Pont bisociatif** : [OMP/cohérence mutuelle, Pont #8] × [O-SAE/MP-KVP Gen 8] → B∘A = *test de cohérence mutuelle dynamique du dictionnaire KV*. Quand des têtes d'attention convergent vers des atomes quasi-colinéaires (coalescence), la RIP est violée localement, rendant la reconstruction parcimonieuse instable.
**Opérateur** : μ(D) = max_{i≠j} |⟨dᵢ,dⱼ⟩| ; violation si μ > 1/√(2k-1).
**Protocole** : Mesurer μ(D) sur le KV-Cache de Llama-3-8B (couches 16-24) sous prompts répétitifs. Seuil : μ > 0.4 sur >30% des paires. Coût : HuggingFace inference gratuit ≤ 1$.

### Faille 12-γ : Instabilité de la courbure ORC-Hodge sous transitions de phase métastables (Paper C, T2/T2d)
**Pont bisociatif** : [métastabilité/Koopman, Art.10] × [ORC-Hodge Gen 8] → B∘A = *spectre de Koopman comme détecteur de transitions de courbure*. Le mode subdominant de Koopman signale les reconfigurations de phase avant que la courbure d'Ollivier-Ricci les détecte — créant une fenêtre aveugle de déférence.
**Opérateur** : Décalage temporel Δt entre premier passage du mode Koopman λ₂ sous seuil et signe de κ_OR.
**Protocole** : Sur système bistable [Art.10], mesurer Δt. Seuil réfutation : Δt > 3τ_Kramers. Coût ≤ 1$.

### Faille 12-δ : Séparation de phase d'intrication multi-agents sous heavy tails (Paper B)
**Pont bisociatif** : [grandes déviations heavy-tail, Art.7] × [importance splitting, Pont #7] → B∘A = *opérateur de troncature φ_b comme régulateur de l'intrication tensorielle multi-agents*. ### Faille 12-β — Effondrement de la séparation Koopman en présence de métastabilité quantifiée (Sondes P3/P4, Art.8/Art.10)
Art.8 (Cihak) montre que les amplitudes quantifiées du bump neural créent des **modes Koopman dégénérés** dont les taux de décroissance se confondent. ### Faille 12-δ — Troncature heavy-tail et perte du principe de grandes déviations (Paper B, Art.7)
Art.7 (Wang & Rhee) prouve que la troncature φ_b modifie fondamentalement l'asymptotique des grandes déviations.
