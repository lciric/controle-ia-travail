# Analyse formelle : Méta-conception du moteur bisociatif v6.3

## 1. Chaîne de raisonnement et réponse structurée

### 1.1 Limites mathématiques exactes des trois modules actuels

**`_score_pertinence_texte`** opère par recouvrement lexical (intersection de sacs de mots normalisés). Sa limite fondamentale est l'absence de géométrie sémantique : deux articles partageant zéro token mais occupant des régions voisines dans l'espace conceptuel reçoivent un score nul. Formellement, si `s(A,Q) = |V_A ∩ V_Q| / |V_Q|`, alors `s` est une pseudo-métrique de Jaccard dégénérée — symétrique mais aveugle aux synonymies et aux analogies structurelles inter-domaines. C'est précisément là que la bisociation (Koestler) échoue : les ponts les plus fertiles relient des vocabulaires *disjoints*.

**`memoire_isvd.py` / SHA-256** : le hachage SHA-256 vers ℝ¹⁶ est une projection *aléatoire non contrôlée*. La propriété de Johnson-Lindenstrauss garantit la préservation des distances euclidiennes pour des vecteurs denses, mais ici les vecteurs d'entrée sont des entiers de hachage — leur géométrie est uniforme par construction cryptographique, donc *maximalement non-informative* pour la similarité sémantique. La projection de Koopman `[v, sin(v), v²]` introduit une non-linéarité, mais appliquée à du bruit uniforme, elle produit un espace de features pseudo-aléatoire sans structure exploitable. Le bonus `+15 % multi-familles` est heuristique non fondé analytiquement.

**`mitose_spectrale.py` / répulsion d'Onsager** : la matrice de Gram `G_ij` est construite sur des vecteurs TF-IDF ou lexicaux, donc souffre du même biais lexical que `_score_pertinence_texte`. La capacité de Shannon `0.5 * log det(I + SNR * G)` mesure la diversité *lexicale* du corpus sélectionné, non la diversité *structurelle* des opérateurs mathématiques ou des méthodes. La répulsion d'Onsager évite les doublons terminologiques mais pas les redondances conceptuelles profondes.

### 1.2 Loi optimale de tirage conjoint et opérateur de synthèse

**DPP bilinéaire Domaine × Opérateur** : le tirage d'un k-uplet `{a₁,...,aₖ}` devrait suivre une distribution déterminantale `P({a₁,...,aₖ}) ∝ det(L_S)` où `L` est un noyau de qualité-diversité bilinéaire :

```
L_ij = q(aᵢ) · φ(aᵢ)ᵀ · φ(aⱼ) · q(aⱼ)
```

avec `q(a)` = score de qualité (pertinence à la question), et `φ(a)` = vecteur de *signature opératoire* de l'article (type de preuve, structure de l'opérateur principal : variationnel, spectral, stochastique, topologique). En Python pur, `φ` peut être approximé par un dictionnaire de motifs syntaxiques extraits par regex sur l'abstract (termes `"gradient"`, `"eigenvalue"`, `"martingale"`, `"sheaf"`, etc.) normalisés en vecteur binaire de dimension ~50. Le déterminant de la sous-matrice `k×k` se calcule par Cholesky incrémental — coût `O(k²·d)`, compatible C-01 à C-17.

**Bandit contextuel de ponts Swanson A↔B↔C** : chaque article est un nœud, une arête `(aᵢ, aⱼ)` porte un poids `w_ij = MI(Xᵢ ; Xⱼ | Q)` (information mutuelle conditionnelle à la question). En pratique, `MI` est approchée par cooccurrence de termes-ponts dans les abstracts : si `aᵢ` contient `{gradient, Onsager}` et `aⱼ` contient `{Onsager, optimal transport}`, le terme-pont `Onsager` crée un arc de valeur `log(P(Onsager|aᵢ,aⱼ) / P(Onsager|aᵢ)·P(Onsager|aⱼ))`. Le bandit UCB sélectionne à chaque génération le triplet `(A,B,C)` maximisant `Σ w_AB + w_BC + bonus_exploration / √n_tirages`.

**Synergie Williams-Beer** : la synergie `Syn(X₁;X₂→Y)` mesure l'information sur `Y` (la question) que `X₁` et `X₂` fournissent *ensemble* mais pas séparément. Approximation tractable en Python pur : `Syn ≈ MI(X₁,X₂;Y) - MI(X₁;Y) - MI(X₂;Y) + Red(X₁;X₂;Y)` où la redondance `Red` est bornée par `min(MI(X₁;Y), MI(X₂;Y))`. Cela identifie les paires dont la combinaison est super-additive — exactement les paires bisociatives fertiles.

**Pushout catégoriel `B ∘ A`** : l'opérateur de synthèse est une somme amalgamée dans la catégorie des espaces de concepts. Si `A` et `B` partagent un sous-concept `C` (terme-pont Swanson), le pushout `A ⊔_C B` est le nouvel espace conceptuel minimal contenant les deux et identifiant `C`. En Python, cela se traduit par la fusion de deux graphes de termes avec identification des nœuds-ponts et propagation des arêtes — implémentable avec des dictionnaires natifs.

```python
# MODULE: bisociation_dpp.py (v6.3)

import math, hashlib, re
from itertools import combinations

# --- Signature opératoire (φ) ---
OPERATEURS = [
    "gradient", "eigenvalue", "martingale", "sheaf", "kernel",
    "variational", "spectral", "stochastic", "topological", "optimal transport",
    "conformal", "Bayesian", "causal", "symplectic", "ergodic",
    "manifold", "entropy", "divergence", "Lagrangian", "Hamiltonian",
    "fixed point", "contraction", "measure", "cohomology", "diffusion"
]

def signature_operatoire(texte: str) -> list:
    """Vecteur binaire de présence d'opérateurs mathématiques."""
    t = texte.lower()
    return [1 if op in t else 0 for op in OPERATEURS]

def norme(v):
    n = math.sqrt(sum(x*x for x in v))
    return n if n > 0 else 1.0

def cosine(v1, v2):
    return sum(a*b for a,b in zip(v1,v2)) / (norme(v1) * norme(v2))

# --- Noyau DPP bilinéaire ---
def noyau_L(articles: list, scores_qualite: dict) -> list:
    """
    L_ij = q(i) * cos(phi_i, phi_j) * q(j)
    articles: liste de dicts avec 'id', 'texte'
    """
    n = len(articles)
    phis = [signature_operatoire(a['texte']) for a in articles]
    L = [[0.0]*n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            qi = scores_qualite.get(articles[i]['id'], 1.0)
            qj = scores_qualite.get(articles[j]['id'], 1.0)
            L[i][j] = qi * cosine(phis[i], phis[j]) * qj
    return L

def det_sous_matrice(L, indices):
    """Déterminant par élimination de Gauss (Python pur, O(k^3))."""
    k = len(indices)
    M = [[L[i][j] for j in indices] for i in indices]
    det = 1.0
    for col in range(k):
        pivot = None
        for row in range(col, k):
            if abs(M[row][col]) > 1e-12:
                pivot = row; break
        if pivot is None: return 0.0
        M[col], M[pivot] = M[pivot], M[col]
        if col != pivot: det *= -1
        det *= M[col][col]
        for row in range(col+1, k):
            f = M[row][col] / M[col][col]
            for c in range(col, k):
                M[row][c] -= f * M[col][c]
    return abs(det)

# --- Termes-ponts Swanson ---
def extraire_termes(texte: str, top_n=20) -> set:
    tokens = re.findall(r'\b[a-z]{4,}\b', texte.lower())
    freq = {}
    for t in tokens:
        freq[t] = freq.get(t, 0) + 1
    triés = sorted(freq, key=lambda x: -freq[x])
    return set(triés[:top_n])

def poids_swanson(a1: dict, a2: dict) -> float:
    """Information mutuelle approchée par termes-ponts partagés."""
    t1 = extraire_termes(a1['texte'])
    t2 = extraire_termes(a2['texte'])
    ponts = t1 & t2
    if not ponts: return 0.0
    # Approximation: log(|ponts|+1) / log(|t1|+|t2|-|ponts|+1)
    return math.log(len(ponts) + 1) / math.log(len(t1) + len(t2) - len(ponts) + 2)

# --- Synergie Williams-Beer approchée ---
def synergie_wb(a1: dict, a2: dict, question_termes: set) -> float:
    """
    Syn ≈ MI(a1,a2;Q) - MI(a1;Q) - MI(a2;Q)
    approximé par recouvrement de termes-ponts avec Q
    """
    t1 = extraire_termes(a1['texte'])
    t2 = extraire_termes(a2['texte'])
    t12 = t1 | t2
    mi_joint = len(t12 & question_termes) / (len(question_termes) + 1)
    mi1 = len(t1 & question_termes) / (len(question_termes) + 1)
    mi2 = len(t2 & question_termes) / (len(question_termes) + 1)
    return mi_joint - mi1 - mi2  # positif = synergie, négatif = redondance

# --- Sélection DPP greedy de k articles ---
def selectionner_dpp_greedy(articles, scores_qualite, k=5):
    """
    Sélection greedy maximisant det(L_S) par ajout séquentiel.
    Complexité : O(n * k^3)
    """
    L = noyau_L(articles, scores_qualite)
    n = len(articles)
    selectionnes = []
    candidats = list(range(n))
    for _ in range(k):
        meilleur, meilleur_score = None, -1.0
        for c in candidats:
            indices = selectionnes + [c]
            score = det_sous_matrice(L, indices)
            if score > meilleur_score:
                meilleur_score = score
                meilleur = c
        if meilleur is None: break
        selectionnes.append(meilleur)
        candidats.remove(meilleur)
    return [articles[i] for i in selectionnes]

# --- Pushout catégoriel (fusion par termes-ponts) ---
def pushout_conceptuel(a1: dict, a2: dict) -> dict:
    """
    Somme amalgamée : graphe de termes fusionné avec identification des ponts.
    Retourne un dict représentant l'espace conceptuel hybride.
    """
    t1 = extraire_termes(a1['texte'], top_n=30)
    t2 = extraire_termes(a2['texte'], top_n=30)
    ponts = t1 & t2
    termes_a = t1 - ponts
    termes_b = t2 - ponts
    return {
        'ponts': ponts,
        'termes_a': termes_a,
        'termes_b': termes_b,
        'termes_fusionnes': t1 | t2,
        'score_fertilite': len(ponts) * math.log(len(termes_a) + len(termes_b) + 1)
    }

# --- Bandit UCB sur triplets Swanson ---
class BanditSwanson:
    def __init__(self):
        self.compteurs = {}   # (id1,id2): n_tirages
        self.recompenses = {} # (id1,id2): somme_recompenses

    def score_ucb(self, paire, w_base, t_total):
        n = self.compteurs.get(paire, 0)
        mu = self.recompenses.get(paire, 0.0) / (n + 1e-9)
        exploration = math.sqrt(2 * math.log(t_total + 1) / (n + 1))
        return mu + w_base * exploration

    def selectionner_triplet(self, articles, question_termes, t_total):
        meilleur_score = -1.0
        meilleur_triplet = None
        for i, j, k_idx in combinations(range(len(articles)), 3):
            a, b, c = articles[i], articles[j], articles[k_idx]
            w_ab = poids_swanson(a, b)
            w_bc = poids_swanson(b, c)
            syn = synergie_wb(a, c, question_termes)
            score = (self.score_ucb((a['id'],b['id']), w_ab, t_total) +
                     self.score_ucb((b['id'],c['id']), w_bc, t_total) +
                     syn)
            if score > meilleur_score:
                meilleur_score = score
                meilleur_triplet = (a, b, c)
        return meilleur_triplet

    def mettre_a_jour(self, paire, recompense):
        self.compteurs[paire] = self.compteurs.get(paire, 0) + 1
        self.recompenses[paire] = self.recompenses.get(paire, 0.0) + recompense
```

## 2. Incertitudes et limites

**Non vérifié** : l'approximation de `MI` par cooccurrence de termes-ponts est une heuristique — la vraie information mutuelle nécessiterait des distributions de probabilité sur l'espace conceptuel, inaccessibles sans embedding dense. **Condition de réfutation** : si P1 montre que v6.3 ne dépasse pas 25 % de paires synergiques, la thèse que le DPP bilinéaire améliore la bisociation est réfutée et il faudrait reconsidérer la définition de `φ`.

### 1) Réponse et chaîne de raisonnement : Vérification des prémisses et régularisation duale

**A. Pathologies cachées de `v6.2.1` et critique des prémisses de la Caste #1**
1. **`_score_pertinence_texte`** est une forme linéaire séparable $S(A) = \sum_{a \in A} s(a)$. Elle maximise la redondance intra-domaine et aveugle le tirage aux complémentarités opératoires.
2. **Hachage SHA-256 dans `memoire_isvd.py`** : Effet d'avalanche cryptographique ($\mathbb{E}[\langle h(w_1), h(w_2)\rangle] = 0$ pour $w_1 \neq w_2$). La non-linéarité de Koopman $[v, \sin(v), v^2]$ appliquée sur du bruit blanc amplifie la variance isotrope : le spectre ISVD ($\sigma_1 = 269.0 \gg \sigma_6 = 4.41$) capture la fréquence brute des tokens et détruit la topologie des graphes d'opérateurs.
3. **Répulsion d'Onsager dans `mitose_spectrale.py`** : Pénaliser les `termes_satures` au niveau atomique interdit la réutilisation des *termes-pivots* ($B$ dans le pont de Swanson $A \leftrightarrow B \leftrightarrow C$, [Art.7, Art.11]). Sans $B$, le poussé catégoriel s'effondre en produit libre disjoint (chimères).

*Contre-exemple à la Caste #1 :* Un noyau DPP bilinéaire $L = K_{\text{op}} \circ (J - K_{\text{dom}})$ n'est **pas garanti semi-défini positif (PSD)** car la matrice complémente $J - K_{\text{dom}}$ possède des valeurs propres négatives dès que le rang $> 1$, faisant échouer la factorisation de Cholesky. De plus, l'information mutuelle de Williams-Beer est sous-échantillonnée sur des résumés courts ($N < 200$ mots).

**B. Formulation mathématique corrigée : DPP sur Graphe de Ligne et Pushout Pondéré**
1. **Noyau L-ensemble PSD et Graphe de Ligne ([Art.10]) :** Pour garantir $L \succeq 0$, chaque article $i$ est projeté sur deux dictionnaires fixes de taille $D=16$ : domaine $\hat{d}_i \in \mathbb{S}^{15}$ et opérateur formel $\hat{o}_i \in \mathbb{S}^{15}$. On définit la matrice de caractéristiques $B_i = \hat{o}_i (\I - \hat{d}_i \hat{d}_i^\top)^{1/2} \in \mathbb{R}^{16 \times 16}$. Le noyau de Gram :
$$L_{ij} = q_i q_j \operatorname{Tr}(B_i^\top B_j) = q_i q_j \langle \hat{o}_i, \hat{o}_j \rangle \left(1 - \langle \hat{d}_i, \hat{d}_j \rangle^2\right)$$
est strictement PSD (produit de Schur de matrices PSD). Inspiré d'ALIGNN ([Art.10]), la répulsion d'Onsager est déplacée des nœuds $w$ vers le **graphe de ligne** $L(G)$ (paires orientées $(w_1 \to w_2)$), préservant les pivots $B$ tout en bloquant les transitions déjà explorées.
2. **Synergie par Surprise de Rényi d'ordre 2 et Bandit Swanson :** La synergie de Williams-Beer sur le triplet $(A, B, C)$ est stabilisée par l'entropie de collision $H_2(X) = -\log \sum p_x^2$ : $\text{Syn}_2(A,C|B) = \max(0, I_2(A;B) + I_2(C;B) - I_2(A;C))$. Le tirage séquentiel suit un score UCB sur les ponts $B$ : $\text{Score}(A,C) = \max_{B} \sqrt{I_2(A;B)I_2(C;B)} + c \sqrt{\frac{\ln t}{n_{AC}+1}}$.
3. **Somme amalgamée (Pushout $A \sqcup_B C$) pondérée par Perspectives ([Art.1, Art.6]) :** En extrayant les triplets relationnels $(s, r, o)$, l'interface $B = O(A) \cap O(C)$ sert d'amalgame. Selon le cadre à 3 personas d'[Art.1], on évalue la validité du pushout par produit scalaire sur 3 vecteurs d'orientation $\vec{u}_{\text{formel}}, \vec{u}_{\text{empirique}}, \vec{u}_{\text{structurel}}$.

**C. Plan d'implémentation Python pur (`v6.3`) et 4 Protocoles Falsifiables**

# Sonde orthogonale : Contre-exemples et axes négligés

## 1. Chaîne de raisonnement — Attaque des prémisses

Les deux positions précédentes convergent sur un noyau DPP couplant similarité d'opérateurs et orthogonalité de domaines. Je teste la solidité de cette prémisse partagée par trois angles orthogonaux.

**Contre-exemple A : Effondrement du DPP en régime creux.** Un DPP sur une matrice L de taille n×n requiert le calcul de det(L_S) pour tout sous-ensemble S. Quand le corpus moissonné par cycle est petit (n ≈ 12-30 articles, ce qui est le cas réel de v6.2.1), le spectre de L est dominé par 2-3 valeurs propres. Le DPP dégénère alors en un échantillonneur quasi-déterministe qui sélectionne toujours le même sous-ensemble modal. La diversité promise est illusoire : on retombe sur un top-k déguisé. Les deux castes ignorent ce régime n≪100 qui est précisément celui de l'organisme.

**Contre-exemple B : Le pont de Swanson A↔B↔C suppose une transitivité sémantique que le hachage SHA-256→dim16 de l'ISVD détruit.** Le hachage projette des vecteurs sémantiques dans un espace pseudo-aléatoire où la distance cosinus entre deux projections est asymptotiquement constante (concentration de la mesure en haute dimension après hachage). Aucun bandit UCB ne peut exploiter un signal de pont si les embeddings intermédiaires sont décorrélés par construction. Avant d'ajouter un bandit Swanson, il faut réparer la représentation.

**Contre-exemple C : La synergie Williams-Beer est calculable analytiquement uniquement pour des variables discrètes à faible cardinalité.** Sur des distributions continues (scores de pertinence), l'estimation par binning introduit un biais O(1/bins) et une variance O(1/n_samples) qui, pour n≈20 articles, rendent la décomposition PID (information partielle) numériquement instable. Aucun seuil falsifiable proposé ne tient.

## 2. Axe complémentaire : Tirage par marche aléatoire sur graphe biparti pondéré

Au lieu du DPP (coûteux, dégénéré en petit n), je propose un **graphe biparti Concepts×Articles** construit incrémentalement. Chaque article est relié aux concepts qu'il mentionne (extraits par TF-IDF sur le corpus local, sans dépendance externe). Le tirage bisociatif devient une **marche aléatoire à temps de mélange contrôlé** : on part d'un article-ancre, on traverse 2 arêtes (article→concept→article'), et on collecte l'article d'arrivée. La probabilité de transition est pondérée par l'inverse de la fréquence du concept-pont (les concepts rares créent des ponts plus fertiles — c'est exactement le mécanisme de Swanson sans bandit).

**Avantage critique** : en Python pur, c'est un dict-of-sets + random.choices, O(1) par tirage. Pas de déterminant, pas de Cholesky, pas d'estimation de PID.

**Protocole falsifiable** : Sur 5 cycles de moissonnage (coût ≤ 2$), comparer le taux de paires d'articles tirées partageant zéro mot-clé commun mais reliées par un concept-pont de degré ≤ 3 dans le graphe. Seuil : la marche aléatoire doit produire ≥ 40% de paires inter-domaines vs ≤ 15% pour le tri par _score_pertinence_texte actuel.

## 3. Incertitudes

- Je ne suis pas sûr que le graphe biparti reste connexe avec n≈20 articles ; en dessous d'un seuil de connectivité, la marche dégénère aussi.
- L'extraction de concepts par TF-IDF local peut être bruitée sans lemmatisation (pas de dépendance externe).

L'analyse critique des propositions émises par les castes précédentes et de l'architecture `v6.2.1` révèle quatre vulnérabilités mathématiques majeures qui menacent la fertilité expérimentale réelle de la future `v6.3` :

**A. Pathologie non-stationnaire de l'expansion de Koopman et effondrement spectral**
Dans `memoire_isvd.py`, le relèvement non-linéaire $[v, \sin(v), v^2]$ appliqué sur des projections aléatoires par hachage en dimension 16 souffre d'une asymétrie d'échelle critique. Sans normalisation sphérique stricte ($\|v\|_2 = 1$) préalable, le terme quadratique $v^2$ domine le spectre de covariance dès que $\|v\|_\infty > 1$, tandis que $\sin(v)$ sature. Cela explique la dégénérescence du spectre ISVD actuel ($\Sigma_1 = 269.0 \gg \Sigma_6 = 4.41$) : la SVD de Jacobi de rang 6 ne capture pas des invariants dynamiques de Koopman, mais la dérive de variance des moments pairs, créant un filtre aveugle aux isomorphismes structurels faibles.

**B. Explosion combinatoire du graphe de ligne et biais des moyennes-hubs**
La Caste #2 propose de déplacer la répulsion sur le graphe de ligne $L(G)$ (inspiré d'ALIGNN, Art.10) pour préserver les pivots de Swanson. Or, un nœud-pivot $B$ de degré $d_B$ dans le graphe d'interactions génère $\binom{d_B}{2} = \mathcal{O}(d_B^2)$ arêtes dans $L(G)$. Pour un corpus moissonné à la volée, les concepts méthodologiques transversaux (« *optimization* », « *matrix* », « *bound* ») agissent comme des hubs qui saturent la matrice de Cholesky en $\mathcal{O}(d_{\max}^6)$, étouffant les véritables ponts bisociatifs rares. Quant à la marche aléatoire pondérée par IDF (Caste #3), elle confond *rareté lexicale* et *compatibilité opératoire* : un terme rare partagé entre deux domaines est souvent une coïncidence terminologique (homonymie inter-disciplinaire) plutôt qu'un foncteur de transfert valide.

**C. Obstruction cohomologique au Pushout Catégoriel ($A \leftarrow B \rightarrow C$)**
La consigne postule que l'opérateur de synthèse procède par somme amalgamée ($A \sqcup_B C$). Mathématiquement, ce pushout n'existe et n'est non-trivial que si les morphismes d'injection $f: B \to A$ et $g: B \to C$ préservent la structure interne de l'opérateur $B$. En texte libre (résumés d'articles), deux domaines peuvent partager le même opérateur nominal $B$ sous des axiomatiques contradictoires (ex: régularité continue vs topologie discrète). Sans vérification de cohérence des pré-conditions, l'amalgamation produit des chimères formelles (hallucinations syntaxiques sans validité expérimentale).

**D. Loi de tirage corrigée et implémentation Python pur**
Pour surmonter ces limites en Python standard (`math`, `collections`), le tirage doit opérer non sur les textes bruts, mais sur des triplets typés `(Domaine, Opérateur, Contrainte_de_validité)` extraits par patrons syntaxiques :

## Brique 1 — SimHash + normalisation sphérique pré-Koopman (`memoire_isvd.py`)

- **Le diagnostic, tel qu'écrit, est faux sur un point vérifiable** : le code v6.2.1 normalise déjà chaque vecteur
  relevé à norme 1 (`extraire_vecteur_koopman`, dernière ligne). « L'élévation quadratique non normalisée écrase le
  spectre » ne peut donc pas être le mécanisme tel quel.
- **Le mécanisme probable** (à confirmer par l'essai a) : (1) `base` — la somme des hachages par jeton — n'est pas
  normalisée avant le relèvement : ses composantes croissent comme la racine du nombre de jetons, donc `sin(val)` sature
  et oscille, et `val²` grandit, **avant** la normalisation finale ; (2) surtout, les coordonnées `i % 3 == 2` valent
  `val² ≥ 0` : tous les exemplaires partagent le même demi-espace sur un tiers des coordonnées — une direction commune
  que la normalisation par vecteur n'enlève pas, et qui suffit à faire un σ1 dominant. **Le remède du rapport
  (normaliser avant le relèvement) borne (1) mais ne corrige pas (2)** ; le correctif manquant est un **centrage**
  (soustraire la moyenne des exemplaires avant le spectre), qui est l'usage standard avant toute décomposition.
- **SimHash sur n-grammes** : fondé — le hachage SHA-256 par jeton entier est bien à effet d'avalanche (vérifié dans le
  code) et détruit les racines morphologiques ; l'essai a mesure le gain réel.
- **Effet de bord non traité par le rapport** : changer l'encodage change la mesure de nouveauté et donc le **critère
  d'arrêt** des générations (convergence de Cauchy du spectre + saturation de Shannon) ; les 18 générations accumulées ne
  sont plus comparables. Toute v6.3 doit re-étalonner son critère d'arrêt et le dire.

## Brique 2 — noyau de tirage « DPP bilinéaire » + Sinkhorn (`principal.py`)

- **Le noyau annoncé « strictement PSD par produit de Schur » ne l'est pas sous la forme donnée.** La matrice
  M_ij = 1 − ⟨d_i,d_j⟩² a une diagonale nulle (d_i unitaires) donc une trace nulle : dès qu'elle n'est pas nulle, elle a
  une valeur propre négative ; le produit de Schur ⟨o_i,o_j⟩² ∘ M n'hérite d'aucune garantie (le théorème de Schur vaut
  pour un produit de deux matrices PSD ; M n'en est pas une). **C'est exactement le piège que la caste 2 reproche à la
  caste 1.** La forme « trace » affichée comme équivalente, Tr(B_iᵀB_j), vaut en réalité ⟨o_i,o_j⟩·(14 + ⟨d_i,d_j⟩²) en
  dimension 16 : elle est PSD, mais elle **récompense** (faiblement) la similarité de domaine au lieu de la pénaliser —
  l'égalité affichée dans le rapport est fausse. L'essai b le mesure.
- **Défaut de conception plus profond** : dans un processus ponctuel déterminantal, on ne peut pas « récompenser » la

- **Sinkhorn** : l'équilibrage symétrique D L D préserve la semi-définie positivité (congruence) — juste ; mais équilibré

## 1. Brique 2 — noyau de tirage

### Essai 1 : semi-définie positivité de la forme du rapport

Méthode. 1 000 jeux de n = 20 couples (d_i, o_i) unitaires tirés uniformément sur la sphère de dimension 16, q_i uniforme sur [0,5 ; 1,5]. Le noyau est assemblé sous la forme exacte L_ij = q_i q_j ⟨o_i,o_j⟩² (1 − ⟨d_i,d_j⟩²), puis décomposé par la copie de la fonction de Jacobi de l'organisme. Violation si λ_min < −10⁻⁸.

| Mesure | Valeur |
|---|---|
| Jeux en violation | **1 000 / 1 000** (de même à 120 rotations : un quotient de Rayleigh négatif suffit à le certifier) |
| λ_min | médiane −0,715 (de −1,414 à −0,366) ; λ_min/λ_max médiane −0,545 |
| Valeurs propres négatives par matrice | 10 à 13 sur 20 (médiane 11) |
| \|diagonale\| max ; \|trace\| max | 2,3e-15 ; 7,0e-15 |
| Mineurs principaux 2×2 négatifs | 189 380 / 190 000 (les autres ont L_ij < 10⁻⁶) |

Pourquoi. ⟨d_i,d_i⟩ = 1 annule la diagonale de M = J − C∘C, donc celle de L, donc sa trace. Une matrice symétrique non nulle de trace nulle a une valeur propre négative. Le théorème du produit de Schur exige deux facteurs semi-définis positifs, et M ne l'est pas. La note de la consigne (« K∘M n'est pas forcément indéfini ») est juste en général, mais ici K = (O∘O) a une diagonale unité et M une diagonale nulle : l'indéfinition est certaine dès que L ≠ 0. Conséquences : P({i}) ∝ L_ii = 0 pour tout singleton, P({i,j}) ∝ −L_ij² < 0 pour toute paire. Aucun tirage n'est défini. Cholesky échoue dans 200 corpus sur 200, en version gloutonne incrémentale comme en version de la bibliothèque d'algèbre linéaire [b2-tirages].

Sinkhorn-Knopp (5 itérations) puis + γI. Écart à la bistochasticité après 5 itérations : 2,9e-4 en médiane. La version symétrisée D L D est une congruence, elle conserve l'inertie : λ_min reste négatif (médiane −0,484). Violations : 1 000 / 1 000 pour γ ∈ {10⁻⁶ ; 10⁻³ ; 10⁻² ; 10⁻¹}. Le γ minimal requis vaut 0,37 à 0,66 (médiane 0,48), soit la moitié d'une somme de ligne, et non une régularisation « de Tikhonov ». À ce γ, la diagonale est constante : la qualité disparaît, et l'effet sur la sélection s'inverse (essai 3).

**Affirmation « garanti semi-défini positif par produit de Schur » : réfutée (1 000 / 1 000 violations).**

### Essai 2 : forme « trace » de la caste 2

**Égalité « Tr[…] = 1 − ⟨d,d⟩² » : réfutée. La trace vaut 14 + ⟨d,d⟩².** La forme trace est bien semi-définie positive. Dans un processus déterminantal, son terme dominant 14·⟨o_i,o_j⟩ est une similarité, donc une répulsion. Elle écarte les paires qui partagent un opérateur : 5,5 à 16 % d'ensembles bisociatifs contre 33,5 à 71,5 % au hasard (essai 3).

## 2. Brique 3 — répulsion et pivots de Swanson

### Seuil d'entrée du pivot

`termes_satures` = jetons de fréquence documentaire ≥ max(2, ⌊0,75 n⌋), triés par (−fréquence, ordre alphabétique), 6 premiers. Le seuil réel vaut ⌊0,75 n⌋/n : 60 % à n = 5, 70 % à n = 10, 75 % à n = 20.

Corpus : textes A et C sur deux vocabulaires disjoints (60 mots chacun, loi de Zipf), pivot B dans m des n textes en alternance A/C, k mots-outils présents dans tous les textes (plus 20 mots-outils à probabilité 0,5 quand k > 0). 200 graines par cellule. Probabilité que B soit dans `termes_satures` [b3-synth] :

| n (seuil) | k = 0 | k = 3 | k = 6 | k = 12 |
|---|---|---|---|---|
| 5 (3/5) | f = 0,6 : 0,73 à 1,00 ; f ≥ 0,8 : 1,00 | f = 0,6 : 0,00-0,07 ; 0,8 : 0,77-0,97 ; 1 : 1,00 | 0 pour f < 1 ; f = 1 : 0,98-1,00 | 0 pour f < 1 ; f = 1 : 1,00 (« calcium ») / **0,00** (« magnesium ») |
| 10 (7/10) | 0 pour f ≤ 0,6 ; **1,00 dès f = 0,7** | f = 0,7 : 0,73-0,89 ; ≥ 0,8 : 0,97-1,00 | 0 pour f < 1 ; f = 1 : 1,00 | 0 pour f < 1 ; f = 1 : 1,00 / **0,00** |
| 20 (15/20) | 0 pour f ≤ 0,7 ; **1,00 dès f = 0,75** | idem k = 0 | 0 pour f < 1 ; f = 1 : 1,00 | 0 pour f < 1 ; f = 1 : 1,00 / **0,00** |

Le pivot entre dès f ≥ ⌊0,75 n⌋/n tant que moins de 6 jetons le précèdent. Avec 6 mots-outils omniprésents ou plus, il n'entre jamais pour f < 1. À f = 1, il n'entre que si l'ordre alphabétique le place parmi les 6 premiers ex aequo : « calcium » oui, « magnesium » non avec 12 mots-outils. Le plafond de 6 et les mots-outils protègent donc le pivot, par accident.

## 3. Brique 4 — fusion « pushout »

### Biais de verbosité du score de fertilité

Fonctions `extraire_termes` et `pushout_conceptuel` copiées à l'identique du code de la caste 1 [b4].

Ponts constants (p ponts plantés 3 fois dans chaque texte, V mots propres par texte) :

| p | score original, V = 2 → V ≥ 30 − p (plafond des 30 termes) | score normalisé, idem |
|---|---|---|
| 1 | 1,61 → 4,08 (×2,53) | 0,322 → 0,069 (×0,21) |
| 3 | 4,83 → 12,02 (**×2,49**) | 0,690 → 0,211 (×0,31) |
| 8 | 12,88 → 30,45 (×2,37) | 1,073 → 0,586 (×0,55) |

Population réaliste : 2 000 paires, p vrai de 0 à 6, longueurs de 10 à 150 jetons par texte, 30 % de vocabulaire général partagé, donc des ponts fortuits.

| Score | corr. de rang avec p vrai | avec la verbosité | partielle verbosité \| p | partielle p \| verbosité |
|---|---|---|---|---|
| original | 0,837 | 0,274 | **0,534** | 0,877 |
| normalisé \|ponts\|/\|union\|·log(1 + \|diff. sym.\|) | **0,872** | 0,153 | **0,351** | 0,886 |
| \|ponts\| seul | 0,857 | 0,228 | 0,477 | 0,885 |

Dans les strates de p, la corrélation avec la verbosité vaut 0,50 à 0,61 pour l'original et 0,22 à 0,45 pour le normalisé. Le résidu vient des ponts fortuits, qui croissent avec la longueur : 1,53, 2,34 puis 3,20 ponts en moyenne selon la tranche. **Le biais est établi. La normalisation le réduit sans l'annuler, et l'inverse à ponts strictement constants.** Corriger le résidu demanderait de comparer le recouvrement à son attendu sous hasard, ou de pondérer les ponts par leur rareté de fond. Ce n'est pas testé ici.

### Filtre de compatibilité des contraintes

Filtre minimal. Quatre axes (linéaire / non linéaire, stationnaire / transitoire, discret / continu, convexe / non convexe), formes françaises et anglaises, expression Unicode, formes négatives masquées avant de chercher les positives. Il y a contradiction si un texte vaut + et l'autre − sur un même axe ; un texte portant les deux marqueurs vaut « ± » et n'est pas compté. Corpus : 200 corpus de 20 textes (10 A, 10 C), valeur plantée +, − ou ∅ par axe (probabilités 0,3 / 0,3 / 0,4), d'où environ 56 % de paires contradictoires. Bruits : paraphrase hors lexique, mention du marqueur contraire hors affirmation, homographe « continue ». Les fusions candidates sont les paires A×C d'interface non vide selon `pushout_conceptuel`.

| Régime (paraphrase, mention contraire, homographe) | candidates | contradictoires acceptées sans filtre | avec filtre | précision | rappel | rejets à tort |
|---|---|---|---|---|---|---|
| propre (0 ; 0 ; 0) | 11 593 | 57,4 % | **0,0 %** | 1,000 | 1,000 | 0,0 % |
| réaliste (0,15 ; 0,15 ; 0,10) | 11 676 | 55,9 % | **34,4 %** | 0,938 | 0,608 | 5,1 % |
| bruité (0,30 ; 0,30 ; 0,20) | 11 726 | 56,3 % | **48,1 %** | 0,817 | 0,354 | 10,2 % |

Par construction, la part de contradictions *détectées* parmi les fusions acceptées est de 0 % avec filtre ; sans filtre, elle vaut 57,4 %, 36,3 % ou 24,4 % selon le régime. Par ailleurs, **65 à 67 % des fusions candidates n'ont aucun des ponts plantés dans leur interface** : la condition « B = O_A ∩ O_C non vide » est remplie par les mots du gabarit et les marqueurs eux-mêmes.

- Le filtre de contradictions est évalué sur un lexique que j'ai écrit et sur des bruits que j'ai choisis. Son rappel réel sur des résumés moissonnés est inconnu (affirmation C3 indécise sur ce point).

## Les points de convergence des trois modèles

- **Architecture recommandée** : garder le noyau (sûreté), y greffer l'idéation/mutation d'un moteur de la littérature **en conteneur sans clés** *si* la première expérience montre notre grammaire bornée insuffisante, et ajouter un **évaluateur figé tenu par le noyau, hors des agents** — absent des deux voies aujourd'hui.
- **Sélection darwinienne sans Goodhart** : sévérité *ex ante* — le test et le nul sont **figés par le noyau avant** l'expérience, les tirages sont **frais après** l'engagement de l'hypothèse. Nul **composite** (bibliothèque de prédicteurs aveugles au domaine ; inférence universelle de Wasserman–Ramdas) pour que l'inégalité de Ville tienne même si le nul n'est pas exactement connu. **Contenu** d'une hypothèse = risque déclaré (divergence à une référence) × couverture du domaine : un pari couvert est classé bas, une hypothèse qui ne prédit rien ne survit pas.
- **Qui écrit le test** : avec nul figé et tirages après dépôt, peu importe (Ville tient) — mais c'est **à vérifier**, et c'est l'objet de la première expérience.
- **Recombinaison bisociative** (sous réserve de la pièce C) : forme minimale = tirage (éloignement des domaines × similarité d'opérateur sur arbre syntaxique **canonisé**) + filtre mécanique de contraintes + fusion ; test sur des mondes à isomorphismes plantés **contre un tirage stratifié recevant exactement le même prompt et le même filtre** ; réfutée si l'écart < ~12 points.

### (a) Ce que la question suppose sans que ce soit établi (et diagnostic des points 1 à 3)

#### 1. Diagnostic de la forme corrigée (`c5` dans C3b) et ses points de rupture
Dans C3b, le correctif $L = \operatorname{diag}(q)(S + 10^{-3}I)\operatorname{diag}(q)$ avec $S_{ij} = \langle d_i, d_j \rangle^2$ suivi d'un appariement d'opérateur après tirage affiche une diversité de domaines de `0,891` à `0,936` et un taux d'ensembles bisociatifs de `0,995` à `1,000` (**RAPPORTÉ**). Toutefois, la question suppose implicites plusieurs prémisses non établies :

* **Séparabilité lexicale Domaine / Opérateur sur résumés courts** — Statut : **HYPOTHÈSE**. C3b note explicitement dans ses réserves que les méthodes `c3` à `c5` utilisent des étiquettes d'opérateur supposées connues, et qu'en pratique il faudrait les extraire de résumés de moins de 150 mots (**RAPPORTÉ**). Or, sur données textuelles brutes, l'intersection lexicale $B = O_A \cap O_C$ ne contient aucun des ponts plantés dans `65 %` à `67 %` des fusions candidates (**RAPPORTÉ**, C3b §3).
* **Indépendance entre le tirage répulsif de domaine et l'existence d'un pont après tirage (`c5`)** — Statut : **HYPOTHÈSE**. Dans C3b, pour $n = 20$ et $k = 4$, le tirage par déterminant maximal sélectionne 4 articles de domaines éloignés *sans regarder les opérateurs*, puis cherche une paire partageant un opérateur parmi les $\binom{4}{2} = 6$ paires tirées (**RAPPORTÉ**). Cela ne fonctionne à `99,5 %` dans C3b que parce qu'il n'y a que 8 opérateurs synthétiques pour 20 articles (paradoxe des anniversaires) et que `c5` force la paire après coup (**OBSERVÉ-NON-AUDITÉ**). Sur un corpus réel de $n \in [12, 50]$ articles avec des dizaines d'opérateurs fins ou bruités, un tirage de $k=4$ purement aveugle aux opérateurs a une probabilité élevée de ne contenir *aucune* paire partageant un opérateur non trivial (**HYPOTHÈSE**).
* **Neutralité des opérateurs moyeux (hubs) et homonymes** — Statut : **HYPOTHÈSE**. Si l'opérateur partagé est un hub méthodologique générique (« *gradient* », « *matrix* », « *bound* ») ou un homonyme inter-domaines (« *noyau* », « *champ* », « *diffusion* »), `c5` déclarera un succès bisociatif alors que l'interface est triviale ou contradictoire. C3b montre que sans fréquence de fond externe (remède `b+`), aucune règle interne au petit corpus ne sépare un vrai pivot d'un hub générique (**RAPPORTÉ**).
* **Stabilité du filtre de compatibilité des contraintes face au bruit** — Statut : **RAPPORTÉ (fragile)**. En régime de bruit réaliste (paraphrases `0,15`, mentions contraires `0,15`, homographes `0,10`), le filtre laisse passer `34,4 %` de fusions contradictoires (rappel `0,608`) et grimpe à `48,1 %` en régime bruité (**RAPPORTÉ**, C3b §3).
* **Supériorité du DPP sur une partition / stratification simple à petit $n$** — Statut : **HYPOTHÈSE**. La question suppose qu'un processus déterminantal (avec Cholesky ou Jacobi à 5 000 rotations, car à 120 rotations Jacobi ne converge pas à $20 \times 20$, résidu `0,046`, **RAPPORTÉ** C3b §0) est nécessaire pour éloigner les domaines. Or, à $n \in [12, 50]$, un regroupement glouton par distance cosinus de domaine ou une grille explicite Domaine $\times$ Opérateur garantit exactement $\langle d_i, d_j \rangle < \tau$ en $\mathcal{O}(n^2)$ opérations scalaires sans algèbre spectrale (**HYPOTHÈSE**).

#### 2. Trois autres mécanismes sérieux de génération de ponts

1. **Grille Qualité-Diversité (MAP-Elites) indexée par $(\text{Domaine}, \text{Opérateur canonisé})$** — Source : Mouret et Clune (2015), *Illuminating search spaces by mapping elites* (**VÉRIFIÉ**). Au lieu d'échantillonner des k-uplets via un déterminant qui mélange répulsion de domaine et qualité et ignore l'opérateur jusqu'au post-traitement, on maintient une archive matricielle explicite où les lignes sont les grappes de domaines $D_a$ et les colonnes sont les signatures d'opérateurs formels $O_m$ (filtrées par inverse de fréquence de fond selon `b+`). Chaque cellule $(D_a, O_m)$ ne conserve que l'élément de qualité $q_i$ maximale. Un « pont bisociatif » est lu directement et déterministement dans toute colonne $O_m$ qui possède au moins deux cellules peuplées $(D_a, O_m)$ et $(D_b, O_m)$ avec $a \neq b$ et $\langle d_i, d_j \rangle^2 < \tau$. Contrairement à `c5`, ce mécanisme ne rate jamais un pont rare présent dans le corpus ($n = 12$ à $50$) et évite totalement les inversions matricielles (**HYPOTHÈSE**).
2. **Alignement d'arbres relationnels / Analogie structurelle (Structure-Mapping Engine)** — Source : Gentner (1983), *Structure-mapping: A theoretical framework for analogy* ; Falkenhainer, Forbus et Gentner (1989), *The structure-mapping engine: Algorithm and examples* (**VÉRIFIÉ**). Pour éliminer les chimères verbales dues aux homonymes lexicaux (où deux textes partagent le mot « *potentiel* » ou « *convergence* » sans structure commune), l'opérateur n'est plus un sac de mots mais un arbre syntaxique ou DAG d'opérations canonisées (dans notre pôle, l'arbre de l'hypothèse : `entrées -> transformations -> invariant/borne -> sortie`, **HYPOTHÈSE**). Selon le principe de systématicité de Gentner, on n'apparie deux éléments de domaines disjoints que s'ils partagent un sous-arbre relationnel d'ordre $\ge 2$ (par exemple : une transformation non linéaire suivie d'une borne de concentration) dont les feuilles portent des types mathématiques compatibles. C'est le seul mécanisme qui attaque à la racine les `65–67 %` de fausses interfaces lexicales mesurées dans C3b (**HYPOTHÈSE**).
3. **Découverte fondée sur la littérature (Swanson A–B–C) pondérée par rareté de fond et surprise directionnelle** — Source : Swanson (1986), *Fish oil, Raynaud's syndrome, and undiscovered public knowledge* (**VÉRIFIÉ**). Dans la formulation classique A–B–C sur graphe biparti Articles $\times$ Concepts, les chemins de longueur 2 ($A \to B \to C$ avec $A \cap C = \emptyset$) sont pollués par les hubs méthodologiques $B$. Mais en combinant le résultat établi `R3` (`b+`) de C3b (**RAPPORTÉ**) avec un graphe orienté de paires `(pré-condition -> opérateur -> post-condition)`, un pivot $B$ n'est valide que si : (i) sa fréquence dans l'archive de fond est basse ($f_{\text{fond}}(B) \le 0,10$), et (ii) la post-condition de $A$ satisfait la pré-condition de $C$ via $B$. Cela transforme le modèle descriptif de Swanson en composition fonctionnelle $C \circ_B A$ (**HYPOTHÈSE**).

#### 3. La fusion : consigne d'amalgamation et critère mécanique d'excès de contenu empirique

* **Pourquoi l'union échoue** : Une hypothèse fille $H_{AC}$ qui se contente de juxtaposer $H_A$ et $H_C$ ($H_A \wedge H_C$ sur leurs sous-domaines respectifs, ou un « pari couvert » conditionnel du type `si domaine A alors H_A sinon H_C`) ne gagne aucun pouvoir prédictif croisé (**HYPOTHÈSE**).
* **Consigne de fusion structurée (Substitution d'opérateur sous transport de contraintes)** : Le gabarit envoyé au modèle de langue ne doit pas demander une « synthèse créative », mais imposer quatre champs obligatoires vérifiables par le noyau :
  1. `Invariants_transportés` : quelle variable d'état de $A$ est identifiée à quelle variable de $C$ via l'opérateur commun $B$.
  2. `Contraintes_héritées` : l'union explicite des hypothèses de régularité de $A$ et de $C$ (soumise au filtre mécanique de non-contradiction).
  3. `Loi_fille_exécutable` : l'expression paramétrique dans la grammaire bornée du noyau (compatible `C-17`).
  4. `Instance_croisée_falsifiable` : une prédiction chiffrée sur un régime où les variables de $A$ et de $C$ interagissent simultanément.
* **Critère mécanique de Popper–Lakatos (« prédire plus que ses parents »)** — Statut : **HYPOTHÈSE**. Soit $\mathcal{X}$ l'espace des instances de test géré par le noyau (avec nul composite $P_0$ figé *ex ante*, cf. synthèse R-525, **RAPPORTÉ**). Chaque hypothèse $H$ définit un domaine d'applicabilité déclaré $D(H) \subseteq \mathcal{X}$ et une distribution prédictive (ou fonction de score) $P_H(y \mid x)$. Reprenant la mesure de contenu validée au tour précédent ($\text{Contenu}(H) = \text{Risque déclaré } KL(P_H \| P_0) \times \text{Couverture } |D(H)|$, **RAPPORTÉ** R-525), le noyau accepte mécaniquement la fille $H_{AC}$ *avant* tout tirage frais si et seulement si elle satisfait simultanément trois inégalités strictes :
  1. **Non-trivialité de l'interface** : $D(H_{AC}) \cap D(H_A) \neq \emptyset$ et $D(H_{AC}) \cap D(H_C) \neq \emptyset$.
  2. **Gain de contenu strict sur l'enveloppe des parents (anti-juxtaposition)** :
     $$\forall x \in D(H_A) \cap D(H_C), \quad \min\big(\operatorname{JS}(P_{H_{AC}}(\cdot|x), P_{H_A}(\cdot|x)), \, \operatorname{JS}(P_{H_{AC}}(\cdot|x), P_{H_C}(\cdot|x))\big) \ge \delta_{\text{div}}$$
     (la fille ne copie ni $A$ ni $C$ sur leur intersection), **ET** le contenu total vérifie :
     $$\operatorname{Contenu}(H_{AC}) > \max\big(\operatorname{Contenu}(H_A), \operatorname{Contenu}(H_C)\big) + \Delta_{\text{ext}}$$
     où $\Delta_{\text{ext}}$ est le contenu évalué sur les instances d'interaction $x \in D(H_{AC}) \setminus (D(H_A) \cup D(H_C))$ ou sur le produit croisé des variables de $A$ et $C$.
  3. **Survie séquentielle (inégalité de Ville)** : sur les tirages frais post-engagement, la richesse de martingale $M_t(H_{AC})$ dépasse à la fois le seuil de promotion $1/\alpha$ et le maximum ponctuel des parents $\max(M_t(H_A), M_t(H_C))$ sur le domaine d'interaction. Cela élimine mécaniquement toute juxtaposition ou moyenne convexe des parents.

### (b) Expériences décisives en inférence forte ($H_A$ contre $H_B$)

#### Expérience 1 — Étage de tirage et d'appariement (Mondes à isomorphismes plantés, remplaçant C4 absent)

* **Question tranchée** : À petit corpus ($n = 30$) et sous bruit lexical réaliste (synonymes inter-domaines et hubs méthodologiques), le tirage DPP corrigé `c5` sur n-grammes/mots bat-il une grille directe Domaine $\times$ Opérateur canonisé (avec filtre de fond `b+`) ?
* **Hypothèse $H_A$ (Suffisance du DPP corrigé `c5`)** : Le noyau $L = \operatorname{diag}(q)(S + 10^{-3}I)\operatorname{diag}(q)$ couplé au SimHash morphologique et à l'appariement post-tirage `c5` suffit à découvrir les isomorphismes plantés lorsque les domaines utilisent des vocabulaires disjoints.
* **Hypothèse $H_B$ (Cécité structurelle de `c5` et supériorité de la Grille QD + AST canonisé)** : En présence d'homonymes et de notations disjointes (isomorphismes non lexicaux) ou lorsque les vrais ponts sont rares (1 à 2 paires sur $\binom{30}{2} = 435$), le tirage DPP de taille $k=4$ manque la paire avant l'étape d'appariement, tandis qu'une grille directe Domaine $\times$ Opérateur sur invariants d'arbres syntaxiques canonisés (filtrée par fréquence de fond `b+` $\le 0,10$) extrait les ponts déterministement.
* **Protocole et données** :
  * Construction sur processeur de `200` (illustratif) mondes synthétiques de $n = 30$ articles/hypothèses répartis en 5 domaines au vocabulaire d'objets strictement disjoint.
  * Dans chaque monde, on plante exactement `2` (illustratif) paires véritablement isomorphes (même équation génératrice / même graphe d'opérateurs sous renommage des variables : ex. diffusion thermique sur graphe et consensus distribué de Markov), `5` (illustratif) paires « chimères homonymes » (même mot d'opérateur mais contraintes contradictoires ou structures d'arbres incompatibles), et `10` (illustratif) paires reliées par un hub générique ($f_{\text{fond}} > 0,30$).
* **Contrôle négatif (Nul calibré)** : Tirage aléatoire stratifié par domaine (1 article par domaine, soit $k=4$ domaines distincts tirés sans DPP), soumis exactement au même filtre de compatibilité des contraintes et à la même consigne de fusion.
* **Métrique** :
  1. `Précision@k_paires` et `Rappel@k_paires` des vraies paires isomorphes parmi les paires envoyées à la fusion.
  2. Taux de fausses alertes (chimères homonymes ou hubs promus à la fusion).
* **Seuils et issues falsifiantes** :
  * **Falsification de $H_A$** : Si le rappel de `c5` sur les isomorphismes plantés est inférieur à `0,50` (illustratif) dès qu'il y a $\le 2$ paires plantées par monde, OU si son gain en `Rappel` sur le contrôle négatif (tirage stratifié par domaine) est $< +12$ points de pourcentage (seuil issu de la synthèse R-525, **RAPPORTÉ**), le tirage DPP est réfuté et abandonné pour la v0.

#### Expérience 2 — Rétrodiction temporelle sur littérature réelle (Ponts historiques A–B–C)

* **Question tranchée** : Le mécanisme de recombinaison redécouvre-t-il de vraies synthèses scientifiques inter-domaines à partir d'articles antérieurs à leur jonction, mieux qu'un tirage stratifié à prompt et filtre identiques ?
* **Hypothèse $H_A$ (Fertilité bisociative réelle)** : L'appariement par opérateur filtré (`b+` + compatibilité des contraintes) suivi de la consigne de fusion structurée génère l'opérateur hybride réel avant la date de jonction $t_0$.
* **Hypothèse $H_B$ (Illusion de post-sélection / Bruit de prompt)** : Le modèle de langue qui effectue la fusion produit des généralités plausibles quelle que soit la paire inter-domaines fournie ; le mécanisme d'appariement ne fait pas mieux qu'un tirage stratifié de domaines disjoints.
* **Protocole et données** :
  * Extraction depuis OpenAlex / arXiv de `30` (illustratif) cas historiques de transfert inter-domaines documentés où deux lignées $A$ et $C$ avaient un taux de co-citation nul avant $t_0$ (ex. $t_0 = 2020$) et ont donné lieu après $t_0$ à un article de jonction $J_{AC}$ (co-citant $A$ et $C$ avec un protocole ou théorème hybride explicite).
  * Pour chaque cas, constitution d'une piscine locale de $n = 30$ (illustratif) résumés antérieurs à $t_0$ : les 2 parents réels $(A^*, C^*)$, 14 articles du domaine de $A$, 14 articles du domaine de $C$. (Pour neutraliser la fuite de mémoire pré-entraînée du LLM, seconde passe avec anonymisation/substitution des entités nommées de domaine par des symboles génériques `Domaine_X`, `Variable_Y`).
* **Contrôle négatif (Nul calibré)** : Tirage aléatoire stratifié (1 article dans la grappe $A$, 1 article dans la grappe $C$, sans appariement d'opérateur), passé dans le **même** filtre de contraintes et le **même** prompt de fusion.
* **Métrique** :
  1. `Hit@5` mécanique sur les paires : présence de la paire $(A^*, C^*)$ (ou d'une paire partageant exactement le même opérateur formel que $J_{AC}$) dans les 5 premières paires classées par le sélecteur.
  2. `Gain d'excès de contenu` : proportion de fusions filles qui reproduisent les contraintes et l'opérateur cible de $J_{AC}$ (évalué par recouvrement des triplets `(opérateur, contrainte, variable)` extraits de $J_{AC}$).
* **Seuils et issues falsifiantes** :
  * **Falsification de $H_A$** : Si l'écart de `Hit@5` ou de recouvrement des triplets de $J_{AC}$ entre le sélecteur bisociatif et le tirage stratifié est $< +12$ points de pourcentage (**RAPPORTÉ** R-525), l'étage d'appariement bisociatif sur résumés est réfuté (confirmant la crainte des castes 2, 4, 5 sur la pauvreté des résumés $< 150$ mots, **RAPPORTÉ** C1).
  * **Falsification de $H_B$** : Si le sélecteur bisociatif atteint un `Hit@5` $\ge 45 \%$ (illustratif) et surpasse le nul stratifié de $\ge +20$ points (illustratif) y compris sous masquage des entités nommées, l'hypothèse que le LLM travaille seul par mémoire ou hasard est réfutée.

#### Expérience 3 — Épreuve de la fusion : Excès de contenu empirique vs Juxtaposition (Popper–Lakatos)

* **Question tranchée** : La consigne de fusion par substitution d'opérateur + filtre mécanique de contenu produit-elle des hypothèses filles qui battent leurs deux parents sur des tirages frais, ou dégrade-t-elle la précision par rapport aux parents isolés ?
* **Hypothèse $H_A$ (Super-additivité empirique de la fusion contrainte)** : Les hypothèses filles qui passent le filtre mécanique de compatibilité et d'excès de contenu ($\operatorname{Contenu}(H_{AC}) > \max(\operatorname{Contenu}(H_A), \operatorname{Contenu}(H_C)) + \Delta_{\text{ext}}$) obtiennent sur les instances d'interaction une richesse de martingale $M_t(H_{AC}) > \max(M_t(H_A), M_t(H_C))$.
* **Hypothèse $H_B$ (Dégradation chimérique ou simple couverture)** : Les fusions acceptées par un modèle de langue sont soit des juxtapositions déguisées (paris couverts : vraies sur $D(A)$ mais fausses sur l'interaction), soit des chimères formelles qui échouent dès qu'on les exécute sur les données fraîches.
* **Protocole et données** :
  * Sur le banc de sélection de la synthèse R-525 (`50` paires d'hypothèses parentes survivantes exécutables dans la grammaire bornée `C-17`, **RAPPORTÉ** / illustratif pour l'effectif), génération de deux bras de filles :
    * *Bras 1* : Fusion libre (« Combine ces deux hypothèses en une hypothèse plus générale ») sans filtre mécanique d'excès de contenu.
    * *Bras 2* : Fusion par substitution d'opérateur + rejet mécanique *ex ante* de toute fille qui viole le filtre de contraintes ou l'inégalité de Popper–Lakatos ($\Delta_{\text{ext}} \le 0$).
* **Contrôle négatif** : L'enveloppe mécanique des parents sans fusion ($\max(P_{H_A}, P_{H_C})$ et mélange $0,5 P_{H_A} + 0,5 P_{H_C}$).
* **Métrique** : Taux de survie sous l'évaluateur séquentiel figé du noyau (inégalité de Ville au seuil $\alpha = 0,05$, illustratif) sur les instances fraîches du régime croisé, et part de paris couverts promus à tort.
* **Seuils et issues falsifiantes** :
  * **Falsification de $H_A$** : Si le Bras 2 produit moins de `25 %` (illustratif) de filles qui surpassent strictement l'enveloppe mécanique $\max(M_t(H_A), M_t(H_C))$ sur les tirages frais, ou si le taux de promotion des chimères dépasse $\alpha = 0,05$ (illustratif), l'opérateur de fusion par LLM est réfuté au profit d'une recombinaison purement algébrique des arbres `C-17`.
  * **Falsification de $H_B$** : Si le Bras 2 réduit à $\le 5 \%$ (illustratif) la promotion des paris couverts (contre $> 30 \%$ pour le Bras 1, illustratif) tout en doublant le taux de filles qui battent leurs deux parents, l'hypothèse de dégénérescence chimérique est réfutée.

## Contre la proposition B

### (a) Failles

**B1. Le monde planté fuit par la forme, pas par le domaine.** B exige des domaines à vocabulaires disjoints et un « tricheur lexical » à précision proche du hasard. Mais chaque élément « décrit une régularité observée » : le texte doit nommer la forme de la loi (saturation, décroissance, plateau, oscillation, seuil). Ce vocabulaire de forme est transversal aux domaines, et c'est lui qui porte la loi latente. Un tricheur sur mots de domaine est au hasard par construction (les ponts n'en partagent aucun, les homonymes en partagent un : le tricheur est même sous le hasard), donc le contrôle de fuite passe sans rien tester. Le tricheur à construire est un classifieur sur le vocabulaire de forme, hors mots de domaine (HYPOTHÈSE).

**B2. E1 à ε = 0 est tautologique, et le contraste DPP/stratifié ne porte sur rien.** B l'avoue (a2) mais ne corrige pas : si l'« étiquette d'opérateur » est la loi latente, le pont après tirage est un oracle, et « précision de pont » vaut 1 dès que les 4 tirés contiennent une paire étiquetée. Les bras 1 et 2 reçoivent le même oracle ; seul diffère le choix des 4 éléments. La métrique mesure alors le nombre de paires étiquetées dans un 4-uplet, pas un pont. À ε > 0, la chute de précision est la même pour les deux bras, puisque l'étape fautive leur est commune : le plan factoriel n'identifie pas la source du gain.

**B3. E2 déplace la lexicalité dans les étiquettes de relations.** Les relations sont extraites par un modèle de langue en « graphe typé », puis l'isomorphisme est vérifié mécaniquement. Si le vocabulaire des relations est ouvert, l'extracteur peut nommer la relation d'après le mot du texte (« applique_noyau ») : l'isomorphisme devient un appariement de labels, c'est-à-dire du lexique rebadgé. Le contrôle « graphes permutés, types conservés » agit sur le graphe déjà extrait, jamais sur l'extracteur. Il manque un vocabulaire de relations fermé et figé avant E2, et un contrôle où l'extracteur reçoit un texte dont les mots-clés ont été échangés entre un homonyme et son jumeau honnête (HYPOTHÈSE).

**B4. Le critère « prédit plus » (ii) ne distingue pas transfert et recopie.** Rejet si « la prédiction est déductible d'un seul parent (on donne au même évaluateur A seul, puis B seul) ». Dans le monde de B, le parent B *contient* l'asymptote. Une fille qui recopie l'asymptote de B en renommant les variables de A n'est pas « déductible de B seul » pour un évaluateur qui ne connaît pas la table de correspondance : elle passe (ii) tout en étant exactement la juxtaposition que B veut écarter. Et si l'évaluateur est un modèle de langue, c'est le juge non étalonné que C2 reproche à P3 (RAPPORTÉ).

**B5. (iii) est acquis par base de rate.** La « conjonction littérale A ; B » ne prédit rien sur l'asymptote de A (B parle de son propre domaine). N'importe quelle fille qui transfère *une* loi de la bibliothèque bat la conjonction ; avec 6 à 8 lois et des mots de forme (B1), deviner la bonne famille a une probabilité largement supérieure à 1/8 (illustratif, HYPOTHÈSE). Le témoin « transfert mécanique » (bras 2) a, lui, accès à la bibliothèque des formes fonctionnelles du générateur : c'est un oracle de forme, pas un témoin. S'il gagne, cela ne dit rien du cas réel sans forme explicite ; s'il perd, c'est suspect.

**B6. Asymétrie de falsification en E0.** « H_A réfutée : tout l'étage par modèle de langue est réfuté, quel que soit le tirage. » Une réfutation sur des mondes à lois paramétriques explicites n'implique rien pour des hypothèses textuelles sans forme fonctionnelle, cas que B reconnaît pourtant en fin d'E0. L'issue est surpuissante dans un sens, nulle dans l'autre.

**B7. E3 : la cible « reliée après T₀ » est définie sur des concepts OpenAlex,** dont la hiérarchie fait que deux concepts frères sous un même parent se relient fréquemment. Les témoins (produit des degrés, voisins communs) ne lisent pas la taxonomie ; un sélecteur qui la lit, même indirectement via les résumés, gagne sans bisociation. Confondant supplémentaire : la disponibilité des résumés dans OpenAlex varie selon éditeur et période ; un signal d'opérateur « absent » dans un tertile peut n'être qu'un résumé manquant.

**B8. Instruments « cas honnêtes appariés » pour le critère de contenu** : « 100 juxtapositions rédigées pour avoir l'air intégrées ». Rédigées par qui ? Si par un modèle, la frontière fille/juxtaposition est fixée par le style du rédacteur, et un critère qui apprend ce style passe le test sans mesurer le contenu.

**B9. Statut.** B réutilise le seuil « 12 points » de R-525 comme s'il était calibré ; R-525 le donne en « ~12 », sans nul couru (RAPPORTÉ). La citation Uzzi et al. (2013) est correctement attribuée à ma connaissance, mais son résultat porte sur des combinaisons de *références* citées, pas sur des opérateurs partagés : l'usage contre a6 est une analogie, à déclarer comme telle.

**C6. L'expérience 2 retire la partie difficile du problème.** La piscine (2 parents réels + 14 + 14 articles des deux domaines du pont) est construite en connaissant l'issue : le choix des **deux domaines** parmi tous, qui est le vrai problème de découverte, est donné.

Deux autres fuites s'ajoutent :
- la métrique accepte « une paire partageant exactement le même opérateur formel que J_AC » : l'opérateur cible est extrait de l'article postérieur, puis sert à noter un sélecteur qui apparie justement par opérateur ;
- les triplets (opérateur, contrainte, variable) de J_AC seront extraits par un modèle de langue, probablement de la même famille que le fuseur, ce qui corrèle juge et jugé.

Quant à l'anonymisation des entités, elle laisse intact le vocabulaire d'opérateur, qui est le signal. Elle écrase en revanche les vecteurs de domaine d_i calculés sur le texte. La seconde passe ne teste donc pas « le même sélecteur sans fuite » mais un autre sélecteur.

**C7. L'expérience 3 repose sur un banc qui n'existe pas.** Les « 50 paires parentes survivantes du banc R-525 » supposent la première expérience de R-525 faite. Elle ne l'est pas (R-525, RAPPORTÉ).

Le témoin max(P_A, P_C) n'est pas une loi prédictive normalisée : la richesse de martingale n'est pas définie dessus sans renormalisation, qui n'est pas spécifiée. Et « taux de promotion des chimères ≤ α » ignore la multiplicité. Avec N filles testées, l'inégalité de Ville borne chaque fille séparément, et l'espérance du nombre de promotions à tort atteint N·α.

**C8. Le critère Popper–Lakatos de C récompense ce qu'il veut exclure.**
- Contenu = KL(P_H ‖ P₀) × |D(H)| : la fille maximise le KL en étant **plus confiante** et maximise la couverture en **déclarant** un domaine large. Les deux termes sont sous le contrôle de l'agent.
- La divergence JS ≥ δ par rapport aux deux parents sur leur intersection récompense le désaccord, pas le contenu. Une sortie aléatoire la satisfait.
- Seule l'étape 3 (tirages frais) sanctionne. Le filtre *ex ante* censé économiser ces tirages ne trie donc rien d'utile.

**C9. b+ adossé à l'archive de l'organisme.** C3b dit explicitement que l'usage de l'archive comme corpus de fond n'est « pas vérifié » (RAPPORTÉ). L'archive est biaisée vers ce que l'organisme a déjà exploré. HYPOTHÈSE : un opérateur réellement fertile mais déjà souvent employé par l'organisme dépassera f_fond = 0,10 et sera rejeté comme hub. Le seuil 0,10 vient d'un réglage synthétique de C3b.

**C10. La grille « ne rate jamais un pont rare » seulement si l'extraction est exacte.** C'est l'hypothèse que C attaque chez c5 (réserve de C3b §5, RAPPORTÉ). La grille exige aussi une discrétisation des domaines (k-means à n = 12 à 50) et un seuil dur ⟨d,d⟩² < 0,25 : deux paramètres sans étalonnage. Elle est déterministe : mêmes paires à chaque génération, sans exploration.

### (b) Scénarios d'évasion

| Instrument de C | Évasion | Coût |
|---|---|---|
| Filtre anti-hubs b+ | Remplacer un hub par un synonyme rare (« gradient » → périphrase) : la fréquence de fond tombe sous 0,10 | ≈ 0 |

**Toutes à la fois.** L'agent écrit des parents dont les opérateurs sont des périphrases rares. Il passe b+, crée une colonne de grille et un « pont » déterministe. Il déclare des plages larges pour passer le vérificateur C-17. Il émet une fille surconfiante, à domaine déclaré maximal, égale à un mélange 0,51/0,49 des parents légèrement perturbé. Il la décline en 20 variantes (illustratif). Coût total : 20 fusions. Espérance à α = 0,05 : environ une promotion fausse par lot, et seul l'étage 3 limite les dégâts. Les étages 1 et 2, présentés comme mécaniques, ne filtrent rien.

### (c) Contrôles négatifs dont l'absence serait fatale

1. **Plan 2 × 2** (c5 contre grille, SimHash contre arbres canonisés) dans l'expérience 1, avec un générateur de mondes écrit par un autre agent que le canoniseur.
2. **Fille « mélange perturbé »** (0,51/0,49 + ε) et **fille surconfiante à domaine large** : elles doivent être rejetées. Sinon, le critère *ex ante* est vide.
3. **Contrôle de multiplicité** : budget fixe de filles par paire, ou contrôle du taux de fausses découvertes par e-valeurs (procédure e-BH ; référence à vérifier). Sans cela, « ≤ α » est faux dès la deuxième fille.
4. **Piscine de rétrodiction non conditionnée** sur les deux domaines du pont : le sélecteur doit aussi choisir les domaines. Et opérateur cible extrait **avant** t₀, ou par un extracteur aveugle à J_AC.
5. **Synonymes rares de hubs plantés** : b+ doit les rejeter. Sinon, la grille fabrique des ponts sur commande.
6. **A/A** avant tout seuil, comme pour A.

## Ce que l'attaque révèle sur le point où A et C s'accordent, et un test qui le tranche

Je m'en sers sans fusionner les deux propositions. A et C recommandent tous deux d'abandonner le noyau au profit d'une stratification ou d'une grille. Chez l'un comme chez l'autre, cette conclusion repose sur des étiquettes de domaine et d'opérateur supposées disponibles, qu'aucun des deux ne mesure (A1, A2, C10). Le seul instrument qui fasse foi dans les pièces, le correctif de C3b, a lui aussi été évalué sur étiquettes plantées (C3b §5, RAPPORTÉ).

**Test (inférence forte).**
- **H_A** : à étiquettes **estimées** par le même extracteur et le même regroupement, la stratification avec paire garantie atteint une proportion de « bisoc vrai » (contre la vérité plantée) au moins égale à celle de c5, moins un bruit fixé par A/A.
- **H_B** : c5 dépasse la stratification de plus que ce bruit, parce que la répulsion continue sur d_i absorbe les erreurs de frontière de domaine que la discrétisation propage.
- **Grille** : n ∈ {12 ; 30 ; 50} ; bruit d'étiquette d'opérateur ε ∈ {0 ; 0,1 ; 0,2 ; 0,3} ; nombre d'opérateurs ∈ {8 ; 40} (illustratif).
- **Contrôle négatif** : mondes sans pont planté, où les deux bras doivent tomber au niveau du hasard.

Chaque issue falsifie une recommandation : H_A falsifie le maintien du noyau, H_B falsifie la v0 « grille seule » de A et de C. Le test se court sur processeur seul, en réutilisant le code de C3b (coût 0 USD selon C3a, RAPPORTÉ).
