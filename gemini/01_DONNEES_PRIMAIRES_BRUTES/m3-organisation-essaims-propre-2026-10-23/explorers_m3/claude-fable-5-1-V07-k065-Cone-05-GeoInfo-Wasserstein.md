BASSIN_MATH: Pont-de-Schrödinger-à-Projections-Duales (PSPD)
LOI_PROPOSEE: π* = argmin_{π∈Π(μ_T,ν_A)} ⟨d²_FR, π⟩ + ε·KL(π‖π_k), puis π_{k+1} = e-proj ∘ m-proj(π*) ; θ_{k+1} = θ_k − η G_F^{-1}(θ_k)∇_θ R

1. **Auto-organisation hors-poids.** L'essaim est un couplage π sur le graphe biparti tâches×agents (μ_T : masse de tâches, ν_A : budget 100/20 USD normalisé par coût d'inférence). Le coût c(t,a)=d²_FR(p_t, q_a) est la distance géodésique Fisher-Rao entre le profil requis de la tâche et la distribution empirique des sorties de l'agent, les deux mesurées gratuitement par `jev-1.14.0`. Le plan optimal est un pont de Schrödinger calculé par Sinkhorn, c'est-à-dire une alternance de m-projections (Csiszár) sur les marges ; ε décroît avec le budget restant (exploration→exploitation). Chaque agent a des coordonnées θ (prompt système, mémoire, outils) ; on les met à jour par gradient naturel d'Amari, G_F étant la FIM estimée sur les classes jev. **Mutation topologique** par défaut de Pythagore : δ=D(p‖r)−D(p‖q)−D(q‖r) le long d'une délégation p→q→r. Si δ>τ_1, la chaîne n'est pas e/m-plate : dérive de consigne (H9) → on spawne un Red-Team recalculant q par e-projection sur la consigne initiale. Si δ<−τ_1 (sur-convergence), on spawne un explorateur. **Monoculture vs chimère** : rang(G_F^{essaim}) < k (FIM dégénérée par poids partagés, H4') ⇒ forcer des arêtes vers une famille différente ; sinon monoculture (moins chère).

2. **Objectif anti-Goodhart.**
R = −Σ_{t,a} π_{ta}·d²_FR(p_t,q_a) − λ_1·Σ|δ| − λ_2·log det(G_F^{essaim}+ηI)^{-1} − λ_3·𝟙[Var(sortie) < CR(θ)]
Le dernier terme (borne de Cramér-Rao violée) signale une récitation paramétrique : variance anormalement basse pour l'information disponible. Le juge est anti-Goodhart car jev n'évalue que des e-coordonnées (classes gelées, non génératives) tirées au sort parmi ses têtes à chaque vague ; aucun agent n'observe quelle tête juge.

3. **Duel $H_A \perp H_B$.** Budget strictement constant (100+20 USD) sur 300 tâches tenues. H_A : PSPD. H_B : assignation i.i.d. uniforme + topologie fixe. **Contrôle négatif** : PSPD avec matrice c permutée aléatoirement sur les agents (même calcul, information détruite). Métriques : taux de succès jev + 60 tâches en double aveugle humain, corrélation d'erreurs inter-agents ρ. Prédiction falsifiable : succès(H_A)−succès(H_B) > 8 points, ρ_A < 0,5·ρ_B, et le contrôle permuté ≈ H_B (test de permutation, p<0,01). Si le contrôle égale H_A, la loi est réfutée.
