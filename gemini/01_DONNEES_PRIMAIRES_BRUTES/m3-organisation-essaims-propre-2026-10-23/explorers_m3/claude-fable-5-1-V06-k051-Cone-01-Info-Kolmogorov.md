BASSIN_MATH: Recherche-de-Levin-Kt-Slepian-Wolf (RLKSW)
LOI_PROPOSEE: Topologie τ* = argmin_τ [ Kt(τ) + Σ_i ℓ_i(D | τ, poids_i) − I_GK(S_A;S_B) ] sous Σ_i c_i(τ) ≤ B, où Kt = K + log(temps), ℓ_i = longueur de code préquentielle des sorties de l'agent i, I_GK = information commune de Gács–Körner entre familles de poids.

1. **Auto-organisation hors-poids** : l'essaim est un programme sur une machine universelle dont les primitives sont {spawn, route, kill, juge}. On n'optimise jamais les poids, seulement le *programme de topologie* τ par recherche de Levin : à chaque phase t, on énumère les mutations τ' de longueur K(τ'|τ) ≤ k et on leur alloue un budget d'inférence 2^{−K(τ'|τ)}·B_t (prior de vitesse de Schmidhuber). Spawner un explorateur coûte peu en Kt (programme court, longue exécution) ; spawner un démolisseur Red-Team n'est accepté que si sa sortie *raccourcit* le code total, i.e. si ℓ(D|τ+RT) + Kt(RT) < ℓ(D|τ). Monoculture vs chimère : codage distribué Slepian–Wolf. Deux agents de même famille ont I_GK élevée (composante extractible commune = mémoire paramétrique partagée, source de H4'), donc leur débit joint R_A+R_B ≥ H(S_A,S_B) ne baisse pas : la chimère n'est choisie que si H(S_A,S_B) − H(S_mono) > coût Gemini/Claude. H9 (dérive de consigne) est bornée en imposant K(consigne_profondeur_d | consigne_0) ≤ ε·d, vérifié par `jev-1.14.0` à coût nul.

2. **Objectif & anti-Goodhart** : 
R(τ) = −[ ℓ_préq(D_test|τ) + Kt(τ) ] + λ·min_j ℓ_préq(D_test|τ, juge_j) 
où le terme min sur un ensemble de juges *tirés aléatoirement* interdit l'optimisation d'un juge fixe ; la récitation paramétrique est pénalisée car une sortie récitée a ℓ ≈ 0 mais K(sortie|poids) ≈ 0 aussi, donc on soustrait le gain de compression attribuable aux poids seuls : R_net = R(τ) − [K(D|poids) − K(D|τ,poids)]⁺ sur données postérieures à la coupure d'entraînement.

3. **Duel H_A ⊥ H_B** : H_A : l'essaim RLKSW atteint ℓ_préq strictement inférieure ; H_B : un essaim fixe (topologie figée) ou i.i.d. (agents sans routage, votes indépendants) fait aussi bien. Budget strictement constant 100 USD Claude / 20 USD Gemini par bras, trois graines, tâches `controle-ia` datées après la coupure, étiquetées par graphes arXiv/Semantic Scholar. Contrôle négatif : RLKSW avec mutations tirées uniformément (prior plat, pas de 2^{−K}). Métrique : regret cumulé de code, Δℓ = ℓ_B − ℓ_A ; on rejette H_B si Δℓ > 3 nats par tâche avec p < 0,01 (test de Wilcoxon apparié), et si le contrôle négatif ne sépare pas de l'essaim fixe (sinon le gain viendrait de la mutation seule, non de la loi).
