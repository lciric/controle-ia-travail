**Ce qui n'est pas établi.**

- Que la mesure de convergence distingue paraphrase et nouveauté (E5) ; mes deux versions antérieures étaient vraies par construction (B/A-2, C/(b)3) ; la version corrigée est à puissance incertaine.

- Que « décisif » soit autre chose qu'un contrôle de présence (F7) ; B l'a montré ; je le déclare plutôt que de le dissimuler sous un critère interprétatif.
