# Résumé sans chiffre de mesure — fiche de décision sur l'épreuve de centrage de l'oracle, v2

Remplace la v1 (même dossier, gardée), trop longue.

**Décision.** L'oracle du saboteur à budget n'est pas centré sur l'agent honnête : rester à l'arrêt, ou refaire l'oracle et son
épreuve et relancer avant la fin du GO ?

**Établi.** Aucun défaut de code mis en évidence ; le code des lecteurs du coût n'a pas été lu (réserve). Cause : propriété de
l'oracle. Le contexte réécrit ancre l'agent et le jumeau chacun sur son propre passé, et l'écart se reporte de pas en pas. Mesure
bruitée, résultat de l'épreuve fragile.

**Options.**
- A : garder l'arrêt, écrire le résultat négatif. Aucun seuil touché, aucune dépense, un jour. En décembre : l'oracle sépare le
  saboteur flagrant de l'honnête sans être centré ; rien sur le saboteur à budget.
- B : oracle et épreuve refaits sur le mécanisme trouvé, scellés avant toute mesure, graines neuves. Deux à trois jours, environ
  deux dollars d'étalonnage, course entière sous le plafond de cinquante-cinq dollars. Épreuve changée après un échec vu : à
  déclarer.
- C : élargir la borne, donc déplacer un seuil après avoir vu la mesure. Crédibilité très entamée, biais intact. Déconseillée.

**Recommandation.** A tout de suite ; B préparée sans dépense, lancée seulement sur GO avant le dernier jour de création
d'instance. Confiance moyenne.

**Défaut sous quarante-huit heures.** A.

Nœuds de Lazar : changer ce que l'oracle ou l'épreuve mesure ; relancer, donc dépenser.
